# Waveform Inversion（地震成像反演）

## 1. 任务与数据

- 预测目标：由地震波波形反演**地下速度场**（full waveform inversion，FWI）——由观测波形推断介质结构。
- 数据形态：震源-检波器波形 + 对应的速度模型（仿真数据）；典型的地球物理反演问题。
- 构造陷阱：
  - 反演问题本身**病态**（多个速度模型可产生相似波形）；
  - 数据规模大（波形 × 震源 × 接收器）；
  - 物理约束需要显式建模（波动方程）。

## 2. 方案特征

| 类型 | 说明 |
| --- | --- |
| **领域入门解释帖**（本场高价值材料） | 用最基础的语言讲清"震源 → 波 → 接收器 → 反演目标"的物理链条，并说明数据的组织方式——与 HMS 的例子一样，**领域门槛的破除是公共品** |
| 主流方案 | 端到端 CNN/U-Net 直接回归速度场；或物理驱动的迭代反演（传统 FWI）+ 神经网络加速 |

## 3. 关键技巧

- **先理解物理链条**（震源/接收器几何、波形与速度的关系）。
- **物理约束 + 数据驱动**的组合（纯数据驱动易违反波动方程；纯物理方法慢）。
- 反演任务的**病态性**需要正则化或不确定性建模（与 ARIEL 的贝叶斯路线同源）。

## 4. 可迁移性评估

- **可直接迁移**：
  - 反演类问题先建立"观测 → 参数"的物理链条理解；
  - 物理约束与神经网络的结合方式（物理模型打底、网络做残差/加速）；
  - 病态反演的不确定性处理。
- 需要前提：地球物理/波动方程基础（或愿意先补）。
- 不建议照搬：无视物理约束的纯黑箱回归。

## 5. 对新手的关键启示

1. **领域解释帖（本场最高价值材料之一）值得优先读**——比直接看代码更省时间。
2. 与 ARIEL、Ventilator、ROGII 对照：**科学反演类比赛的主线是"物理 + 数据"的配比**。
3. 仿真数据的生成机制（震源布置、噪声）决定了可行的方法上限。
