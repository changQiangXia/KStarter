# Kore 2022（规则型 agent 的胜利）

> 数据来源：`intel/kore-2022/`（80 条主题索引 + 6 篇 write-up 正文）

## 1. 任务与数据

- 对局形式：太空资源争夺类对抗游戏（多单位扩张/对抗）。
- 特点：与 Kore Beta 同源，规则明确，**启发式策略空间大**。

## 2. 方案谱系

| 方案 | 名次 | 关键点 |
| --- | --- | --- |
| **纯规则方案**（在 Beta 版冠军思路上改扩张策略） | 1st | 作者自述本想学 RL，结果发现"改一个扩张策略"就能快速爬榜，于是**决定专注规则路线**，最终夺冠；开发方式"像做软件产品"（有清单、逐步迭代） |
| 其他方案 | 见讨论区 | |

## 3. 关键技巧

- **规则路线的上限常被低估**：本场冠军就是纯规则。
- **借鉴前一版本（Beta）的公开冠军方案**，只改动关键策略（扩张）即获大幅提升。
- **以软件工程的纪律开发 agent**（清单、迭代、可维护性）。

## 4. 可迁移性评估

- **可直接迁移**：
  - **先穷尽规则方案的上限，再考虑 RL**（成本低、可控性强）；
  - 在系列赛（Beta → 正式版）里复用并改进已有方案；
  - 用工程纪律组织 agent 开发。
- 需要前提：对游戏机制的清晰理解。
- 不建议照搬：一上来就上 RL（本场冠军的路径恰好相反）。

## 5. 对新手的关键启示

1. **新手的正确起点往往是规则策略**，而不是 RL。
2. **"改一个关键策略"常胜过重写整个系统**。
3. 与 Otto（纯规则进前三）、Santa 2021（手工解法）合并观察：**规则/手工方案在 Kaggle 上被系统性低估**。

## 7. 轻读结论（2026-10 补）

**一句话**：本届是"规则型 agent 的胜利"——1st/2nd/4th/5th/20th 全是 rules-based；1st 在 Kore Beta 冠军代码上加 5,923 行/删 777 行，做"棋盘账本 + 近全路径评分 + 六相位策略"，而神经方案（13th 模仿学习、34th GNN）排名靠后。

- 1st（340035）：六相位（船坞防守/舰队攻击/船坞攻击/扩张/采矿/造舰）+ 每格每时刻的伤害账本 + 近全路径评分；V92→V118→V127，靠 jmerle 的可视化工具定位失败局；赛后名次反复（最后一天被反超又夺回）。
- 20th（339972）：经济建模——30 回合动量、实力投射矩阵、新船/基地 NPV（1% 折现）、三级造舰优先队列、试算舰队规模（含"僵尸舰队"）、Cython 加速。
- 13th（337476）：动作串当语言——75 个 token（目的地 token、num_ships 拆 2 token、DO_NOTHING 分隔）、pix2seq 式 Transformer 编解码 + TorusConv2d；自述收敛慢。
- 34th（339774）：把环面棋盘建模成图（GNN）。
- 工具与社区：jmerle 的 Koreye 调试器（63 票）被 1st 称为"至关重要"；"理解动作空间"（48 票）是入门必读；"2 周收敛"（336801）说明末期排名仍会变动。

**裁决**：对抗模拟赛先用规则方案打到上限；回放/失败归因工具是第一生产力；路径规划与经济估值是核心模块；神经方案适合做局部评价而非端到端决策。

**悬案**：2nd/3rd/4th/5th/10th 等 write-up 正文未收录；GIF 与 Koreye 截图归档缺失（图证缺口）；无高质量 RL 案例。
