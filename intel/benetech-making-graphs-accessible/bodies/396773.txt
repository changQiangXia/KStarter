Topic #396773: How to tackle this competition
  Author: moth
  Posted: 2023-03-22 22:13:42.551000
  Votes: 94  Comments: 30

In this competition you need to predict different values (data series) depending on the figure type. A very clear explanation can be found in the Graph Convention section of this competition. These conventions ensure that predictions can be made in a consistent manner across a variety of chart formats.

Step 1: predict the figure type

Different types of figures have different predictions conventions. So the first step is to predict which kind of chart is present on the image. You can use any CNN backbone (like EfficientNets, Resnets, etc) with a Linear layer at the end with the same amount of neurons as chart types.



This step is relatively easy and you should get high accuracy since it's pretty easy for CNN to distinguish the different types of charts!

Edit: the initial dataset description stated there were 4 types of charts but in fact there is a distinction between vertical bars and horizontal bars, so in reality there are 5 different types, so there should be 5 neurons in the linear layer.

Step 2: add annotations and custom markers

This competition's annotations already provide bounding boxes for the different components of the charts, like the position of the title, x-axis and y-axis labels, x-ticks and y-ticks, etc. You can find how to plot these bounding boxes in this notebook.

However, you might need to add some custom markers for points of interest, like data series which are not marked in the original images. In the next image these markers (bounding boxes) are represented by yellow dots.



Note: it might not be necessary to mark every data series point in the charts. With enough training points the Object Detection network is still able to detect data series points. Also, the accuracy of your Object Detector depends on the accuracy on the input bounding boxes and these are not perfect! For example, just look at the vertical bar chart on the image and you will notice that the provided sky blue bounding boxes are not always very accurate!

Step 3: train an Object Detection Neural Network and predict bounding boxes

With the images, the annotations and the markers you can train or fine-tune an Object Detection neural network. Use this network later at inference time to predict bounding boxes for test images without annotations nor data series points.

This step may be optional, since OCR networks (step 4) predict text and numbers and also output their respective bounding boxes. However, you would rely on the OCR's predictive precision (which is not that precise) and you would still need to find a way to detect the data series bounding boxes (yellow dots)!



Step 4: get text and numbers from OCR

Finally, with the bounding boxes and the original image you can pass them to an OCR (Object Character Recognition) network and get the corresponding text and numbers. Format the numbers, text and data series according to the chart type. 

Knowing the bounding boxes for the data series points, the minimum and maximum values for each axis and their corresponding bounding boxes coordinates you can get data series values by a simple cross multiplication.
