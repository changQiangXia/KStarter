In this competition the evaluation metric is the popular area under the ROC curve, which is ranking metric. It has shown in previous competitions that this metric can be optimized by the ensemble of different model predictions. This notebook from @ambrosm shows that ensemble works. Then, I decided to use ensemble in a slight different way; that is, I used the hill-climbing strategy that was used in a previous tabular competition by @samuelcortinhas (see this post). The idea behind hill-climbing is very simple. It combines model predictions in a linear fashion as long as the objective metric improves. Notice that in the below implementation of the hill_climbing function, we allow for negative weights. This does not have to be the case all the time. You can restrict the weights to be only positive.

In my case, I ensemble six of the traditional tree-based models with the hill-climbing strategy as shown below. First we define the hill_climbing function.
