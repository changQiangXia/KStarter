Thanks to Kaggle team for organising AutoML Grand Prix, it feels good to be back on playground competitions after so long. First round on Grand Prix is concluded, and I am satisfied with my 2nd position. As the team name on leaderboard suggest, my solution is based on some Automatic + Manual Feature Engineering & H2O DriverlessAI.

DriverlessAI provides you very interactive GUI & automates most of the machine learning workflows, which includes feature engineering, automatic visualization, MLI, model validation, model tuning, model selection, model deployment & even some useful features like directly submitting experiments to Kaggle competitions. 🤓

To learn more about Driverless AI, you can refer to these docs & demo videos:
https://h2o.ai/platform/ai-cloud/make/h2o-driverless-ai/
https://www.youtube.com/watch?v=Aiitmp-wggE

My solution mainly consists of two stages, where in first stage I ran few initial experiments directly on the smaller sample size of the data provided and did some EDA using Auto Visualization tool which DriverlessAI features. While in second stage, I did some manual feature engineering using the custom live coding UI in DAI where I could quickly do the EDA alongside & then again using DAI AutoML tool for generating best parameters for catboost and do some feature selection. Finally, using all these information to train my final models.

Within first hour of competition, I was able to fetch 0.865+ CV on Catboost | 0.847 CV with LGBM/XGBoost without any manual tweaks.
