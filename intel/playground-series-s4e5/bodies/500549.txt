Thanks to Kaggle team for organising AutoML Grand Prix, it feels good to be back on playground competitions after so long. First round on Grand Prix is concluded, and I am satisfied with my 2nd position. As the team name on leaderboard suggest, my solution is based on some Automatic + Manual Feature Engineering &amp; H2O DriverlessAI. 

DriverlessAI provides you very interactive GUI &amp; automates most of the machine learning workflows, which includes feature engineering, automatic visualization, MLI, model validation, model tuning, model selection, model deployment &amp; even some useful features like directly submitting experiments to Kaggle competitions. 🤓

To learn more about Driverless AI, you can refer to these docs &amp; demo videos:
https://h2o.ai/platform/ai-cloud/make/h2o-driverless-ai/
https://www.youtube.com/watch?v=Aiitmp-wggE 

My solution mainly consists of two stages, where in first stage I ran few initial experiments directly on the smaller sample size of the data provided and did some EDA using Auto Visualization tool which DriverlessAI features. While in second stage, I did some manual feature engineering using the custom live coding UI in DAI where I could quickly do the EDA alongside &amp; then again using DAI AutoML tool for generating best parameters for catboost and do some feature selection. Finally, using all these information to train my final models. 



Within first hour of competition, I was able to fetch 0.865+ CV on Catboost | 0.847 CV with LGBM/XGBoost without any manual tweaks.

For final runs, I used DAI primarily for Feature selection and Hyperparameters tuning, which were further tuned a little to get my final submissions. One example run shows, if we use the magic sum and other stats features, only few original features contribute to the score as shown below. 



Similarly, you can also view the parameters used in each iteration and the best combination of Hyperparameters in an experiment. 



Finally, I just took the best features and hyperparameters from DriverlessAI, and trained couple of Catboost models with multiple seeds which resulted in Out Of Fold CV Score: 0.86920 and Leaderboard: 0.86912

I think AutoML solutions for tabular datasets are already great in themselves, with some manual tweaks and involvement, they could definitely perform well. 

I have also shared a public notebook to reproduce my results, I basically train 2 models, one catboost was trained on CPU while other one was trained on GPU, so it will take long to run the first model. I have also generated the individual OOF predictions and Submissions for these models, you can also directly use them if you want, by setting parameter FULL_RUN = False in the notebook.

Notebook: https://www.kaggle.com/nischaydnk/team-oxygen-automl-2nd-place
