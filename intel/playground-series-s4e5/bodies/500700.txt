Hi everyone,

Thanks to the AutoML Grand Prix organizers team for the new competition format! We are "Team LightAutoML testers" (me, @alexryzhkov @simakov), this is a write-up of our solution for the 1st round of AutoML Grand Prix.

Manual feature engineering



features described by @ambrosm in his notebook: fsum, fstd, fspecial1: sum, std by row, and indicator "is sum between 71 and 76"

skew, kurtosis by row

counts of each unique value in a row 

values at the given quantile over a row

Result pipeline:

5 fold CV

3 models: linear with L2, LGBM, LGBM with hyperparameters tunning (up to 1200 sec)

each of model has own its auto feature preparation

blending this 3 model's outputs

TabularUtilizedAutoML
Since we had time, we tried to run TabularUtilizedAutoML -- a version of TabularAutoML that does multiple runs  different pipelines with different seeds (max_runs_per_config=4). Later it turned out that blenidng assigns zero weight to some configurations, so  so we left only two of them: conf_1_sel_type_1.yml and conf_3_sel_type_1_no_inter_lgbm.yml.
