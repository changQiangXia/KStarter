Image Classification Checklist

This is a checklist/ cheat-sheet to help you structure your image classification pipeline.
It is mainly a collection of links to kaggle topics / notebooks and some academic papers that helped in the past to solve image classification problems.

Data

Image pre-processing + EDA

Before we get to building our model, we should do some exploratory data analysis and pre-processing tasks.
To do this, look at the dataset and determine what pre-processing can be applied in order to improve the model.

Things to do:

  • Visualisation
  • Dealing with Class imbalance
  • Fill missing values (labels, features and, etc.)
  • Normalisation
  • Pre-processing

Model

Baseline

The first step is to define a baseline network, we can use a pretrained network to develop a baseline.
Then we can compare the baseline results with the newly developed network and iterate to improve the latter one.

Ideas to try to improve our baseline

  • Adding more layers
  • Using the different backbone
  • Different learning rate
  • Dropout, Batchnorm, weight_decay
  • etc.
Backbones

Basic Architectures

  • Residual Networks
  • Wide Residual Networks
  • Inception
  • Residual Attention Network

Modern Powerful Architectures

  • EfficientNet | Notebook
  • Vision Transformer (ViT) | Notebook
  • Swin Transformer | Notebook
Training Schemes

During the training process, we can try to apply different techniques to improve the model's performance or our pipeline speed.

  • Mixed-Precision Training
  • Large Batch-Size Training
  • Cross-Validation Set
  • Weight Initialization
  • Self-Supervised Training (Knowledge Distillation)
  • Learning Rate Scheduler
  • Learning Rate Warmup
  • Early Stopping
  • Differential Learning Rates
  • Ensemble
  • Transfer Learning
  • Fine-Tuning
Regularization

Some regularization tricks we can try:

  • Adding Dropout
  • Adding or changing the position of Batch Norm
  • Data augmentation
  • Mixup
  • Weight regularization
  • Gradient clipping

Loss function

Some tricks and methods we can try to improve our loss functions are:

  • Label smoothing
  • Focal loss
  • SparseMax loss and Weighted cross-entropy
  • BCE loss, BCE with logits loss and Categorical cross-entropy loss
  • Additive Angular Margin Loss for Deep Face Recognition
Training Time Augmentation

Data augmentation is more crucial in Image classification problems than any other task. It helps us to increase the network performance and overfitting.

Example of Basic DataAugmentation Techniques

  • Flip H/V
  • Random Rotate
  • Random Zoom
  • Cropping Image
  • Random Brightness

Simple More Baseline Augmentations:

  • Random Fog
  • Random Brightness/Contrast or Both
  • Random Crop
  • Random Gamma
  • RGBShift
  • HorizontalFlip/VerticalFlip
  • Random Contrast
  • Blur and its varients
  • Affine
  • Channel Dropout
  • Inverting Image
  • Noise and its varients
  • …

And Some Examples

  • Horizontal Flip
  • Random Rotate and Random Dihedral
  • Hue, Saturation, Contrast, Brightness, Crop
  • Colour jitter
Test Time Augmentation

We can also use augmentations while predicting. Not only when training.
This makes our model's predictions more robust since each of our final predictions will now be composed of multiple predictions, each with its unique perturbation.

  • Test Time Augmentation (TTA)

This is the closest you get to "free score". If you got the compute time/power to do this: This nearly always works.

Hyperparameter tuning

Once we have a solid pipeline we are happy with, we can optimize its hyperparameters so we can push its performance to be even better. Tuning hyperparameters is often a very time-consuming process and should be done in a step-by-step manner.

Error Analysis

Now we got a pipeline. It is "OK"-ish.. Now what?
In order to fix the cases where it is wrong, we should check what are the causes for errors.
Which cases are causing our model to make mistakes.
This technique is called error analysis. Here are some links to start from:

  • Tracking metrics and Confusion matrix
  • Grad CAM
