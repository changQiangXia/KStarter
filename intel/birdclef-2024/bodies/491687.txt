I just finished to download the missing birds for this competition. 
The dataset roughtly double with these additionals data, so i suppose using them would have an impact on the LB.
I uploaded in mp3 and wav (faster to load in memory, but take more space on disk)




mp3 dataset, resampled at 32Khz with default parameters using ffmpeg : 



https://www.kaggle.com/datasets/ludovick/birdclef2024-additional-mp3


wav dataset using librosa and scipy: 



https://www.kaggle.com/datasets/ludovick/birdclef2024-additional-wav-1 

https://www.kaggle.com/datasets/ludovick/birdclef2024-additional-wav-2 


Enjoy the competition!

Note: The csv file is in roughtly the same format the what we get using the Xeno API, so it might need some processing if you want to get the format of the competition.
