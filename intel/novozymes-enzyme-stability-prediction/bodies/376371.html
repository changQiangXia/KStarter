1st place solution - Protein as a Graph

This is the 1st place solution, but not necessarily the best solution.
Since there can be a large difference between a private score and a public score, many participants could not choose a submission with high private score because of low public score. It seems that there are many participants who have submissions with higher private scores than my 1st place score.
Therefore, this is not the best solution.

However, I want to share my idea so below I share my approach treating protein as a graph.

Data

Protein as a Graph

The three-dimensional structure of a protein can be represented by a graph. Nodes represent residues, and if two residues are closer than a certain distance, the nodes are connected by edges.
I created graph data from PDB files.
(see https://www.kaggle.com/code/gyozzza/create-graph-data-from-pdb-files-for-gnn)

Feature

The features of each node are the embedding vectors of wildtype sequence and mutant sequence generated by HuggingFace's facebook/esm2_t33_650M_UR50D.

I referred to Chris' public notebook (https://www.kaggle.com/code/cdeotte/prot-bert-finetune-lb-0-30 ).

Model

Graph Neural Network (GNN)

My primary GNN model is a 3-layer Graph Isomorphism Network (GIN). The intermediate features of each layer are concatenated, and the global readout features and the features of the node where the mutation occurred are input to a MLP to obtain predictions.

My best single GNN model in public LB scored

  • Private: 0.368

My best single GNN model in private LB scored

Details of 1st place submission

The bugs mentioned in discussion(https://www.kaggle.com/competitions/novozymes-enzyme-stability-prediction/discussion/375920) are

  1. GNN model output almost identical predictions for all samples in each mini-batch due to a memory issue.
  2. GNN model takes wildtype features and mutant features as inputs but two wildtype features were input when predicting on test data.

Submission by the model with the bugs scored:

  • Public: 0.295
  • Private: 0.222
