Topic #552165: Relationship between NAN and Target
  Author: Chris Deotte
  Posted: 2024-12-18 00:09:58.084000
  Votes: 126  Comments: 87

I have observed in this competition's data that some NAN values are strongly correlated with the target, Premium Amount.

Sometimes in data science we impute NAN values to be the average value of the not-NAN (in the same column). However in this competition, many of the NAN values have an associated Premium Amount not represented by any of the not-NAN's relationship to target. This means that NAN contains additional information and we do not want to impute it and hide NANs from our models.

NAN Gives Us Information

For example, consider Annual Income. If we impute NAN to be the average Annual Income then we are saying that NAN would have an expected Premium Amount of 600. But look at the plot below. We see that NAN has an expected Premium Amount of 500. This is unlike any of the not-NAN values' expected Premium Amount for feature Annual Income. (Note: in plot below, NAN is a bar plot and not-NANs are a line plot)



How To Process NAN

So these NANs are giving us additional information and we do not want to hide these NANs by naively imputing them. Here are three ways to process the NAN while telling our model we have a NAN:



Use a model which accepts NAN as NAN like GBDT (and leave NAN as is).

Impute NAN to a never seen before value like -1 (i.e. fillna(-1) )

Impute NAN to a reasonable value (like mean) after first adding a new column to record the NAN (i.e. train[f"is_{c}_na"] = train[c].isna() then impute original column).


More Examples

Below are more examples from our competition's data of NAN that have expected target values not occurring among the not-NAN values. There are also examples where NAN expected values do occur in the not-NAN but we observe that NAN does not represent the mean not-NAN expected target Premium Amount value.

In the plots below (and above), the NAN is always displayed as a bar plot (colored red). For the not-NAN values, if the column is categorical then the other values are also bar plots (colored blue). If the column is numerical then the other values are a line plot where each dot is a bin (i.e. bucket) containing all numerical values in the neighborhood of the associated x axis value.
