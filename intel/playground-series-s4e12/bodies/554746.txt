Hi Kaggle community,

The solution is a stack ensemble of 10 base models. All base models are tree models. I did log transformation of the targets for 9 of 10 of the base models and the meta model. I didn't do much feature engineering except target encoding for the categorical features. For this dataset, I found out treating some numerical features as categorical with target encoding improve the score a lot. Except for catboost, I don't apply any target encoding but simply set those columns as categorical features since catboost creates different types of target statistics for categorical features out of box. In my experiment, it greatly improved the ensemble score. I think this is somewhat similar from what @cdeotte found out in his top-1 solution where he explicitly combined categorical columns and created different target encodings. There is one special base model which is a classification model. I chunked the targets to three classes, x &lt;= 500, 500 &lt; x &lt;= 2000 and x &gt; 2000. So this model outputed the probabilities of each class to the oofs. It slightly improve the ensemble LB score from 1.02355 to 1.02337. The meta model is also a xgboost trained on top of the original features + oofs of the base models.

Some fun fact in the end.
When I try out different categorical feature sets, I found out making "Heath Score" as the categorical is the key. My journey to realize the importance of categorical feature encoding is more like by luck. From @backpaker's public notebook, he/she makes all columns as categorical and uses MSE loss to train a catboost as a base model. At first I thought MSE was the key but I couldn't get the same performance by lightgbm or xgboost. Then I went to the catboost paper and realized they did a bunch of target statistics. That's how I started to use target encoding and try out different categorical sets.
