Note, this post is not a wining solution. Simply a summary of what I did with my code. I see people reporting CVs, but it is really hard to tell what exactly they did. So here I update my codes with figures. hope it helps.

1. CV
I build two models, XGB and GRU.

  • XGB: I train three XGBs separately. Each one has a unique GAP between the train data and labels. For example, for the GAP-2 model, we jump 2 months to make predictions. I used TS=29~40 (2022-01-01 ~ 2022-12-01) as 12 validation folds, you can see each fold SMAPE and the overall SMAPE in the fig.1. The average SMAPE is 2.34. The CV for GAP-3 and GAP-4 models are 2.79 and 3.18. The OVERALL three month CV is 2.76±0.06. As for inference, I use GAP-2 model to infer March 2023, GAP-3 for April, GAP-4 for May. Code is HERE

One thing I noticed by checking the preditions by XGB is that the model usually predict 'increase' comparing to months before the GAP. That means, if you select large population cfips as mine and then use last value*1.010, last value*1.015, last_value*1.020, you may get a similar CV as mine. It seems the model only discover the general linear trend.

  • GRU: I use @cdeotte CV design. Basically, for each cfips, cut the mbd time sequences into 24-time-point sub-sequences. The label is the 3-month-density with a two month GAP as shown in Fig.2. I also use GroupKFold, so all the sub-sequences from the same cfips are in the same fold. After I get the predictions for the validation sets, I calculate SMAPE for each three-time-point labels, i.e., TS=26~28, 27~29, 28~30, …, 38~40. The overall SMAPE is 2.84. Code is HERE

2. Preprocessing

  • Code Section 1.1: Adjust mbd based on 2021 population. Details.
  • Code Section 1.3: Outlier detection and smooth. I use the code from @titericz . But remember that the outlier detection is a dangerous weapon. For example, if you apply it to all the cfips with a small TH, then you will get a small CV which is not the ture CV. But, there are outliers, what can I do? So, I decide to apply smoothing only on the cfips with large population (Top 70%) and a mbd density bigger than 0.5. I plot the distribution of the month change of the mbd, and take the tail 0.005% area as outliers. I get about 300 outliers which are mainly in 2021-01-01. I think it is ok, but not sure…
  • Blacklists for XGB model and GRU model. my explaination. The original idea is in the Giba's notebook.

3. Model training

  • XGB: relative targets with MAE. For example, the GAP2 model give prediction mbd_43/mbd_40, the GAP3 model give prediction mbd_44/mbd_40, the GAP4 model give prediction mbd_45/mbd_40.
  • GRU: adjusted mbd with SMAPE loss.
