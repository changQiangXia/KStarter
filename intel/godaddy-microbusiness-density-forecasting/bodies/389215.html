New Last Value Baseline - LB 3.2776 - without adjustment

Starting Feb 20th onward, the public LB is scored using January 2023 predictions and January 2023 ground truth. And Kaggle has released the data for November 2022 and December 2022. Announcement is here. Kaggle updated the public leaderboard rankings on Feb 22th to reflect this (discussion here). Prior to this, public LB was computed using November 2022 predictions and ground truth.

If we use each county's data from December 2022 to predict their January 2023 microbusiness density, we receive SMAPE = 3.2776. Notebook demonstrating this is here. Version 1 shows LB 3.2776. However, this is not the correct new value baseline. The new LB (for 2023) uses new census data in the denominator of the formula microbusiness_density = 100 * active / adult_population than data from year 2022. Therefore we need to adjust our predictions for the new LB. See important note #2 below.

The final private LB will be March, April, May 2023. (Explained by host here) So we need to use the 41 months of provided data which is August 2019 thru December 2022 inclusive to predict these 3 future months. Our submission.csv file will contain rows for November 2022, December 2022, February 2023, and June 2023 but these 12540 = 3135*4 rows will be ignored by Kaggle.

Important Note #1

Our old submission notebooks will not be rerun. Therefore we must train our models using all the new train data and submit a new submission.csv file so that our private LB predictions are the best that they can be.

Important Note #2

Note that we need to adjust our predictions for 2023 to use updated census information. My last value baseline version 1 notebook does not do this but version 2 and later does adjust. The data from December 2022 uses a different census data file than January 2023. This is important because microbusiness density is the ratio of active to adult population. Therefore when we change the value for adult population with a new census file it will affect microbusiness density. This didn't happen when we used last value October 2022 to predict November 2022 (old public LB) because all months in 2022 use the same census file. But all months in 2023 use a different census file than 2022.
