Methodology

Data Used: Only Training Dataset, I tried combining it with kaggleX dataset but CV bearly increased.

Preprocessing and Feature Engineering :

Since, I had participated in a KaggleX challenge with similar dataset I just copied that notebook , which had minimal preprocessing.

  1. Filling missing values with constant value (like 'nan','missing' ,etc)
  2. Some Extractive Feature Engineering from string columns (like 'engine','transmission').
  3. Feature Selection using Noise feature Method.
  4. For Categorical Encoding, a simple LabelEncoder.
  5. Mainly,Target Transformer with StandardScaler()

Hyperparameter Tunning: Used Optuna for few trails.

and Finally, Tunned models were bagged with 200 estimators.

Final Ensemble=0.35*(0.6 * @trupologhelper solution + 0.4 * @docxian)+0.35*(0.2 * @abdmental01 solution+ 0.8 * @aryagokh solution)+ 0.3 * (0.5 * LGB_bag200+0.3 * GB_bag200+0.2 * HGB_bag200)

Post Processing: Predictions were rounded off to nearest multiple of 5.
