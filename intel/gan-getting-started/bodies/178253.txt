Blog

Jason Brownlee provides a numerous number of GAN tutorials. Check here. Here are some Jason tips to stabilize GAN, quoted from here.

- Downsample Using Stride Convolutions
- Upsample Using Stride Convolutions
- Use LeakyReLU
- Use Batch Normalization
- Use Gaussian Weight Initialization
- Use Adam Stochastic Gradient Descent
- Scale Images to the Range [-1,1]
- Use a Gaussian Latent Space
- Separate Batches of Real and Fake Images
- Use Label Smoothing
- Use Noisy Labels
