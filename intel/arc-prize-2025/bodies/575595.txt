ARC Prize 2024 – Competition Page  
First large-scale sequel to the 2020 ARC benchmark – 100 hidden “human-style” tasks.  

2ᵈ Place – “Omni-ARC TTT” – Discussion  @ironbar

Full, beautifully-illustrated paper 👉 Solution Summary — highly recommended!  it will need a seperate discussion post on itself



Per-task test-time training (TTT) on LoRA-tuned Qwen-0.5 B; model both draws &amp; reasons.  

AIRV loop (augment → infer → reverse → vote) beats rotations &amp; colour permutations.  

Generates synthetic train grids to thicken sparse supervision.  

Falls back to 2020 C++ DSL solver for purely symbolic cases (+14 pts).  

Lightweight — runs in ≈9 h CPU-only if GPU unavailable.  

Dev diary: author logged 50 iterations — from few-shot → Omni-ARC (see paper).  


3ʳᵈ Place – “Guided Brute-Force” – Notebook  @alijs1



Library of 120 hand-coded symmetry / flood-fill / pattern functions.  

Grid-search picks first function that satisfies all train examples.  

Heuristics order functions by task metadata to save time.  

700-line pure-Python script still scores 40 pts.  

Blended with icecuber’s 2020 C++ brute solver for the final push.  


4ᵗʰ Place – “Classical DSL ++” – Discussion | Notebook  @williamwu88



2020 DSL / DAG search run deeper thanks to 30 GB RAM.  

Adds CNN &amp; decision-tree modules for colour counts &amp; masks.  

Heavy data-augmentation (rot/flip/diag/colour swap).  

Ensemble voting with “trust-icecuber-first” override.  

Probabilistic model sampling ∝ #unique solves; avoids over-fitting to any solver.  


5ᵗʰ Place – “PoohAI Mega-Ensemble” – Discussion | Notebook  @greylord1996 @gromml @leadnvalidate @samalkubentayeva



Merges six 2020 solvers (DSL, GA, decision-tree, …) plus their own iterative solver.  

Post-filters auto-repair GA errors (extra lines, wrong shapes).  

Brute-forces hidden task order (≤100 submissions + binary search).  

Strategy: “easier to delete bad answers than pick the best one” – keep top-2 attempts.  

Pure-Python orchestrator; C++ cores run in parallel via subprocess.


13ᵗʰ Place – “Scratch-built Transformers” – Discussion | Repo  @zoenguyenramirez



19-token custom Transformer (no external LLM); PyTorch 2.2 / CUDA 12.  

Novel grid positional encoding beats classical sinusoidal.  

Active-Inference / reverse augmentation loop (+27 pts).  

Ensemble of multiple checkpoints via majority vote → 31 pts private LB.  

Full training &amp; submission scripts open-sourced for further scaling.


21st Place – **Re-color pre-processor (+2 pts over IceCuber) – Short report ** @lyrialtus



28 % score by adding one tiny NumPy function to IceCuber.  

recolor_task() remaps colours by pixel-count order when palette is irrelevant.  

Works only for single-test-pair tasks; skips multi-test ones.  

Re-colors both train &amp; test grids, then restores IDs (‒10/+10 trick).  

Zero C++ edits; plugs into IceCuber as a Python pre-step.  

Insight: humans spot colour-irrelevance instantly → cheap gain.  

Author views it as representation learning hint rather than AGI progress.  


34th Place – **LLaMA 3.1 8B + ARC 2020 hybrid (27 pts) – Silver-medal write-up ** @crsuthikshnkumar



Unsloth-finetuned LLaMA 3.1 8B, temperature-swept prompts.  

Generates multiple candidate grids per task; picks best via heuristics.  

Fallback fusion with 2020 winning solver for coverage.  

Prompt injects lateral-thinking cues &amp; rule-learning reminders.  

Token / top-k / temp schedules tuned over many small runs.  

Runs inside 12 h budget on modest compute (single 8 B model).  

Public notebook &amp; paper: explores how far a single LLM + classic solver can go toward AGI.  


Key 2025 vs 2024 differences



Only one submission per task (2024 had two chances).  

Brand-new task set – 2024 heuristics may transfer poorly.  

Fresh task set (no overlap with ’20/’24). Still 12 h runtime &amp; 30 GB RAM. 

We now get 60 hours per week of GPU usage time in Kaggle instead of the usual 30. (Provided we have a Colab Pro or Pro+ account)

We also get access to more powerful L4x4 machines! These machines offer 96GB of GPU memory enabling submissions with much larger models.
