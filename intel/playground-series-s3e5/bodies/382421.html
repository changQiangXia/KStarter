The evaluation metric used in the competition is Quadratic Kappa Metric which measures the agreement between two ratings.

Quadratic Kappa Metric is the same as cohen kappa metric in Sci-kit learn: sklearn.metrics.cohen_kappa_score when weights are set to 'Quadratic'.

Code Snippet for the metric:

 sklearn.metrics  cohen_kappa_score
(cohen_kappa_score(y_true, y_pred, weights=))
