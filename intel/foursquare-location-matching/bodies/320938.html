As we all know, in this competition text data is very diverse and is coming in many different languages. A lot of the times it is helpful to normalize unicode data, so that all data has the same format. It can be easily accomplished using unidecode package:

>>> pip install unidecode
>>> from unidecode import unidecode
>>> unidecode("Café Stad Oudenaarde")
'Cafe Stad Oudenaarde'
>>> unidecode("Göçmen Börek")
'Gocmen Borek'

Unidecode also handles Chinese, Japanese and many other languages, transforming them into common ascii-like format:

>>> unidecode("つじ田 味噌の章")
'tsuziTian  Wei Cheng noZhang '
>>> unidecode("Κυλικείο 4ου ΓΕΛ")
'Kulikeio 4ou GEL'
>>> unidecode("ПроМедика")
'ProMedika'
