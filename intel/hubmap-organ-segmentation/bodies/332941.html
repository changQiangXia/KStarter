my approach follows the NLP method:

  1. collect many stains of PAS, H&E, DAB/H of the target organs (external data)
  2. select a image transformer model for segmentation
  3. pretrain with unsupervised learning (e.g. masked patch prediction, aka 2d image token)
  4. finetune with few-shot supervised learning (kaggle train data + some hand-label data (mainly for DAB/H stain) )
    ㅤ ㅤ
  5. lower priority:
    if I got time, maybe I can explore using pretrain transformer + GAN/diffusion model to generate more data.
