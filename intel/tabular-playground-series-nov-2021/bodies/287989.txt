Hi guys,

I just summarised for my own use some tricks I found for boosting productivity when working with notebooks, sharing it here so you can also enjoy it! 

Hack 1
Multiple cell outputs
I am sure that you know this but by default notebooks cannot output two outputs in the same cell. 
so if you have multiple lines such as "df.head()" and "df.shape" in the same cell. you would see only the last output. 

To fix it: simply add this code to one of your first cells and all cells whatsoever will be fixed.

from IPython.core.interactiveshell import InteractiveShell
InteractiveShell.ast_node_interactivity = "all"

Hack 2
listing out all Variables. 
As simple as it sounds: you want to see all variables you declared and what value they hold? 
Simply write: 

%whos

Hack 3
Printing functions documentation.
If you find yourself in need for reading about some functions documentation, simply write: 

?str

Hack 4
Fixing blur plots
Ever get this feeling that your plots are blurry for some reason? Use the following to fix it: 
%config InlineBackend.figure_format ='retina'

Hack 5
Plugins! notebooks support plugins and some are just "a must"! 
To enable them, simply use: 
! pip install jupyter_contrib_nbextensions
! jupyter contrib nbextension install --system or
! jupyter contrib nbextension install --user

After running and restarting you will find a new option right after "Clusters" named "Nbextensions". Go to that and you will find tons of useful tools to boost your productivity.

Recommended tools:



Hinterland

Live Markdown preview

Code prettify

PrintView

Snippets

highlighter etc


Hack 6
Debugging! Ever with you had a debugger in a notebook? 
As it turns out, you can! 
Just use: %%debug

Hack 7
Useful keyboard shortcuts you want to remember and try using: 



Shift + Enter - Run cell + select next cell

a - Insert cell above

b - Insert cell below

m - Convert the cell to markdown (after your run the markdown cell, you can double -click it to edit)

y - Convert the cell back to code

x - Cut the selected cell(s)

c - Copy the selected cell(s)

v - Paste the selected cell(s)


Hope you find this useful! 
Happy Kaggling ^^
