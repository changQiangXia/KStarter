In this competition, as I said earlier in this post, I was using a hybrid-like model with zero-alpha Ridge (which is LinearRegression, but I used Ridge to tune alpha parameter later, and 0.0 gave me the best result) and trained it on 1-component PCA transformation of fruitset, fruitmass and seeds features in order to make predictions very linear and to make its residuals a bit far from 0. Then I fitted several LGBM and CatBoost models on these residuals using synthetic training data concatenated with original data and evaluating only on synthetic valid data and then weighted their predictions using LADRegression without bias coefficient. These several models are: 



two LGBM models, where first of them is trained on only positive residuals(where residuals less than 0 equals to 0, as relu activation does) and second is trained on only negative residuals (with the same idea), and then prediction is: linear_pred + model_pos_predicted_residuals - model_neg_predicted residuals (this prediction equation is only for this one, but in other the equation is linear_pred+model_predicted_residuals)

the same technique, but with different LGBM depth parameters

train LGBM using polynomial features of bees and clonesize

train CatBoost on the same thing

train LGBM on polynomial features of fruitset, fruitmass and seeds and without bee density and clonesize features

train CatBoost on the same thing

train LGBM on onehot encoded RainingDays and TRange features and also without bee density and clonesize features

train CatBoost on the same thing

train LGBM on 1-component pca of fruitset, fruitmass and seeds features

train CatBoost on the same thing

train LGBM on yield (Note, before we were training models on linear regression residuals) using data without changes

the same thing on CatBoost

blend it using LADRegression!
