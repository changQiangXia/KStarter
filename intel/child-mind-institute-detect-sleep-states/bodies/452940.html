Model Structure

My model consists of three components: feature extractor, encoder, and decoder.

The feature extractor takes the raw waveform(anglez, enmo, hour) and creates a wavegram (like an image).
The encoder (UNet) takes the wavegrame and creates a two-dimensional heatmap.
decoder takes the heatmap and outputs the probability(sleep, onset, wakeup) of an event occurring at each time.
Finally, post-processing is performed to create a submission file.

Each component has the following already implemented.

  • feature extractor
    • CNN
    • LSTM
    • Spectrogram
    • PANNs
  • encoder
    • UNet
  • decoder
    • UNet1D
    • LSTM
    • MLP
    • Transformer

Tips

  1. The evaluation function can be sped up using a binary search. When the number of detections is large, the evaluation index can be calculated tens to hundreds of times faster than the original implementation.
    https://github.com/tubo213/kaggle-child-mind-institute-detect-sleep-states/blob/8bbc09aff9c34f12259d536fd496deaade8ec087/src/utils/metrics.py#L179
  2. Outputting a file other than submission.csv and submitting it will result in an error. In the inference notebook, it is better to leave only the final submission.csv.
