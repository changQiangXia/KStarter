In a previous topic, @aldparis shared his thoughts about the disadvantage of using the median as an evaluative measure. If classification is used, he explained that 50% of correct classification would be enough to achieve a perfect score (MedAE = 0).

I have doubts about the feasability of achieving this perfect score. However, it should be noted that by choosing only 9 categories, 89.5% of the training set values ​​fall within a maximum absolute error range of 0.25. This means that predicting correctly 56% of the test data should be enough to achieve a MedAE of 0.25. (Assuming that the test set is similar to the training set, which it seems to be).
