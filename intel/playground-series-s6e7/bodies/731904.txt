Here is the writeup of our 2nd place solution, focusing on a robust two-step optimization pipeline applied across 18 base predictors.



Key Highlights &amp; Performance



Ensemble Scale: Integrated 18 base predictors (including diverse implementations of LightGBM, XGBoost, CatBoost, FT-Transformer, RealMLP, and HGBC).

LogLoss Optimization: Reduced OOF LogLoss from 0.105495 (Equal Weight Baseline) down to 0.086310.

Balanced Accuracy Boost: Achieved an OOF Balanced Accuracy of 0.950737 (a +0.061605 improvement over raw argmax).




Methodological Pipeline

1. Simplex-Constrained Multi-Class Weight Optimization (SLSQP)

Instead of a standard uniform average, we optimized class-specific weights $W \in \mathbb{R}^{18 \times 3}$ across all 18 base predictors (54 parameters in total) using SLSQP.



Objective &amp; Constraint: Directly minimize OOF LogLoss. Weights are normalized per class inside the objective function, effectively enforcing a simplex constraint (\sum_m w_{m, c} = 1).

Renormalization: The blended class scores are finally renormalized to form valid probability distributions before evaluating LogLoss.

Complementary Strengths: The optimized weights indicate complementary predictive strengths among the base predictors:


ftt_kawamata (FT-Transformer) received the largest optimized weight across all three classes, contributing 71.81% for Class 0, 62.45% for Class 1, and 50.28% for Class 2.

xgb_ovr_kawamata (XGBoost OvR) acts as a strong complementary predictor, accounting for 45.59% in Class 2 and 28.19% in Class 1.


2. Direct Linear Blending

Rather than training an additional nonlinear meta-learning stage (which risks overfitting out-of-fold metadata), we used a direct linear combination of the base predictions, preserving the linear interpretability of the ensemble weights.

3. Metric-Specific Multiplier Tuning (Nelder-Mead)

To address class imbalance and maximize the target evaluation metric (Balanced Accuracy), we tuned class-wise probability multipliers on the full OOF predictions using Nelder-Mead:



Optimized Multipliers: [C_0: 0.124044, \quad C_1: 1.499826, \quad C_2: 1.250181]

Test Application: These multipliers were optimized on the full OOF predictions and then applied unchanged to the test set predictions. No test labels or leaderboard feedback were used for tuning.

Impact: Down-weighting Class 0 while boosting minority classes (Class 1 and Class 2) improved Balanced Accuracy from 0.889132 (raw argmax) to 0.950737.

💡 Strategic Insight &amp; Discussion



Masaya Kawamata — Trust your CV: the CV-LB relation so far


This discussion was the foundational compass for my strategy. By demonstrating that Public LB fluctuations (±0.001–0.002) were purely binomial noise on the minority classes, it convinced us to strictly optimize both our ensemble weights (SLSQP) and class scaling factors (Nelder-Mead) on the full 690k OOF predictions rather than chasing Public LB scores.
