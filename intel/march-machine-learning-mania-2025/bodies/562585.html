  4. Final Submission: Despite the merge bug, the model (k=41) predicted spreads effectively—securing first place.

March Machine Learning Mania 2022 - Women's - 2nd Place Approach

  1. Base FiveThirtyEight Model: Converted 538’s rating differences into probabilities and adjusted early-round matches for more precise outcomes.
  2. Uncertain Match Overrides: Applied Madtown-style thresholds (e.g., 0.36 vs. 0.64) to split close games across two submissions, limiting log-loss near 0.5.
  3. Variance in Predictions: Flipped ~13 matches to contrarian probabilities in each submission, guaranteeing at least one “correct” side to reduce overall log-loss.
  4. Consistent Top Finish: All override setups placed in the top 8, illustrating how strategic probability splitting can markedly improve final standings.

March Machine Learning Mania 2022 - Women's - 3rd Place Solution

  1. 538 Baseline: Started with implied win probabilities from 538’s projections, deriving each matchup’s chance by adjusting for round advancement.
  2. Linear Transformations: Generated ~1,200 small probability distortions (translation/rotation) around the baseline to explore contrarian edges.
  3. Monte Carlo Simulation: Simulated 25,000 tournaments per transformation, selecting the one that consistently placed top 5 across all runs.
  4. Contrarian Edge: Slightly exaggerating probabilities over 0.93 (and discounting near 0.36–0.64) boosted log-loss improvement by ~0.036, securing 3rd place.
