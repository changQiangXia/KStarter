🚀 ArielML: A Python Library for Ariel Transit Analysis (Built for Learning!)

TL;DR: I created arielml, a Python library with GUI tools for exploring the Ariel dataset. It's not groundbreaking science, but it might help newcomers like me understand the data better!

🔗 Repository: https://github.com/jalalirs/arielml

🙋‍♂️ Background (Full Disclosure!)

Hi everyone! I'm not an astronomer, and I'm definitely not an expert in Gaussian processes or exoplanet science. However, I've been following this field as an enthusiast for a while now. While attending the BEACON conference in Iceland, I heard about this competition and thought "hey, this is a great opportunity to practice with real-world exoplanet detection problems - let me dive in!" 🌌

So please take everything I share with a grain of salt - this is very much a learning exercise for me, and I'm sure there are much better approaches out there!

🛠️ What is ArielML?

arielml is a Python library I built to help me (and hopefully others) explore and understand the Ariel dataset. It's heavily inspired by some excellent work from the community, particularly:

  1. NeurIPS: Non-ML Transit Curve Fitting by @vitalykudelya
    📎 https://www.kaggle.com/code/vitalykudelya/neurips-non-ml-transit-curve-fitting/notebook

  2. Ariel 2nd place submission notebook by @jeroencottaar
    📎 http://kaggle.com/code/jeroencottaar/ariel-2nd-place-submission-notebook

  3. Calibrating and Binning Ariel Data by @gordonyip
    📎 https://www.kaggle.com/code/gordonyip/calibrating-and-binning-ariel-data

Important: ArielML is NOT an accurate implementation of these original works! I've simplified, modified, and probably broken things while trying to understand the concepts. The original notebooks are the authoritative sources - mine is just a learning tool!

🎯 Key Features

📊 Data Inspector GUI

The main feature is a PyQt-based GUI that lets you:

  • 🔍 Load and visualize raw sensor data (FGS1 & AIRS-CH0)
  • ⚙️ Step through preprocessing (calibration, binning, spatial aggregation)
  • 📈 Interactive plotting with mouse-over coordinates
  • 🔄 Real-time parameter tuning with immediate visual feedback
  • 📋 Multiple pipeline modes: Preprocessing, Baseline, and Bayesian
    • Note: Baseline pipeline requires both FGS1 and AIRS-CH0 instruments loaded

🧮 Pipeline Implementations

Baseline Pipeline (simplified from the community notebooks):

  • Preprocessing with configurable binning factors
  • Phase detection for transit start/end
  • Polynomial detrending with optimization
  • Single transit depth for all wavelengths
  • Requires both FGS1 and AIRS-CH0 instruments to be loaded

Bayesian Pipeline (very basic):

  • MCMC sampling for uncertainty quantification
  • Gaussian Process detrending
  • Calibration models for bias correction

🎨 Visualization Tools

  • Light curve plots with transit phases highlighted
  • Detector images showing spatial patterns
  • Component analysis plots for preprocessing steps
  • Transit fit visualization with wavelength selection
  • Covariance matrix heatmaps
  • Ground truth comparison when available

Transit Fit Analysis

One feature I'm particularly happy with is the Transit Fit tab that lets you:

  • 🎚️ Wavelength slider: Explore transit depths across the spectrum
  • 📊 Interactive visualization: See original light curve, polynomial fit, and depth measurement
  • 🎯 Phase highlighting: Visual indicators for transit start/end
  • 📏 Depth annotation: Numerical values displayed on the plot
