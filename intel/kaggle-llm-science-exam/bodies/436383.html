Notes

There is a column named source which indicates which dataset each sample came from. Note that some sources only had 4 answers instead of 5. Therefore a random answer in these rows is NAN. Consider filling NAN with empty string, or a random wrong answer, or removing these rows, or adapting these batches to only have 4 choices, etc etc. (Currently i have been using fillna('') and seems to work fine).

Inference

To submit to the competition, we create a second Jupyter notebook. In this notebook, during submit, we load the hidden test data, append Wikipedia context, and use our saved model (from notebook 1) to infer. I published a starter notebook here. We can easily achieve LB = 0.830+ by adjusting the training parameters in notebook 1. Enjoy!

How To Improve

To improve score above LB = 0.830 we have options:

  • improve the trained model (which takes lots of GPU resources outside Kaggle) and/or ensemble with other trained models.
  • improve the retrieval algorithm to provide better context data (which can be done using only Kaggle notebooks)
  • (maybe) analyze the 60k samples and choose a subset for training that is more aligned with train.csv and test.csv
