GPU Speed Up

I was surprised to discover that each new RAG pipeline I added above improved my CV and LB more than adding additional DeBERTa. Therefore I focused on accelerating the speed of RAG pipeline + DeBERTa inference (with the goal of ensemble in mind). I created lots of diverse RAG pipelines and I accelerated RAG with:

  • Use GPU for Faiss
  • Use GPU for TF-IDF with RAPIDS
  • Use GPU (and fp16 on 2xT4) for Sentence Transformers

Regarding DeBERTa, with 2xT4 GPU I was able to infer DeBERTa 4x faster than using 1xP100 GPU. This was accomplished using

  • from torch.cuda.amp import autocast (Note fp16 only speeds up T4 not P100 GPU) for 2x speed
  • import threading where we infer half the test samples on each T4 GPU for 2x speed

Diverse RAGs

The goal of RAG is to search Wikipedia and find text context. My final ensemble used the following diverse RAGs:

  • Find top 5 articles out of 6M Wikipedia using title, key words, first paragraph. Then extract top 20 sentences.
  • Find top 5 sections out of 128k STEM Wikipedia. Then extract top 20 sentences
  • Find top 5 chunks out of 12M Wikipedia 512 token chunks. Then extract 20 sentences
  • Use Question plus Choices to search Wikipedia.
  • Use Question without Choices to search Wikipedia
  • Use Choices without Questions to search Wikipedia
  • Find top 5 sections out of 271k Wikipedia STEM using RAPIDs TF-IDF. Then use paragraphs
  • Find top 5 sections out of 271k Wikipedia STEM using Sentence Transformers. Then use paragraphs.

Question Drop Out Augmentation

My best DeBERTa-v3-large was trained on my 60k dataset and used Question Drop Out Augmentation. During training, samples typically use Question + 5 Choices to locate context. Then the DeBERTa is trained with context + question + 5 choices. The idea of Question Drop Out Augmentation is that randomly 50%, we only use 5 Choices to locate context. And the DeBERTa is trained with context + 5 choices without seeing the question.

Using Question Drop Out Augmentation achieved my best MAP@3 loss for 200 train sample of 0.470. This single model achieved LB 0.904 in notebook here.

Choice Permute TTA

Another interesting technique that I observed was Choice Permute TTA. When extracting context we can concatenate question + choice A, B, C, D, E. Using sentence transformers, this gets context. If we use concatenate question + choice E, B, A, C, D where we randomly permute the choices, then sentence transformer extracts different context. If we infer both context with DeBERTa and ensemble the two sets of logits, we observe a boost in CV LB!

Another 1.6x Speed Up Trick!

We can achieve another 1.6x Speed Up for a total of 7x speed up when comparing 2xT4 vs. 1xP100 using Drop 2 Wrong Choice. After we infer a few DeBERTa, we can use the result to determine the 2 wrong choices for each test question. Then we can infer only the 3 best choices for a 5/3 = 1.6x speed up. (i.e. we only generate and infer tokens for top 3 choices). We set the prediction for unused choice 4 and 5 as the same logit as choice 3. Then we have 5 logits and we can ensemble this with our previous inference.
