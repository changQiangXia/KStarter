The key finding

Many people have likely noticed that flip/rot90 augmentation doesn't work well on this dataset.

My guess is that during the conversion of polygon annotations to binary masks, the leftmost point is not included while the rightmost point is, causing a misalignment between the image and the mask.



original


img:    [0, 128,   128,    3,   4, 5, 6]

mask: [0, 255a, 255b, 255pad, 0, 0, 0]

normal flip that does not work


img: [6, 5, 4, 3,      128,  128,    0]

mask: [0, 0, 0, 255pad, 255b, 255a, 0]

consistent flip should be


img: [6, 5, 4, 3, 128,  128,    0]

mask: [0, 0, 0, 0, 255b, 255a, 255pad]


I tried two solutions to address this issue.

solution 1, train with misaligned (img ,mask)



training


img: normal flip

mask: consistent flip

inference


flip tta: normal img flip -&gt; predict -&gt; consistent mask flip


training/test time augmentation is a bit tricky in this case.

solution 2, train with aligned (img, mask)



training


shift img by +0.5 pixel

inference


shift img by +0.5 pixel


training/test time augmentation is as normal in this case.

Both solutions worked. For simplicity, I chose solution 2. I use the following code to apply resize512&amp;shift1

img_affine_matrix = np.array([[2.0, 0.0, 1.5], [0.0, 2.0, 1.5]], =np.float64)
img = cv2.warpAffine(
    img,
    img_affine_matrix,
    (512, 512),
    =cv2.INTER_LINEAR,
    =cv2.BORDER_CONSTANT,
    =0,
)


Note that you need to calibrate M for warpAffine. So it's 1.5 in the final affine matrix.

 calibrate(M):
    
    [:, ] += M[:, ] * . + M[:, ] * . - .
     M
