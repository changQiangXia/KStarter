Solution overview of my part

Models

I use 5 models as follows:

  • Single frame model 1: EfficientNetV2L + UNet, 512x512, crop to 480x480 for training.
  • Single frame model 2: EfficientNetV2L + UNet, 768x768, crop to 512x512 for training.
  • Multi frames model 1: EfficientNetV2L + customized 3D UNet 1, 256x256, use all 8 frames.
  • Multi frames model 2: EfficientNetV2L + customized 3D UNet 2, 512x512, crop to 480x480 for training, use 5 frames only.
  • Multi frames model 3: EfficientNetV2L + customized 3D UNet 3, 512x512, crop to 480x480 for training, use 5 frames only.
    (Best single model, late submission, private LB: 0.71443, public LB 0.70803)

About the customized 3D UNet

  • Apply the same encoder(backbone) to each frame
  • Combine the encoder outputs by Conv3D at each level. ConvLSTM2D also works, but it's slower.
  • Use UNet as decoder to get the final output.

Augmentation

  • Filp LR, Filp UD, Rotate 90 (for TTA8)
  • Noise by channel, noise by pixel
  • Random dropout frame (multi frames model only)
  • Random crop

At the early stage of the competition, I noticed that if I don't use flip and rot90, the model will be overfitting quickly. But if I use the flip and rot90, the result became worse. I was confused for a long time. Finally, I found the reason. As mentioned in other discussions, The image and the mask are not aligned. The mask is a littel bit shifted to the bottom right. So if we use flip or rot90, we need to align them. The magic number for me is: x = 0.408, y = 0.453.

Tried but not worked:

  • Random rotate
  • CoarseDropout
  • Dropout by channel

Target and loss function

I used 2 targets:

  • Target 1: Sigmoid to 1 channel. weight: 75% (human_pixel_masks.npy)
  • Target 2: Softmax to 5 channel. weight: 25% (human_individual_masks.npy. 0 for not contrails, 1 for 25% of labelers, 2 for 50% of labelers, 3 for 75% of labelers, 4 for 100% of labelers)

The loss function is weighted binary cross entropy + dice loss.
And use Lion for optimizer.　(Lion: https://github.com/keras-team/keras/blob/v2.13.1/keras/optimizers/lion.py)

Prediction

  • Ensemble by 5 models with TTA8 (flip LR, flip UD, rotate 90)
    The TTA8 is very important. It can improve the score by 0.005~0.01.

The best result is public LB: 0.71243, private LB: 0.71756. But unfortunately, we didn't choice it as our final submission.

Other experiments

  • I tried to use all bands, which can give a improvement of 0.000x. But it make the submission too complex, and take too much time. So I didn't use it in the final submission.
  • UNet + Tranformer (256, 128: UNet, 64, 32: Transformer). Using the trasformer to get the information of other frames. It works but not better than UNet. Maybe because the transformer is not pretrained.
