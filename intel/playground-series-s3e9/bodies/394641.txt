In this competition, I used LinearRegression based on Component features, then added its predictions as a features, also, I added some additional features like rmse of the model, and length of training data to help my model (XGBoost in this case) understand the linear model more better (like how good our model is? How rmse metric is accurate(based on training length feature?). This approach I showed in [my notebook]
(https://www.kaggle.com/code/demko1/s3e9-using-features-based-on-linearregression) more detaily. But with a few differences: 




First off, I realised my mistake in notebook. The length feature, must show the amount of training data, but in test set lengths feature shows amount of test set instead of training set, from that, despite the cv score scores a good result, the predictions will be bad, because test set and train set are not similar


I fixed the second mistake in my notebook. When I cut linear preds where AgeInDays value count less than 20 to make model better handle NaN values, I did it only in train set, from that, since train set and test set aren’t similar, test predictions won’t be good. So, I also cut that in test set too.


I added some features based on Linear Regression like: 



intercept of LinearRegression

minimum value of LinearRegression coefficients

maximum value of LinearRegression coefficients

mean value of LinearRegression coefficients

std value of LinearRegression coefficients

Target Encoding based on AgeInDays


Then, I optimised XGBoost hyperparameters using optuna, gpu acceleration, 10 000 n_estimators, 300 early_stopping_round
