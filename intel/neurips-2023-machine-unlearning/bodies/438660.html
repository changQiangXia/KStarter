1. A Survey of Machine Unlearning
    • Code: https://github.com/tamlhp/awesome-machine-unlearning
    • Summary: Computer systems house vast personal data, leading to privacy concerns as machine learning (ML) models can "remember" this data. Regulations now champion "the right to be forgotten", demanding user data be deleted from databases and ML models. However, present ML models may still retain old data, necessitating the concept of machine unlearning to erase specific data. Current efforts in machine unlearning lack uniform frameworks. This paper provides a detailed overview of machine unlearning's principles and applications and offers code resources.
  2. Machine Unlearning
    • Code: https://github.com/cleverhans-lab/machine-unlearning
    • Summary: Once data is shared online, revoking access and deletion become challenging, especially with machine learning (ML) models which may "memorize" the data, risking user privacy. Addressing this, we introduce SISA training—a framework that facilitates faster unlearning by minimizing the impact of individual data points during training. Primarily benefiting stateful algorithms, SISA reduces the time and computational costs of unlearning. Using priors on anticipated unlearning requests can further optimize the process. Evaluations show SISA improves unlearning speed significantly across various datasets, with minimal accuracy loss in complex tasks. This aids in effective machine unlearning data governance.
  3. Unlearnable Examples: Making Personal Data Unexploitable
    • Code: https://github.com/HanxunH/Unlearnable-Examples
    • Summary: The abundance of freely available online data has fueled deep learning but brings about privacy issues due to unauthorized personal data use in commercial model training. This paper investigates whether data can be rendered unlearnable for deep learning models. We introduce "error-minimizing" noise, a subtle alteration undetectable to humans, which convinces the model there's nothing to learn from certain examples. This noise's effectiveness is validated in multiple scenarios, including a face recognition case study. Our research marks a pivotal move towards preventing personal data misuse in deep learning models.
  4. Machine Unlearning of Features and Labels
    • Code: https://github.com/alewarne/machineunlearning
    • Summary: Removing data from machine learning models is complex, especially when sensitive data inadvertently gets included. While existing machine unlearning methods can delete individual data points, they struggle with larger data groups. This paper introduces a novel method to unlearn both features and labels. Utilizing influence functions, our technique updates model parameters in a streamlined manner, addressing data leaks and privacy concerns. For models with specific loss functions, our approach offers guaranteed unlearning. In models with different loss types, our method is shown to be efficient and faster than alternatives.
  5. Sequential Informed Federated Unlearning: Efficient and Provable Client Unlearning in Federated Optimization
    • Code: https://github.com/Accenture/Labs-Federated-Learning
    • Summary: Machine Unlearning (MU) aims to ensure the complete removal of specific data from training. Federated Unlearning (FU) extends this to removing a client's data from federated training. Current FU methods lack scalability and theoretical validation of their effectiveness. This paper introduces Informed Federated Unlearning (IFU), an efficient FU method with quantifiable results. IFU determines the best point to restart federated learning upon an unlearning request, using a randomized perturbation mechanism. It also caters to sequential unlearning requests. Tests show IFU is more efficient than basic re-training and other FU methods.
  6. Zero-Shot Machine Unlearning
    • Code: https://github.com/ayushkumartarun/zero-shot-unlearning
    • Summary: Modern privacy laws allow individuals the "right to be forgotten" by various entities, which, in the context of machine learning (ML), means removing data from both storage and ML models. This has birthed the need for "machine unlearning". While most methods depend on existing data or metadata for unlearning, this paper introduces "zero-shot machine unlearning" which unlearns without access to any original training samples. Two novel solutions are proposed based on error management and knowledge transfer to maintain model efficacy after unlearning. This method offers defense against potential data attacks. A new metric, the Anamnesis Index, is introduced for evaluating unlearning quality. Experimental results on deep learning models are promising.
