Topic #275669: 1M rows: ...how to read in only some of the data

This month the train.csv occupies 2.32G and has 1,000,000 rows. 

I would not be at all surprised in one could make quite a lot of progress initially only working with, say, only 10% of the training data. A very simple trick one can use is to only read in the first nrows of data, for example


  
train_data = pd.read_csv('train.csv', nrows=100000)


or if one wishes to to read in a different chunk one can use skiprows before nrows:


  
train_data = pd.read_csv('train.csv', skiprows=range(1, 100001), nrows=100000)


(Note that we start the skiprows from position 1 in order to keep row 0, which has the header data with the feature names).

One can also reduce the RAM usage along the way by deleting unwanted dataframes, large arrays etc.  using garbage collection:


  
import gc
  del unwanted_dataframe
  gc.collect()


For example, when one has finished fitting, or 'training', ones model, the training data is no longer required and can be deleted. This will free up memory to then go ahead and read in the test.csv file (which is also large),  make the predictions, and finally create the submission.csv file.

When you are happy with your prototype, and you really do want to access all of the data, may I heartily recommend  the "Tutorial on reading large datasets" written by Vopani, introducing alternatives such as Dask, Datatable and the the Rapids cudf, which harnesses the power of the GPU's, and all affording considerable speedups w.r.t. pandas.  

All the best,
