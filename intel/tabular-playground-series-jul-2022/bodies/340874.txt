As the competition comes to a close, I thought it would be a good idea to review what we've learnt in kaggle's first unsupervised competition. 



The Rand Index measures how well we cluster pairs of data points. (ref1 Gunjan Dhanuka).

The Adjusted Rand Index is a corrected-for-chance version of the Rand Index that takes into account how difficult a clustering problem is (ref1 Towhidul.Tonmoy, ref2 Marília Prata, ref3 AmbrosM).

Scaling is necessary as many clustering algorithms compare the distance between data points. (ref1 by Michael Mellinger)

The Elbow Method allows us to estimate how many clusters are present in the data (ref1 C4rl05/V, ref2 Samuel Cortinhas).

Dropping features that don't separate the clusters speeds up training time and reduces the chance of overfitting to noise (ref1 des., ref2 AmbrosM).

The Shapiro-Wilk Test and the Poisson Dispersion Test are ways of checking if the data is Normally or Poisson distributed, respectively. (ref1 Francisco Javier Gallego, ref2 Samuel Cortinhas).

Dimensionality reduction techniques like PCA, t-SNE and UMAP can give insight into the structure of the data (ref1 vwood, ref2 egrundman).

Common clustering algorithms include k-Means, Mean Shift, DBSCAN, Gaussian Mixture Models and Agglomerative Hierarchical Clustering (ref1 The Devastator).

Gaussian Mixture Models (GMMs) can be implemented via the Expectation-Minimisation (EM) algorithm (ref1 Samuel Cortinhas).

Ensembling clustering predictions is hard mainly due to memory constraints. There were many approaches tried in this competition. (ref1 The Devastator, ref2 Laurent Pourchot, ref3 vwood).

The problem can be converted into a supervised one by using pseudo-labels and a classifier like BayesianGMMClassifier. (ref1 ricopue, ref2 Outatime, ref3 Cabaxiom).
