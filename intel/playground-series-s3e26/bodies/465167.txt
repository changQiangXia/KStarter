In this Kaggle competition, I employed a sophisticated ensemble learning technique combining LightGBM and XGBoost classifiers. This approach was instrumental in securing the 7th place. Below, I outline the key components of my methodology, including data preprocessing, feature engineering, model optimization, and ensemble strategy.

1. Data Preprocessing and Feature Engineering:



Label Encoding: Custom class LabelEncoding was implemented to convert categorical features like 'Drug', 'Sex', etc., into numerical format, ensuring compatibility with ML models.

Feature Creation: New features, such as 'date_of_diagnosis' and 'diseases', were engineered from existing data to enhance the model's predictive power.

Data Splitting: The dataset was split into training and testing subsets, with stratification to maintain the proportion of target classes.


2. Model Optimization:
-Optuna for Hyperparameter Tuning: Optuna, an open-source hyperparameter optimization framework, was employed to fine-tune the parameters of LightGBM and XGBoost models.



Custom Objective Function: For each model, a custom objective function was defined to optimize the negative log loss, ensuring a robust model performance.


3. Ensemble Strategy:
-Voting Classifier: An ensemble of LightGBM and XGBoost models was created using the **VotingClassifier ** from scikit-learn. This approach combined the strengths of both models, improving overall accuracy and robustness.
-Soft Voting: The ensemble used soft voting, which takes the probability estimates from each classifier and averages them to predict the final output.

4. Results and Submission:
-Performance Evaluation: The ensemble model was evaluated using the log loss metric on the test dataset.

-Prediction and Submission:  Predictions were made on the unseen test data, and results were formatted into a submission file following the competition guidelines.

Conclusion:
The combination of LightGBM and XGBoost with a focus on hyperparameter optimization and feature engineering proved to be a highly effective strategy. This approach not only provided robust predictions but also showcased the power of ensemble techniques in tackling complex machine learning problems.
