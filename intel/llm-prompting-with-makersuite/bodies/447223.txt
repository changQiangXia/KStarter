If anybody doesn't know how, there are examples in the prompt gallery for designing Text, Data, and Chat prompts in Maker Suite. You can preview and edit them in Maker Suite. For examples, visit this link.

Additionally, there are free short courses on the deeplearning.ai website that cover prompt engineering. While these courses may not be directly related to Maker Suite, they encompass many aspects of prompting.

Also you can check Google Cloud Generative AI repository for palm api notebooks.

Below are some results from Bard for prompt engineering:

OpenAI's Prompt Engineering Guide: This guide provides a comprehensive overview of prompt engineering, including its principles, best practices, and examples. link

PromptHero: A website that allows you to search and browse prompts for a variety of language models, including ChatGPT and Bard. link

PromptVine: A curated collection of prompt examples for ChatGPT. link

Awesome Prompt Engineering: A GitHub repository that contains a collection of resources on prompt engineering, including papers, guides, and code. link

Prompt Papers: A GitHub repository that contains a collection of papers on prompt-based tuning for pre-trained language models. link

OpenPrompt: An open-source framework for prompt learning. link

Prompt Engineering for ChatGPT: A Coursera course that teaches you how to use prompt engineering to build applications with ChatGPT. link

ChatGPT Prompt Engineering for Developers: A DeepLearning.AI course that teaches you how to use prompt engineering to build applications with the ChatGPT API. link

AI prompt library: Discover AI prompts to elevate your work. Get more out of ChatGPT, GPT4, Bard, Claude, and more with these prompts. link
