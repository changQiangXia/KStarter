After evaluating more than 200 submissions, we are excited to announce the winners of the LLM Prompting with MakerSuite Competition! Thank you to everyone that shared your unique and creative ideas for prompting LLMs, and to those that helped to share best practices.

NOTE: we will update all of the links in this document as soon as the prompts themselves are made public and added to the MakerSuite Prompt Gallery.

Developer Tools Category Winner: @ajaysadhu

This prompt can be used to make corrections to misformatted YAML data. The approach that the author used was to provide the general instructions as a system prompt, and then to provide multiple input/output examples where the inputs lack formatting all together but the outputs are properly formatted YAML. The method was tested multiple times and was shown to consistently improve the formatting.

Data Science Tools Category Winner: @elanderos

This prompt prepares the model to respond to basic questions about data science. It specifies to both explain the underlying concepts and to provide code examples as well. By conversing with the model students can ask questions that they might be embarrassed to ask otherwise, and they can quickly get pointed in the right direction.

Education and Interactive Tutors Category Winner: @hoangpham51

This prompt can be used to generate short quizzes (along with some preliminary evaluation criteria) to test one's knowledge on any arbitrary subject. The prompt specifies that responses should be formatted as JSON where each question is followed by an "answer matrix" (that can be used to evaluate the completeness and accuracy of the response) as well as an example answer, and new questions can be generated by simply redefining the input values.  

Utilities for Everyday Life Category Winner: @ankushmandal

This prompt can be used to quickly summarize the outcome of sales calls and support conversations. The prompt specifies that responses should provide a detailed explanation of the reason why a given customer was either interested or not interested in purchasing the product. To summarize your own customer interactions, you can replace the conversation transcript with your own input values.

Well Explained Reasoning Category Winner: @abprime5

This prompt** **instructs the model to evaluate the strength of ideas, to brainstorm potential advantages and disadvantages of a given approach, and to recommend alternative solutions. By chatting with a model that has been prompted in this way, you can find a helpful partner for brainstorming new ideas. 

Storytelling and Interactive Games Category Winner: @mvoulo

This prompt can be used to generate new Dungeons &amp; Dragons campaigns. You provide the name for your fantasy world as an input and then the model responds by describing the world, the goals of the campaign, and a variety of different adventures to partake in.

Other Ideas Category Winner: @dineshctech

This prompt can be used to generate self-help advice for individuals encountering adversity. A description of the adversity encountered and a description of the group being helped are used as inputs for the model, which then responds by providing a list of proactive solutions and additional support resources. 

Great work everyone!

The Kaggle Team will reach out to the winners with instructions on how to collect their prizes.
