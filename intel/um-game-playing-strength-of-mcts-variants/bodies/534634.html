• Use GroupKFold for cross validation because test set is composed with new games
  • There are 2 text columns, tried to use transformer models to extract signal but I failed, I think the best approach is to use tabular models and focus on categorical columns. I still think we can extract more signal out of the text columns by using different approaches, maybe this will be one of the keys of the competition.
  • I have not tried a DNN (MLP or similar), but I believe it could be nice for blending with boosting models
  • My best RMSE CV using StratifiedGroupKFold is 0.4092, and a LB of 0.428. Something really intresting is that I have another experiments with exactly the same code, the only thing I change was the seed and for that experiment the RMSE CV was 0.4095 but LB was 0.430. This tell's me to not trust LB so much, LB score changes 0.002 just by changing the seed of the model.
  • Because we can generate more data using the host code, I was wondering how it could benefit my model. Therefore insted of using 5 folds (80% of the data is for training) I used 10 folds (90% of the data is for training). The RMSE CV was 0.4095 so this could mean generating more data does not guarantee a better model (can't be sure about this, but at least I would first focus on building strong models with the data that we currently have).
  • There are a lot of columns that don't have any signal, actually if I train my model with 700 features compared to the same model that is trained with 200 features the CV is almost the same. Of course we need to take into account hyperparammeters and others, but at least this tell me that the signal is in a fraction of the features.
  • I tried some feature engineer, some of it improve my score slightly but most of them failed to improve CV, I think feature engineer is another key for this competition, especially understand how we can extract relevant feature from the games that generralize throught a big percentage of the games.
