PluvIA with Gemma

PluvIA is an offline-first mobile application using Gemma 3n to provide vulnerable communities with real-time flood prediction

Project Description

PluvIA is an offline-first, multimodal mobile application designed to assist communities vulnerable to urban flooding. This solution addresses the critical need for timely and reliable flood information in areas with limited connectivity and infrastructure.

The app uses Gemma 3n to power a multimodal and multilingual assistant. This AI assistant provides users with actionable guidance and answers questions about nearby flood risks, even when there's no internet connection. PluvIA's core features include a map-based interface to visualize flood-prone areas, proactive notifications based on three-day weather forecasts, and a secure system for managing emergency contacts and addresses.

The solution's architecture combines a Flutter mobile application with a robust backend system that uses n8n for workflow automation and EPA SWMM 5 for hydrological modeling. This backend generates and stores flood predictions, which the app then caches locally. By processing all AI interactions on the device, PluvIA ensures user privacy and low latency, making it a powerful and accessible tool for disaster preparedness. Though initially developed as a proof of concept for Campina Grande, Brazil, the system is designed to be globally scalable and adaptable.
