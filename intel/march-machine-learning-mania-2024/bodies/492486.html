This submission used an unconventional but simple approach to a stats-driven machine learning contest. It built an ensemble of binary text classifiers with encoder models (i.e. BERT). This model was then used to predict the probability of Team 1 beating Team 2. txtai was used to train the text classification models.

All historical games had the following text generated for training (see below for the Kentucky vs. Oakland 1st round game). 

NCAA Tournament Matchup:

This text shows the matchup, seeds, team records, coaches, conferences and matchup stats. Box scores were used to generate simple ratings for all historical and current year data. Then for each matchup between Team 1 and Team 2, a ratio of each stat is calculated as (Team 1 Value) / (Team 1 Value + Team 2 Value).

The idea here is to generate a variety of tokens to help the text classifier pick up clues on what leads a team to win or lose. Perhaps a powerhouse program, coach or conference boosts (or decreases) a win probability. Perhaps it's a certain stat ratio.

A separate model was trained for the men and womens competition. The same text format was then used for all current year matchups. The prior submission file format was then generated and used to simulate 100K brackets per competition.

The last step was finding a 0/1 1st round game to build two separate submissions. One submission had Florida winning the 1st round at 100% probability and the other had Colorado at 100%. This strategy added a score boost but it would have really boosted the final score had Colorado beat Marquette. In hindsight, if I had instead picked the Texas Tech / NC State game, it would have had quite a significant boost (This would have resulted in a score of 0.05781 and 27th place).

All in all, while this methodology is simple, it's quite effective. The model could have certainly scored much closer to the top if one or two really close games went the other way (LSU beating UCLA in the womens tournament had the most severe penalty for me). I'm sure we can all say that though 😀. That's what makes this competition so much fun. While we can build an effective model, there is so much luck involved.
