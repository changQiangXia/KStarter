Logistic Regression - Nvidia cuML

My favorite model was my logistic regression models (code shared here). There are two versions. In version 1, we create every pair of features and target encode these new columns. For pairs, this is 78 features. TE is probabilities, so next we convert these columns to log odds (i.e. logits). Then from each column, we create 3 columns [x, x^2, x^3]. Lastly we fit Nvidia cuML logistic regression (with column standarization) on these 234 features. For version 2, we create every triplet of features and target encode. Then convert to logits and make x, x^2, x^3. This is 858 features. Lastly we fit Nvidia cuML logistic regression. Below we show a diagram without pairs nor triplets and without x, x^2, x^3:

This model was important and powerful in my final ensemble because the features (in this competition) had limited interaction with each other. Using logistic regression allowed us to control how much interaction we wanted our model to utilize. Furthermore, this model was diverse from all published notebooks (and ensembled well with public notebooks).

PyTorch MLP - Nvidia GPU

My second favorite model was my custom PyTorch MLP. For each column, we treat it as categorical and create embeddings in our MLP. We also merge the original dataset with tmp = orig.groupby(COL)[TARGET].agg(STATS). For STATS, we use mean, median, std, skew, count. We treat these stats as categorical and create embeddings for them too. We concatenate all the embeddings, then feed into layer of dimension 512, then 256, then a single output neuron with smoothed BCE loss.

UPDATE - Post Comp Analysis

It is helpful to review our solutions after a competition ends and ask, "How could I have done better?". Personally, I was surprised that my strong ensemble CV score did not perform better on the private LB.

I have reviewed my models and I believe that my Logistic Regression v2 model's CV score is leaky and over optimistic. In this model, after creating all triple pairs of features, I compute target encoding outside the KFolds instead of nested inside the KFolds. Often logistic regression models do not overfit, but with this model we have 858 features after creating all triples and then using x, x^2, x^3. With so many features, the possibility of overfitting becomes real and we should be careful to perform target encoding correctly nested inside our KFold.

When I remove this model from my ensemble and just use an equal weighted ensemble of the remaining 5 models, the CV score is 0.95581 and the private LB is 0.95534 top20 finish.
