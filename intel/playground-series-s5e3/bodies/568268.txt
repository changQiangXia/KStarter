Linear Models like SVC

Since the data is small, using simple models with bias (like linear models) will help avoid overfitting the train data and generalize well to test data.

Non-Linear Features

One technique to help linear models perform a little better is to carefully control adding some non-linear terms to our linear model.

I publish a starter notebook showing how to add some non-linear interaction features to a simple Linear SVC model using Forward Feature Selection here

Enjoy!
