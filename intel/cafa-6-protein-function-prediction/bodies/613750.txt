Looking back at my CAFA5 submissions, one of my biggest oversights was completely ignoring taxonomic information in my modelling approach. Let me explain why taxonomy matters and how you can easily incorporate it.

Taxonomy 101: It's a Hierarchical Graph

Biological taxonomy organises life into a hierarchical tree structure 

 → Phylum →  →  →  → Genus → Species


Just as GO (Gene Ontology) terms form a directed acyclic graph in which terms inherit from parent terms, taxonomy creates natural hierarchies in which organisms share features with their ancestors.

Why This Matters for Protein Function Prediction

Close relatives, similar proteins, similar jobs, conserved domains, shared partners, analogous pathways. Useful prior, never a guarantee. 

Setting Up TaxonKit

Before you can use TaxonKit, you need to download the NCBI taxonomy database:


!wget ftp://ftp.ncbi.nih.gov/pub/taxonomy/taxdump.tar.gz


!tar -xzf taxdump.tar.gz names.dmp nodes.dmp delnodes.dmp merged.dmp


TAXONKIT_DIR=
 -p 
 names.dmp nodes.dmp delnodes.dmp merged.dmp 


Using TaxonKit: A Quick Example

Once set up, extracting taxonomic lineages is simple:

 3702 \
| taxonkit lineage \
| taxonkit reformat -f  \
|  -f3


Output:

Eukaryota - Streptophyta - Magnoliopsida - - - Arabidopsis - Arabidopsis thaliana


What's Happening Here?



Input: NCBI Taxonomy ID (3702 = Arabidopsis thaliana)

taxonkit lineage: Fetches the full taxonomic lineage from the database

taxonkit reformat: Formats it with placeholders:


{d} = Domain

{p} = Phylum  

{c} = Class

{o} = Order

{f} = Family

{g} = Genus

{s} = Species
