This looks like it will be a really great competition. I'm looking forward to it. I noticed that the data is quite large ~18GB and in CSV format. This can be an issue when reading in a kaggle notebook that only has 16GB of ram. To help out I've created a dataset with the training data in parquet format. Parquet files are much faster to read in for datasets of this size. It has both:



The entire training set as train.parquet (18GB -&gt; 5GB) loads in &lt; 1min.

The training data split by the 3579 unique investment_ids

train_low_mem.parquet The entire training set with optimized dtypes for low memory use. (18GB -&gt; 3.5GB) loads in ~30 seconds.


The dataset can be found here: https://www.kaggle.com/robikscube/ubiquant-parquet

Example notebook here. You can load in subsets of columns with parquet easily too: https://www.kaggle.com/robikscube/fast-data-loading-and-low-mem-with-parquet-files/

Hope it helps.
