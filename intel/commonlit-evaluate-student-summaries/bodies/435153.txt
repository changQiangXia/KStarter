Topic #435153: Offline pip install

I see people sharing info on how to install packages in notebooks without internet connection, but they use fancy ways instead of using pip options. Here is how to pip install offline using pip options.

I demonstrate it with the sentence_transformers package in this notebook. You can add this notebook as a data source to get sentence-transformers run in your notebook.

The method is rather straightforward and can be used for any pypi package.

First, start a notebook and run this in your first cell. In this example I chose sentence-transformer as name, but you are not forced to use the same name as the package you download in it.

After the first line add all the packages you are interested in, one per line. Here I only put one package, sentence-transformers.

%%writefile requirements.txt
sentence_transformers


Then download the package(s) in a second cell:

! python -m pip download --destination-directory . -r requirements.txt


And save your notebook. This will store everything pip requires in the output of the notebook.

You can then add the saved notebook as a data source for your own notebooks.  

To use the  downloaded packages simply add this in a cell in your notebook. Replace the sentence-transformers name with the name of your data source notebook name.

! python -m pip install --no-index --find-links=..//sentence-transformers -r ..//sentence-transformers/requirements.txt
