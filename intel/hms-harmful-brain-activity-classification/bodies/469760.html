Magic Formula

Exciting news everyone. I think we found the magic formula to convert EEG waveforms into Kaggle Spectrograms.

LL Spec = ( ( - F7) + spec( - T3) + spec( - T5) + spec( - O1) )/4
LP Spec = ( ( - F3) + spec( - C3) + spec( - P3) + spec( - O1) )/4
RP Spec = ( ( - F4) + spec( - C4) + spec( - P4) + spec( - O2) )/4
RL Spec = ( ( - F8) + spec( - T4) + spec( - T6) + spec( - O2) )/4

The trick is that we need to average four spectrograms to produce the LL (i.e. Left Temporal Chain) single spectrogram instead of combining Fp1, F7, T3, T5, O1 into a single waveform and computing a single spectrogram. If we combine waveforms first with W = (Fp1 - F7) + (F7 - T3) + (T3 - T5) + (T5 - O1) then this reduces to W = Fp1 - O1 and it doesn't use information from F7 , T3, T5. But the above magic formula does use information from all EEG waveforms.

History

One week ago, we started a discussion here to determine how the Kaggle spectrograms were made. Kaggle users @seshurajup and others have been active and helpful in this conversation. I tried various ways to combine the 19 EEG waveforms into the 4 spectrograms LL, LP, RL, RP. I have finally created spectrograms that achieve a better CV and LB score than the Kaggle spectrograms!

Kaggle Dataset

The new EEG spectrograms using the Magic Formula have been uploaded to a Kaggle dataset here. We can attach this Kaggle dataset to our future Kaggle notebooks to boost our CV scores and LB scores!

If working offline, we can download one 7.5GB Python dictionary file that contains all 17089 EEG spectrograms with the command: 

kaggle datasets download -f eeg_specs.npy cdeotte/brain-eeg-spectrograms

And we can download all of Kaggle spectrograms in one 2.5GB Python dictionary that contains all 11138 Kaggle spectrograms with command:

kaggle datasets download cdeotte/brain-spectrograms
