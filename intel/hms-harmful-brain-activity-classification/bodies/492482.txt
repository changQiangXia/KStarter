Understand Test Data - What is Competition Task?

The task in this competition is to predict annotator opinions. By reading the host's paper here, we learn that there are 119 overall annotators in train data and 20 expert annotators in test data. The paper shows the average Seizure prediction from 119 annotators is 18.8% whereas the 20 experts are less likely to classify as Seizure and their average is 1.5%. 

Wow, this is a big difference therefore we need to train our models with expert opinions instead of overall opinions. We can locate the expert annotators in the train data with the filter expert annotators = train.loc[train.vote_count&gt;=10].

Which Features Do Annotators See?

From the paper we see that the annotators see 2D spectrograms and 2D plots of waveforms. So let's input 2D spectrograms and 2D plots of waveforms into our models. (Also inputting 1D raw waveform helped too).

Train 3 Separate Models with Vote&gt;=10

First we train 3 separate models using train data with vote_count &gt;= 10 (i.e. the expert annotator opinions). 



One model receives 2D spectrograms (created from EEG) as input and uses tiny_vit_21m_512 to classify into 6 targets. 

Second model receives 2D matplotlib plots of the montage waveforms converted into a 2D image and uses tiny_vit_21m_224 to classify into 6 targets. 

And third model receives 1D raw time series waveform and uses EegNet-1D here to classify into 6 targets.






Pseudo Label Vote&lt;10

Using our 3 single models above, we pseudo label the train data with vote&lt;10. We set the new labels as new_label = 0.1 * old_label + 0.3 * model1 + 0.3 * model2 + 0.3 * model3.

Build One Mega Model and Train with Vote&gt;=10 plus Pseudo Vote&lt;10

We load our 3 pretrained models above and remove the 3 heads. We combine them into one model, concatenate the final embeddings and add 1 new head. Then we train with 2x copies of vote&gt;=10 data concatenated with 1x copy of vote&lt;10 with pseudo data. (Note the 2D spectrogram model above actually trains with both 10 sec spectrograms and 50 spectrograms in one image as depicted below):

More Details

To successfully accomplish the above and achieve single model Gold Medal Hooray!, there are many small details. Here are some:




Preprocess all raw waveform with MNE library 

     mne.filter import filter_data, notch_filter
    sample = data.T[[0,4,5,6, 11,15,16,17, 0,1,2,3, 11,12,13,14]]\
             - data.T[[4,5,6,7, 15,16,17,18, 1,2,3,7, 12,13,14,18]]
    sample = notch_filter(sample.astype(), 200, 60, =32, =)
    sample = filter_data(sample.astype(), 200, 0.5, 40, =32, =) 
    sample = np.clip(sample,-500,500)
    sample = np.nan_to_num(sample, =0)



Use all 107k rows of train data (instead of only 1 row per eeg_id).


Read all eeg parquets into CPU RAM and create spectrograms inside dataloader with torchaudio.transforms.MelSpectrogram and crop with eeg_label_offset_seconds.

import torchaudio.transforms as T

make_spec1 = T.MelSpectrogram

make_spec2 = T.MelSpectrogram



Each epoch train with 1 sample from each unique eeg_id. But randomly select 1 sample from all eeg_id samples with train = train.loc[train.eeg_id == EEG_ID].sample(1).


Apply data augmentations to raw waveform (not spectrogram) inside dataloader before creating spectrogram.


Use data augmentation "brain-right-left flip", "brain-temporal-parasagittal-flip", "waveform-crop-rescale", "waveform-invert", "frequency-dropout"


Use tiny_vit_21m_512 for 2D spectrograms and tiny_vit_21m_224 for 2D wave plots.


Use Nischay EegNet-1D here for 1D raw wave data model.


Tune LR and learning schedule of each model individually using my discussion post here


Cross validate with train vote&gt;=10 and observe perfect correlation between CV and LB.
