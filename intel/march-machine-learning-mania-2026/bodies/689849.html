1.Summary

This solution focused on building a well-calibrated probabilistic system rather than simply maximizing prediction accuracy. The strongest improvements came from:

  • Using temporal cross-validation to avoid leakage and ensure realistic validation
  • Applying data-driven ensemble weighting instead of manual heuristics
  • Incorporating seed-based priors as a form of regularization
  • Leveraging model diversity across multiple pipelines (feature-based, Elo, etc.)

A key realization was that reducing overconfidence and variance had a larger impact than increasing model complexity. Careful calibration and disciplined ensembling consistently outperformed intuitive or manual adjustments. At the same time, several intuitive ideas (manual overrides, external brackets, improper weighting) highlighted how easy it is to break probabilistic consistency, even with seemingly reasonable changes.

One of the most valuable lessons from this competition is that exploring other participants’ work is extremely important — their shared ideas can significantly accelerate learning, save time, and provide insights that are difficult to discover alone.

6. Improved Ensemble (Key Differentiator)

The main gains came from how predictions were combined, not from adding more models.

we implemented a submission-level A/B testing framework to systematically explore improvements without retraining models. First, a feature matrix was constructed for all possible matchups, and predictions were generated using three base models: Logistic Regression (with scaling), XGBoost, and LightGBM. These were combined into a baseline ensemble (40/40/20), which served as the reference prediction.

From this baseline, multiple controlled variations were created by adjusting clipping ranges to reduce overconfidence, modifying ensemble weights to emphasize different models, and introducing small seed-based blending (5–10%) as a form of regularization. When available, optimized weights derived from out-of-fold predictions were also applied.

6.1 Temporal Cross-Validation (Leakage-Free)

Instead of k-fold: Train on seasons < N Validate on season N

Benefits: Eliminates future leakage More realistic validation Better generalization

6.2 Optimized Ensemble Weights

Used Scipy optimization to minimize log loss on OOF predictions.

Advantages: Data-driven weighting Captures model complementarities Outperforms manual weights

6.3 Seed-Based Blending (High Impact)

Tournament seeds are extremely predictive.

Final formula: final_pred = ALPHA * model_pred + (1 - ALPHA) * seed_pred

Insight: Acts as regularization Reduces variance Controls overconfidence

Key Insight

Biggest gains came from:

  • Variance reduction
  • Calibration improvement

—not model complexity.

8. What Didn’t Work

8.1 Manual Overrides

Based on personal judgment Introduced bias Increased overconfidence

➡️ Worse log loss, even when directionally correct

8.2 External Brackets (ESPN) Data

Issues: Not true probabilities Strong bias toward favorites Poor calibration ➡️ Damaged prediction distribution

8.3 Weighting Bug

Intended weight: ~0.05 Actual: ~0.25

Impact: Weak signals dominated Model signal diluted Performance dropped significantly Lesson Poor weighting can destroy a strong ensemble.

9. Final Takeaways

Calibration > Accuracy Variance reduction is critical Simple ideas (like seeds) can outperform complex models Ensembling works only with: Proper weighting Calibration awareness

10. Future Improvements

Use external ratings (Massey, KenPom, BPI) Advanced calibration (Isotonic / Platt scaling) Time-aware CV (leave-one-season-out) Separate pipelines (Men vs Women) Learn weights for human priors instead of manual blending
