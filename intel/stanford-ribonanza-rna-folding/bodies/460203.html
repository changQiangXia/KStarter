Modified RNAdegformer

code: https://github.com/tattaka/stanford-ribonanza-rna-folding-public

Input

  • Sequence
  • BPP Matrix (by EternaFold and Contrafold)

Architecture


Made some changes to the RNAdegformer(https://github.com/Shujun-He/RNAdegformer) proposed by Shujun, including the order of layers.

  • kernel_size = 7 except for the last transformer, which is 1
  • postnorm
  • GLU family activation
  • ALiBi positional encoding is applied separately head from bp_matrix
  • Other minor changes ensemble

Training

  • simple kfold (k = 5)
  • 1st stage: First train with sn > 0.5 (300epoch)
  • 2nd stage: Then finetune with sn > 1.0 for a short number of epochs (15epoch)
  • When training with train dataset only, output errors for each nucleotide in addition to reactivity
  • For pseudo labels, use sn_pred>0.75 for the 1st stage, sn_pred>1.0 for the 2nd stage, and future=1 only
    • Train from scratch with the pseudo labels added
  • lr=1e-3, bs=256, AdamW(eps=1e-6), with warmup for 1st stage

1D Conv & Residual BPP Attention

code: https://github.com/fuumin621/stanford-ribonanza-rna-folding-4th

Based on the 1D Conv + BPP Attention architecture proposed by nyanp, we made improvements.

Architecture

  1. Sequence Embedding
  2. Conv 1d
  3. SE Residual & Residual BPP Attention x 12 layers
    • Using BPP as attention weight
    • Reduced the kernel size of 1D convolution as the layer depth increased
  4. Bi-LSTM x 2 layers
  5. Linear

Input

  • Sequence
  • BPP Matrix (by EternaFold)

Parameter

  • Drop out rate: 0.1
  • n_dim: 256
  • Kernel size: 9, 7, 5, 3 (decreases as the layer depth increases)
  • Learning rate: 4e-3 with cosine scheduler
  • Batch size: 64

Training

The training strategy essentially adopted the same approach as the above Modified RNAdegformer

Score for the single model

  • CV (k-fold): 0.12161
  • Public Score: 0.13889
  • Private Score: 0.1425

Transformer with BPP Attention Bias (@ren4yu's Part)

code: https://github.com/yu4u/kaggle-stanford-ribonanza-rna-folding-4th-place-solution

This model borrows the bpp attention bias idea from the RNAdegformer, but is closer to the original Transformer architecture.
Instead of using positional embedding, Conv1D was used in FFN to give relative positional information.

Training Procedure

  • Train model with AdamW LR=2e-3 to 2e-4, BS=128, use s/n filter threshold=0.5
  • Finetune model with AdamW LR=2e-4 to 0, BS=256, use s/n filter threshold=1.0

Score for the single model

  • Private Score: 0.14267
