One of the first things I noticed when I started looking into this dataset is the x, y, and z features. I plotted the data in a 3D space to gain more insight as seen below (view the full EDA notebook here):



Alright so there is a clear linear relationship between these features and the target variable price. But what is x, y, and z exactly?



x: Length of the cubic zirconia in mm.

y: Width of the cubic zirconia in mm.

z: Height of the cubic zirconia in mm.


So these features correspond to the shape of each cubic gemstone. Here are some feature engineering ideas based on this fact:
