Description

  1. Volume: The volume of a diamond can be calculated by multiplying the three dimensions (x, y, and z). Therefore, a new feature "volume" can be created by applying this mathematical formula: volume = x * y * z

  2. Density: Density is an important property of a diamond that can be derived from the volume and carat weight. A new feature "density" can be created using this formula: density = carat / volume

  3. Table percentage: The table percentage is the ratio of the diameter of the table (the flat facet on the top of the diamond) to the average diameter of the diamond. It can be calculated using this formula: table_percentage = (table / ((x + y) / 2)) * 100

  4. Depth percentage: The depth percentage is the ratio of the depth (the distance from the table to the culet, the bottom of the diamond) to the average diameter of the diamond. It can be calculated using this formula: depth_percentage = (depth / ((x + y) / 2)) * 100

  5. Symmetry: Symmetry is an important aspect of a diamond's appearance. It can be calculated by taking the difference between the length of the longest and shortest axis of the diamond and dividing it by the average length of the three axes. The resulting value can be used as a new feature "symmetry". symmetry = (abs(x - z) + abs(y - z)) / (x + y + z)

  6. Surface area: The surface area of a diamond can be calculated using the following formula: surface_area = 2 * ((x * y) + (x * z) + (y * z))

  7. Depth to table ratio: The ratio of depth to table can provide insight into the diamond's proportions and can be used as a new feature "depth_to_table_ratio". depth_to_table_ratio = depth / table
