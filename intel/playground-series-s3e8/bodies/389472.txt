Description




Volume: The volume of a diamond can be calculated by multiplying the three dimensions (x, y, and z). Therefore, a new feature "volume" can be created by applying this mathematical formula: volume = x * y * z


Density: Density is an important property of a diamond that can be derived from the volume and carat weight. A new feature "density" can be created using this formula: density = carat / volume


Table percentage: The table percentage is the ratio of the diameter of the table (the flat facet on the top of the diamond) to the average diameter of the diamond. It can be calculated using this formula: table_percentage = (table / ((x + y) / 2)) * 100


Depth percentage: The depth percentage is the ratio of the depth (the distance from the table to the culet, the bottom of the diamond) to the average diameter of the diamond. It can be calculated using this formula: depth_percentage = (depth / ((x + y) / 2)) * 100


Symmetry: Symmetry is an important aspect of a diamond's appearance. It can be calculated by taking the difference between the length of the longest and shortest axis of the diamond and dividing it by the average length of the three axes. The resulting value can be used as a new feature "symmetry". symmetry = (abs(x - z) + abs(y - z)) / (x + y + z)


Surface area: The surface area of a diamond can be calculated using the following formula: surface_area = 2 * ((x * y) + (x * z) + (y * z))


Depth to table ratio: The ratio of depth to table can provide insight into the diamond's proportions and can be used as a new feature "depth_to_table_ratio". depth_to_table_ratio = depth / table


Code. See the details in my notebook

    df['volume'] = df['x'] * df['y'] * df['z']
    df['density'] = df['carat'] / df['volume']
    df['table_percentage'] = (df['table'] / ((df['x'] + df['y']) / 2)) * 100
    df['depth_percentage'] = (df['depth'] / ((df['x'] + df['y']) / 2)) * 100
    df['symmetry'] = (abs(df['x'] - df['z']) + abs(df['y'] - df['z'])) / (df['x'] + df['y'] + df['z'])
    df['surface_area'] = 2 * ((df['x'] * df['y']) + (df['x'] * df['z']) + (df['y'] * df['z']))
    df['depth_to_table_ratio'] = df['depth'] / df['table']


Note that df['x'] has a few zeros, we need to replace them with small values such as df['x'] = df['x'].replace(0, 1) first to avoid division by zero error.

The prompts



Basically, first you want to test if ChatGPT understand the domain. "Given a ML classification task about diamond with the following features: x, y, z, carat, cut, color, clarity, table, depth, explain the features."

Then, you ask it to generate features "Use feature engineering to derive more features using math operations." Note the math so it gives you formula.

Then, ask it to give you code "Given a dataframe df, generate code for those features , using single quote to access original feature names"
