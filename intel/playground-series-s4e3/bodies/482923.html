as some of you might know, I created an automl framework called BlueCast. Despite usual solutions it is not build to go through many different architectures and maybe even assemble them, but rather be a flexible framework with lightweight dependencies that helps in real world applications end-to-end while still having strong performance.

If you want to explore it's capabilities, here is a notebook to give a comprehensive overview:
https://www.kaggle.com/code/thomasmeiner/ps4e3-bluecast-a-comprehensive-overview

This shows:

  • EDA via BlueCast
  • Data drift detection
  • The many ways to model with BlueCast (out-of-the-box, own params, ensemble, custom model)
  • Experiment tracking
  • Experiment analysis

The package is still relatively young. If you like it, a star on GitHub would be so much appreciated.

Also ideas and contributions are welcome.
