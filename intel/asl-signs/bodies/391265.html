after some experiments for the first week, here is the master plan:

[1] one (or two) layer transformer is sufficient. for one fold, memory is only 2mb ( tf.lite.Optimize.DEFAULT, i.e. int8 in storage) and 25min for all 40_000 test videos (or 30 msec per video). Future because of missing frame, long term attention has its advantage

in fact two layer transformer would lead to over fitting.

[2] next step is to spend more time on data representation, especially normalization

[3] use of external data, maybe need to use mediapipe to extract landmarks on external ASL video.
Other ways to use increase data increases, adversarial/diffusion augmentation, masked token prediction, etc

I feel that SSL with masked token prediction (e.g. generative pretraining) fits this problem well as there are high proportion of missing frames.

[4], There no much of algorithm design because network is quite shallow. if there is, it would be more on increasing parameters for accuracy and speeds. There are many VIT tricks that can be used here, e.g. window attention, poolforming, convolutional positional encoding, grouped conv, …

First results

  • one fold, max video length=60 (crop first) : LB 0.65
  • 1 fold, max video length=512 (crop center) : LB 0.65 25 min
  • 4 fold, max video length=512 (crop center) : LB 0.68 32 min
  • 5 fold, max video length=512 (crop center) : LB (better) 0.68 35 min

CV one fold using train/validation random split: cv 0.72~0.74 (probably the limit if good generalisation)
CV one fold using train/validation participant non-overlap split: cv 0.61 (compared with above, show the severity of lack of train data)
