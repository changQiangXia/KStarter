This Feedback Prize competition is very similar to Kaggle's PetFinder competition. Both are regression tasks utilizing pretrained CNN and/or Transformers. 

The 1st place solution in PetFinder (by Giba here) extracted embeddings from dozens of not-finetuned models and then trained and predicted with RAPIDS cuML SVR using the concatenated 10,000's of columns of embeddings. This works well in this competition too as an alternative to the current public notebooks which all use common NLP training techniques.

RAPIDS cuML SVR



Starter Notebook

I published a started notebook here which achieves CV 0.4505 and LB 0.44x without finetuning any NLP transformers! The notebook simply extracts embeddings from downloaded Hugging Face transformers and then trains and infers a RAPIDS cuML SVR.

How To Improve

There are many ways to improve this starter notebook



We can try adding embeddings from the dozens of other Hugging Face models such as BERT, RoBERTa, Funnel, Electra, etc

We can try finetuning the transformers before using SVR. Note: you must finetune models using the same folds that you wish to train SVR with 

We can try using models that have been trained on another task such as Feedback competition 1 and 2. Just take the trained models, remove the head, extract embeddings, and train RAPIDS SVR ! 

We can add columns of meta features like "number of unique words", "length of text", "number of misspellings" etc

We can extract embeddings from other layers from NN like second to last hidden, or the token embedding layer, or the output from some special pretrained head, etc etc


Enjoy!
