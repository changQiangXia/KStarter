What I learned from my first Kaggle Notebook in this competition:
I was just following my guts since I don't have any background. 

First issue, I would have to deal with URL. There are plenty of work with images (jpg) in Kaggle, not with URL.  After reading Radmir's (it was the only Notebook, I highly recommend it) to have an insight about to perform with URLs.

How to open an image from the URL in PIL?  After searching in Google:
"Write Url with file name in URLLIB. request. urlretrieve() method."  Then Bla, Bla, Bla, Blaba. 

Simple? It seemed to be, though after several attempts and answers in StackOverflow  I've only got: "display: unable to open X server" 

If you want to open a file with many rows apply: nrows=10000 or 1000 or whatever. Thank you Udbhav.

Then I found: "Accessing Lots of Images in Python" by Rebecca Stone: (2019 no date)
https://realpython.com/storing-images-in-python/

"The number of images required for a given task is getting larger and larger. Algorithms like convolutional neural networks,  CNNs, can handle enormous datasets of images and even learn from them." 

You can use Pillow for the image manipulation. I tried but I was not well succeeded.

"Use LMDB which is a B+ tree, which basically means that it is a tree-like graph structure stored in memory where each key-value element is a node, and nodes can have many children. Nodes on the same level are linked to one another for fast traversal."  I didn't applied that.

What about HDF5?  NASA’s blurb on HDF5.   If it's good for Nasa, probably it won't help a Newbie.

!pip install h5py
import h5py

You can store that huge data in a disk, in LMDB and of course In GOOGLE Cloud, or other cloud shh! 

How long did all of that storing take?  I didn't even think about that.

You'll have to adjust the code for many images, then experiment for reading them with timeit:

from timeit import timeit

"The write time is often less critical than the read time."  And, plot all the read and write timings. 

Parallel Access

"With such large datasets, you may want to speed up your operation through parallelization."  

In fact, I just intended to plot some images, without coping others code, not to go so far. As a beginner we can't absorb or even understand that level of information. 

https://realpython.com/storing-images-in-python/

Concurrency

"In the majority of cases, you won’t be interested in reading parts of the same image at the same time, but you will want to read multiple images at once. With this definition of concurrency, storing to disk as .png files actually allows for complete concurrency." (Rebecca Stone) 

You can learn more about how Convnets (CNNs) can be used for ranking selfies.
