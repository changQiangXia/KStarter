Advanced EDA Technique

In addition to basic technique where we plot features and/or targets, it is helpful to train models and observe the results. This is advanced EDA.

One example is training XGB with different max_depth parameters. I trained multiple XGB with different max_depth parameters on the original dataset and plotted the results below:

We see that this competition's original dataset achieves the best performance when max_depth = 1. This is not normal and this indicates dataset properties. This indicates that the features are mostly independent of each other.

Using This Observation

In general, the art of data science (i.e. finding patterns among features to predict targets) is mostly about discovering feature interaction. i.e. How does the combination of features influence the target. It is very informative that this data has no feature interaction, so instead of focusing on discovering interactions, we need to explore other techniques to model this data!

For example, the lack of interaction makes logistic regression model strong. I publish a logistic regression starter here
