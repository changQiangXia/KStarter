Validation

I did a lot of LB probing and comparisons between 'pure' Kaggle and Persuade 2.0 datasets. Key findings:



There were 5 topics in the test set with the following proportions (curious if I was right):




Driverless cars - 35.6%

Facial action coding system - 24.6%

Exploring Venus - 19.6%

The Face on Mars - 12.6%

'A Cowboy Who Rode the Waves' - 7.6%




Persuade 2.0 and Kaggle-only records are different.

There were no records from the Persuade 2.0 dataset in the test set.

All the topics were present in the public LB part of the test set. My assumption was that they are also present in the Private part of the dataset.


I used the findings in the following way:



I validated on the 5 topics Kaggle-only essays with weights adjusted to expected test set weights. You can find the weights calculation in this notebook. The persuade records and topics that I thought were not present in the test set had weight=0 for validation.

I trained on all train data, but added a persuade binary flag as a feature. In the test set, all the records had persuade=0.

I used StratifiedKFold stratified by score.


Despite all the efforst described above I was not able to obtain strong CV-LB correlation. My 0.836 solution was chosen based on 50% CV and 50% LB score. I had one better PB solution with 0.837 score.

Solution

I used this notebook as my baseline. My modifications:



Validation as described above.

persuade flag.

Training vectorizers (TfidfVectorizer, CountVectorizer) on the test set only.

Increased DeBERTa max inference length to 1536.

Transformed DeBERTa OOF into CDF. My intuition was that it would be much easier to use for tree-based models optimizing QWK objective.

Added texstat and spaCy-based features (similarities between sentences in one text, words, sentences, and paragraphs stats).

Conclusions

I've spent a lot of time on data: EDA, reading essays, comparing Kaggle and Persuade 2.0 datasets, LB probing, trying various augmentation techniques, etc. This allowed me to improve the baseline (changes were subtle) and choose almost optimal submission (2nd best on PB). The 6th place solution scored 0.817 (1,200+ place on LB). The 0.824 solution (25th on LB) scored 0.832 (500+ on PB). I also want to acknowledge the role of luck here (possibly big one). Getting my first gold medal took me 6 years, and I feel thankful and proud I finally got it.
