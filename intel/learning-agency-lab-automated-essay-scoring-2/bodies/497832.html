Regression versus Classification

An alternative to using AutoModelForSequenceClassification.from_pretrained(MODEL, num_labels=6) classification is using regression.

It's simple, just use AutoModelForSequenceClassification.from_pretrained(MODEL, num_labels=1) and set the 1 target to the train.csv's value of score converted to datatype float32. Then we have regression.

No Dropout for Regression

If we want to use regression, remember that we need to remove dropout from NLP transformers to prevent batch norm from destabilizing our regression prediction. Discussion here

Max Token Sequence Length

Most (actually, I think all) public notebooks use tokenizer(essay, max_length=512) with max=512. Below is a histogram of essay token length. The transformer DeBERTa can accept any length input. (Whereas other encoder models like BERT or RoBERTa can only accept 512).

Using max_length = 1024 or max_length = 1536 for DeBERTa gives a nice CV score boost (versus 512). Consider doing this. If we want to use RoBERTa (which has different architecture and tokenizer), consider using the model LongFormer (which is a modified RoBERTa model) and can also accept any length input. (Also if we use RoBERTa or LongFormer, consider adding parameter trim_offsets = False to the tokenizer to give your model more information because it doesn't remove whitespace).

Batch Size

Note that different batch sizes achieve different CV score and LB score. It makes a big difference in this competition. So experiment with different batch sizes. For me, batch size = 8 (with starting LR 1e-5) is working best!

Fast Experimentation

For experiments, consider using "microsoft/deberta-v3-small" or "microsoft/deberta-v3-xsmall". And then after developing your intuition and finding good hyperparameters, train "microsoft/deberta-v3-large" for boost in CV score and LB score.

Learning Schedule

We can train with constant, linear, step, and cosine. And we can vary the number of epochs. Make sure to find the best schedule and learning rate! For me, using linear with epochs=4 is working best!
