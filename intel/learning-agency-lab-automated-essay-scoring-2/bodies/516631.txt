I would like to thank Kaggle and the competition hosts for organizing this interesting competition. 
The 3rd place submission showed a consistent correlation between CV, public, and private scores.

CV: 0.836
Public: 0.832
Private: 0.839

I will provide a detailed explanation of the solution separately, but here is a brief summary. The focus on the Kaggle-only data contributed to achieving stable scores.



Pre-training with MLM

Two-stage training:
First stage: Train with Kaggle data and validate with Kaggle-only data.
Second stage: Load the weights from the first stage model, train on the Kaggle-only data, and validate on the non-Kaggle-only data.
　(Validation used data other than the Kaggle-only data to avoid overfitting to the Kaggle-only data)

Ensemble using the following combinations of backbone, head, and max_length:
Backbone: DeBERTa-v3-base / DeBERTa-v3-large
Head: Mean&amp;Pool / Attention / LSTM
Max_length: 1024 / 1536


I did not use the Persuade Corpus 2.0 data in this submission because I did not receive a response regarding its licensing. Although I also submitted a version using Persuade Corpus 2.0, thinking it might positively impact the private score, there was almost no difference compared to the version without it, indicating no significant impact.

Additionally, while the CV strategy using groupkfold by prompt_name showed good public scores, the private scores dropped significantly. This suggests that the private data might have had a similar data distribution to the Kaggle-only data rather than unknown prompt_name.

MLM Training Notebook : https://www.kaggle.com/code/dsohonosom/lal-deberta-base-mlm

Inference Notebook : https://www.kaggle.com/code/dsohonosom/aes2-3rd-place-submission
