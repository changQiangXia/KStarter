Topic #515356: More Training Data (Processed JPEGs) - Upsampling Malignant Images
  Author: Nischay Dhankhar
  Posted: 2024-06-27 20:23:08.439000
  Votes: 296  Comments: 82

Since we have just 393 Positive targets (Malignant images) and more than 400k negative targets, training the 2D CNNs become quite challenging. If you plan to use the entire competition data for training deep learning models, many batches won't even have single positive label :))

To overcome that, We can make use of training data from previous Melanoma Detection Competitions held by ISIC in 2020, 2019, 2018 &amp; even 2017. The SIIM-ISIC Melanoma Classification 2020 competition was one of the most widely participated computer vision competitions held on Kaggle. (It was also my first computer vision competition 😃) In that competition, many of the top-performing solutions incorporated images from the 2019 and 2018 datasets.

I have collected all of these previous year competitions datasets and processed them in the same format as this competition. The training images for this competition has very low resolutions (&lt;256x256) with most image size around 128 - 156. Meanwhile for previous competitions, resolutions were very high, so I have done centre cropping and resized them to 224x224 &amp; 256x256 size images to match with ISIC 2024 data.

With me being close to become 4X GrandMaster, I found a perfect opportunity to publish datasets :))

ISIC 2020 Dataset :

Distribution: 32542 - benign, 584 - malignant

224x224 Images: https://www.kaggle.com/datasets/nischaydnk/isic-2020-jpg-224x224-resized
256x256 Images: https://www.kaggle.com/datasets/nischaydnk/isic-2020-jpg-256x256-resized

ISIC 2019 Dataset

Distribution: 20809 - benign, 4522 - malignant

224x224 Images: https://www.kaggle.com/datasets/nischaydnk/isic-2019-jpg-224x224-resized
256x256 Images: https://www.kaggle.com/datasets/nischaydnk/isic-2019-jpg-256x256-resized

ISIC 2018 Dataset

Distribution: 8197 - benign, 785 - malignant

224x224 Images: https://www.kaggle.com/datasets/nischaydnk/isic-2018-jpg-224x224-resized
256x256 Images: https://www.kaggle.com/datasets/nischaydnk/isic-2018-jpg-256x256-resized

Formatting is same as ISIC 2024.



train-image/ - image files for the training set (provided for train only)

train-metadata.csv - metadata for the training set


Columns in train-metadata.csv




Field Name
Description




target
Binary class {0: benign, 1: malignant}.


patient_id
dummy values for ISIC 2018,2019, unique patiend ids for ISIC 2020


isic_id
Unique identifier for images
