Topic #253000: DICOM to PNG dataset (128 GB -> 5.2 GB) 🎨🔥
  Author: Jonathan Besomi
  Posted: 2021-07-14 15:44:09.438000
  Votes: 369  Comments: 103

Preprocessing DICOM files is generally quite computational-intensive and slow, especially considering the large dataset size (~128 GB). For this reason, I've fired up a GCP VM and transformed the data from DICOM to PNG for you. The dataset file size has been reduced from 128 GB to 5.2 GB. 

Notes



Images sizes have been kept as the original ones. 

To further reduce file size, all empty DICOM images files have not been included in the dataset, you can easily spot them by looking at the images sequences (Image-X.png). Note that, because of that, some entire folders (such as train/00109/FLAIR) are not included in this dataset (as they contain empty images only).

The structure of the dataset is not changed. I.e all .dcm files are now .png files.


Dataset link



RSNA-MICCAI-PNG-Dataset [5.2 GB]


Script

For each image, run: (Adapted from @tanlikesmath work)

dicom = pydicom.read_file(path)
data = apply_voi_lut(dicom.pixel_array, dicom)
if dicom.PhotometricInterpretation == "MONOCHROME1":
    data = np.amax(data) - data
data = data - np.min(data)
data = data / np.max(data)
data = (data * 255).astype(np.uint8)


More

If you need other formats, you want a version with resized images or anything else, just ask 👍

Thank you for reading, happy kaggling to all!
