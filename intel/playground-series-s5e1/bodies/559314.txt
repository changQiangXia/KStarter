Deep learning continues to amaze me! Before 2010, both computer vision and natural language processing needed humans to engineer features. These features were then input into ML models (like SVM or logistic regression). In the mid 2010's we started witnessing DL (neural network like CNN and Transformer) models doing the feature engineering for us and achieving better accuracy than human feature engineering could achieve.

Transformer Starter - No Feature Engineering

I would like to share a competitive deep learning solution to Kaggle's sticker playground competition. Using no feature engineering, the transformer starter here achieves an amazing LB = 0.052, wow! And this model can be improved further to achieve LB = 0.04X!

How Time Series DL Works

Time series DL (deep learning) uses 3 common blocks: RNN block, CNN block, and Transformer block. These blocks accept a time series as input with shape (batch size, sequence length, in_features) and output a new time series with engineered features, (batch size, sequence length, out_features). 

So we can input a sequence of about 3 years (sequence length = 1440 days) with 1 feature (num_sold) into a RNN or CNN or Transformer block. And the block outputs a sequence of length 3 years with K features where we choose K. So we can pick K=64 as shown in image below and get 64 engineered features!



Time Series Model

We build a time series DL model by assembling layers of blocks. So shape (batch_size, sequence_length, 1) goes into 1st layer and out comes (batch_size, sequence_length, 64). Then we input that into 2nd layer and out comes (batch_size, sequence_length, 64) again (or any number of features other than K=64 if we want). Each time the engineered features are getting better! We can repeat this as much as we want. 

We add a positional encoding sequence to our input sequence to help the transformer understand time. And the final block of our model (with all it's engineered features) feeds into a head (global pooling layer and dense 32 layer) to predict the future time series. 

We can improve the head by building a decoder. Then our model would be an encoder-decoder like a sequence to sequence transformer. Right now our model is an encoder with a 32 output regression head (to predict 32 future days of num_sold).



Autoregression

There are many ways to predict future sequences. This starter uses autoregression. We input a sequence of 1440 days which is about 3 years and the model outputs 32 days which is about 1 month. To get the second month. We concatenate our 1st prediction with 2 years 11 months of most recent train data. Then we take those 3 years and input that into the model to get the second month. We use for-loop and repeatedly predict output and use the prediction as input (plus some months of train data) 35 times to get 3 years of predictions.

EDA of Predictions

In this competition, we predict 90 time series. There are 5 products, 6 countries, and 3 stores. For each pair of product, country, store we predict a time series of length 3 years. The first 2 years are for the public LB and the last 1 year is for private LB. Below are some predictions from the Transformer starter model. We see that they look good!
