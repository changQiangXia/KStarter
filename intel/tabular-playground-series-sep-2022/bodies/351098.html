Introduction

This discussion topic is intended to accumulate the valuable ideas as for the additional feature engineering for this competition.

Notes:

  • This thread is useful if your strategy for this contest is to turn the classical TS problem into regression problem (and thus use the popular regression ML algorithms). If you prefer to use the classical TS modelling techniques, then it would not be of any interest to you.
  • I am going to update it from time to time, to aggregate the new ideas that proved to work in the expert models

Additional Features for This Contest

The following ‘body of knowledge’ contains the info about the useful features suggested / tried by the experts who participate in the competition.

GDP 2017-2021 Data: as suggested by @hasanbasriakcay in Additional Features For The Competition, GDP 2017-2021 Data, it will certainly improve the model score in the leaderboard.

Education index: as demonstrated in the contest with the similar dataset ( TPS-Jan-2022 ), Education Index was helpful. Therefore @desalegngeb recommended to use it in this contest, too (per this thread )

Consumer Confidence Index: as mentioned by @xclimx in this thread, this feature proved to work for this competition, much like it did for TPS-Jan-2022. This discussion thread refers to the relevant dataset and notebook to demonstrate it in work.

Business Confidence Index: as mentioned by @xclimx in this thread, this feature proved to add the edge to the model forecasting accuracy in this competition.

Covid lockdown dates: as 2021 (the time interval to predict the book sales) fell in COVID-19 pandemic, the natural suggestion (by @xclimx in Feature engineering - Covid lockdown dates ) is to add the critical per-country lockdown dates as features into the dataset. The external dataset per Stay At Home COVID 2020-2021 contains the relevant details for it. Also, the mini-EDA per Lockdown affects the Kaggle Book Sales in Italy, Poland, and Spain? provides the additional visualization in support of it.

Holidays: Holidays per country prove to work for this contest (as in most of TS-type contests). You can check Holidays by country and year for more details. It is also justified by the mini-EDA research by @hasanbasriakcay presented in Holiday and The Target Relationship
