My current public LB score is 0.82, and it was achieved by my AI-agent application.
First, I implemented the solution myself and achieved a public LB score of 0.82. Afterwards, I built an agent application and, with only simple instructions, had the agent handle the implementation.I use Mastra as the agent-application framework.

The agent receives only the following information:

  • Competition data
  • Competition page link
  • System prompt
  • Rule prompt: details on how to conduct experiments, when to run static analysis and tests, etc.
  • My past Kaggle competition code and its explanations: these aren’t critical; they’re mainly used as references for file names and code structure, which helps improve readability.

Here are my impressions of kaggle agent:

  • When using only a single model, the evaluation score is still low. With just the o3 model, the IMU-only CV score was 0.70.

  • Combining multiple models and having the agent evaluate and plan the implementation is extremely important; doing so raised the LB to 0.82.

Given the complexity of this competition’s task, it seems I don’t need to be very involved in the implementation. For more complex tasks, I’d like to try in the future and see what kind of ranking I can achieve.
