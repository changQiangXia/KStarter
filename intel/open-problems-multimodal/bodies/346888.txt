The Goal:



We can think of this competition as having two parts: Multiome and CITEseq.

For both parts, we need a model that can make a vector prediction given a vector input.

Each cell id represents a sample

For Multiome, we need to use transformed numerical DNA data to predict transformed numerical RNA data.

For CITEseq, we need to use transformed numerical RNA data to predict transformed numerical Protein data



(The numbers are just random obviously use the values in the actual dataset. Also this only shows for one sample, you will actually be doing this for many samples)
learn more about central dogma of molecular biology

Submission



format your predictions similar to the targets tables

index the cell_id / gene_id from the label matrix to fill out the evaluations_ids.csv

map the evaulations_ids.csv to the sample_submission.csv using the row_id
