1st Place Solution - TPS Jun Denoising AE

by Sebastian van Gerwen
An amazing implementation of DEA.

Tricks

  • Random Mask Created a binomial random mask and multiplied by the original data to randomly set values to zero.

  • Feature-wise embeddings The model embeds both the features and the mask and adds them together. This is so it can learn a representation of where the nulls are set to zero, and therefore where to focus to impute.

  • MLP Architecture Used layer normalization with skip connections, with 7 dense layers using the mish activation function.

  • Output Computation Output through a final dense layer to match the dimensions with the input shape. Then, the final output is conditional on whether the value was masked.

  • Masked MSE Loss Used an MSE loss that sets the value to zero according to a mask. This mask is the true data null values - thus we never calculate a loss on values that were originally in the training data, but we can still learn from those rows without creating bias by using a naive imputation method during training.

  • Conditional Ensemble Ran the DAE 3 times in pytorch and tensorflow - tensorflow runs performed significantly better, but the average of all performed the best.

#2 Solution

by ArturRa

  • Understood from the competition description that The dataset has similarities to the May 2022 Tabular Playground,… means the best model from the previous competition must be able to untangle the same patterns of the current dataset.

  • Used the May 2022 Tabular Playground 1# Solution notebook

  • Used mean technique for the F_1 and F_3 groups.

  • For the F_4 group, I started using one column as the target and the others as features.

  • Split the F_4 data into six groups: without NaNs, with one, two, three, four, and five NaNs. The first group was used for training, the others – for predicting.

  • Trained different models for these x-NaNs groups by changing the number of outputs for x.

  • Had to train a lot more than just 80 regressors. And this took a lot of time.

  • Examples: 4-NaNs group here. Splitting F_4 data into six groups here.
