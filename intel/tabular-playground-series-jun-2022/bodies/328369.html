One more interesting TPS competition for June 2022. This month, our objective is to predict the missing values.

There are already a lot of useful posts on handling missing values and how to impute them. Apart from the imputation approach, one approach is to treat this as a regression problem and then solve it.

  • In this approach, we can consider one column as a target at a time and try to predict the column's value using other columns. For example, say we can use the column F_1_0 as target and use the other columns to predict this column.
  • Since missing values are present only in the numerical columns, we can build regression models to do the predictions.
  • For each column, we can take all the rows where the column value is present as the training dataset and the missing column values as the test dataset. An example code for F_1_0 column would be
df = pd.read_csv("/kaggle/input/tabular-playground-series-jun-2022/data.csv")
train_df = df[~df["F_1_0"].isna()]
test_df = df[df["F_1_0"].isna()]
  • We can then split the train data to build and evaluate our regression models.
  • We will end up with 80 models - one for each of the columns
