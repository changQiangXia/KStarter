Hi all, as the title states, I've taken the 2M DiffusionDB subset and uploaded it to Kaggle as 20 datasets. That's 100,000 images per dataset and each dataset is 100 'part-ids'.

For more information about DiffusionDB you can check out their website:

  • https://poloclub.github.io/diffusiondb/


NOTE ON METADATA:

Alexandre Teles already created a dataset containing the two metadata files (one for the 2M subset and one for the large superset). That link is:

  • https://www.kaggle.com/datasets/alexandreteles/diffusiondb-metadata
