I was having trouble visualizing the robot arm in motion (especially since it has magical telescoping arms?), so I built a little js visualizer for it:

https://kagglesanta2022.netlify.app/

It's fully client side (so your files and path data don't go to any server ever), and it's just a single file react js app, so it should be easy to download it and mess around yourself. I'll probably add more features to it, but wanted to get something up and running quickly.



Using your own path data

You can paste in path data (3d array), or upload a json file of the robot path. It starts with a sample path as an example.

So for example, if you wanted to see the first 1000 steps of the path from the getting started notebook, then use this code to save the path as an output.json file:

import json
with open("output.json", "w") as file:
    file.write(json.dumps(path[0:1000]))


and then you can upload that output.json file to the visualizer (again, it doesn't go to any server - it's all client side), and it will load it into the box for you.

Note

It does work with the full path (100k+ rows), but since it's all client side js, it hangs the page for a bit. I think I can fix that by not using a textarea for file uploads, but that will be a future improvement :). For now, I'd stick with say, max 10k rows at a time or so.

Rendering

Once your data is in the text box, click "Render" to see the first frame of the path. 

Motion

Then you can click "Play" to see the robot in motion! It's pretty neat to see how it moves

Errors / Future Features

There's zero error checking right now, so if you upload a bad file or get into a bad state, it will just crash the page (probably just show a white blank page). If that happens just refresh and try again :)

I'll add some more features like a frame scrubber, speed controls, etc, but if anyone has ideas, let me know!

Hope that helps - and good luck everyone! 🎅
