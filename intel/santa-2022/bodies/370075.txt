Hello,

Inspired by Chris's post, I also created a vizualization.

You can find it hosted here:
https://danieloliveira56.github.io/kaggle-santa2022-tools/

There's no error checking. It currently loads a solution I took from the notebook posted by Ryan.

Current features:



Upload your solution in the submission.csv format

Adjustable frame rate

Scaling the image size

 Pixel number displayed

Image is plotted pixel by pixel

Arm is drawn


The framerate of the plot is limited by your monitor refresh rate. So it takes a while to draw all 257x257 pixels at 60 pixels per second.

Let me know if there's any feature you would like to see. I'm planning to add zooming and stepping.

New features December 12th:



Hover pixels to see x,y positions and r,g,b values.

Change the number of pixels plotted per frame, so now you have 2 settings that affect how long the plotting takes, frames per second and pixels drawn per frame. With this, the whole image can be plotted in a few seconds.

Manual stepping a number of pixels.

Pause/Unpause button.

Reset button (won't unpause if paused)

Bootstrap styling.

Cost calculation removed for now, the new changes made more complicated to track the total cost, specially with the manual stepping.
