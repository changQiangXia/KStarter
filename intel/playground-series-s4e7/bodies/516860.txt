Solution description

As a starting point, we have trained a straightforward TabularAutoML model on the full train dataset to figure out all the important points of the task. Below you can see both variants of the feature importances calculation (fast - based on the number of splits by each feature, permutation - permutation importances on holdout):



As we can see, the best 2 features in both variants are the same (Previously_Insured and Vehicle_Damage) and both of these features are binary. So we have tested training separate models for each variant below using LightAutoML:



1 LGBM model for the whole train dataset

2 LGBM models for the 0 and 1 subsets based on Previously_Insured feature

2 LGBM models for the Yes  and No subsets based on Vehicle_Damage feature

4 LGBM models for the train dataset subsets based on the unique combinations of Previously_Insured and Vehicle_Damage


This 9 LGBMs were used to create so called LGBM_composition_1 - the first weighted blend.

After that we have trained 7 tabular NNs using LightAutoML based on 4 different NN architectures:



3 DenseLight nets

2 ResNet nets

1 AutoInt net

1 FT-Transformer 


We have tuned all the hyperparams for these nets including activation functions, hidden and embedding sizes, SWA (stochastic weighted averaging) and early stopping params etc - this helps us to receive pretty high-performance NNs (for example we received 0.89232 AUC using single DenseLight model - the proof-kernel is here). 

Out-of-Fold predictions (OOFs) from 4 of these NNs (2 DenseLight, 1 ResNet and  1 FT-Transformer) were used as new features to train another 9 LightAutoML LGBM models (in the same manner as previously using full train dataset and separated segments). These stacking models were used to create LGBM_composition_2 - the second weighted blend.

The final submission was created using both LGBM weighted blend and 4 best tabular NNs - this helps us to receive 0.89375 AUC and secure the 3rd place.

That's all!



Once again, it was amazing 24 hours run and I would like to congratulate organisers and other contestants for that.

All the best,
