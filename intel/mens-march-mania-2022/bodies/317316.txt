Thanks very much to Amir Ghazi to for sharing his approach (which is to re-run @raddar's 2018 womens submission! Edit: Github code here)

I noticed on his bracket that Baylor's first match is a real outlier, for a top seed vs 16 seed it should surely be a darker green? His winning score is 0.51577 but when I run the code I get 0.66334, and a bracket like this:



Here is a heatmap view:



This looks similar to raddar's 2018 (Women's) winning solution:



So, where did I go wrong? There is a line near the end to select season statistics to be merged before scoring the xgboost models, I used:

sub$Season = 2022


If we re-use the 2018 code exactly as it was:

sub$Season = 2018


We merge in 2018 season statistics, to get 0.51577:



That explains why Amir's submission does not favour Baylor at all, but does rate teams like both Michigan's, who were better in 2018 (simple five38 baseline for 2018):



So… Continuing the meme theme, for anyone reading in 2023 :)
