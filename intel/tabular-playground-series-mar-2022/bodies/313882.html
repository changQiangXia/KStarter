Competitions are for me the most engaging part of the Kaggle experience, there are many good parts like the data sets and the great community, but competitions are the best for me.

I implemented the solution for this challenge using Apache Spark ML and Scala as the programming language.

For the implementation I extracted the day of the week and the hour as separated columns from the date column, and use these two fields along side with the direction and X and Y fields.

I used One Hot Encoders for the indexed string fields, a Random Forest regressor and a cross validator. I split my test data in order to save about 10% for evaluation and I did some hyper parameter tuning.

Doing this I was able to get the score of 5.320 which currently sets me at the 66% percentile, not great by any means but decent in my opinion :)
