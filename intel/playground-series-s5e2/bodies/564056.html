Weird Data

Kaggle's Backpack playground competition has weird train/test data. This data is unlike normal real life sales data for backpacks. This competition uses synthetic data generated from an original dataset that has randomly assigned targets (discussion here, code here).

It is natural to say; "there is no signal" or "we are fitting noise". But remember, we cannot fit noise nor predict random targets. If there was no relationship between features and target, then we would not be improving our CV scores nor LB scores as consistently as we are. With 4 million rows of train data, we cannot get lucky and improve our CV score with random feature engineering. There is indeed signal here. So, what is the signal?

Original Dataset Has Signal

In the original dataset, 10% of the rows have a duplicate (because the author duplicated 5% of rows). Therefore if we apply KNN with k=1, then 10% of the time we can predict the price by searching for the pair! (example notebook demonstrating this is here)

Synthetic Data Has Signal

Furthermore the process of creating synthetic data to enlarge 5e4 rows dataset to 4e6 rows dataset is essentially making 80 copies of each row of the original dataset (more info here). Thus there are two reasons why KNN (and/or using groupby aggregations with GBDT explained here) are highly effective in this competition!

Summary of Signal

In conclusion, 10% of this comp's 4 million row data has 159 other rows that we can use to predict price and 90% has 79 other rows to help us predict price. Groupby aggregations find these "other rows". (Starter notebook here)
