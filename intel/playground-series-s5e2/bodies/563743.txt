Hi everyone. Kaggle's Backpack competition is a tough competition! It is hard to build a model that performs better than simply predicting the constant value of train mean for all test samples. But it is possible!

The Magic

The secret sauce in this competition is feature engineering. There is a weak signal in the data and we need to help our model find it with feature engineering. I publish a starter notebook here to help.

GroupBy Aggregation

The most powerful feature engineering technique is groupby(COL1)[COL2].agg(STAT). This is where we group by COL1 column and aggregate (i.e. compute) a statistic STAT over another column COL2. This is the underlying method used to compute target encoding and count encoding. By computing raw statistics with groupby(COL1)[COL2].agg(STAT) and inputting them into our model, our model can do more than only receiving TE or CE.

Avoid Leakage

For COL1 and COL2, we can use any columns. Often, using the target price works best for COL2 (but of course we can use any column for COL2). If we use target price for COL2, we need to prevent leakage by using nested folds. These are K folds inside K folds. If COL2 is not target price, then we do not need nested folds. I publish a starter notebook here demonstrating how to use nested and not-nested folds for groupby(COL1)[COL2].agg(STAT).

STEP 1

The first step when using groupby(COL1)[COL2].agg(STAT) is to create or find a column for COL1. We can either use an existing column or we can make a column from one or more existing columns. There is a lot of room for creativity here. Below are three ideas how to make a new column. Some are demonstrated in my starter notebook here.



Transform an existing column into new bins. For example df[COL] = df[COL].round(6). 

Combine multiple columns together. For example df[NEW_COL] = df[COL_A].astype('str')+"_"+df[COL_B].astype('str').

Transform and combine. We can merge the above two ideas. 


STEP 2

Create or find a column for COL2. Similar to above, we can create (or find) a new column to use for COL2. If COL2 was created from target price, then we need to use nested folds to prevent leakage. If COL2 does not use target price, then we do not need to use nested folds.

STEP 3

Create or find a statistic STAT, and compute groupby(COL1)[COL2].agg(STAT). Note that there is lots of room for creatively here. We do not need to limit ourselves to the list ["mean", "std", "count", "nunique", "median", "min", "max", "skew"]. 

After applying groupby(COL1)[COL2] we have a collection of numbers. We can invent any technique that creates a new number from this group of numbers. For example we can invent a new aggreation  called lopsided. We can divide the count of numbers above the mean by the count of numbers below the mean. 

RAPIDS cuDF-Pandas v25.02

Experiment, experiment, experiment. This is the way to improve our model's CV score and LB score. We need to repeatedly try new feature engineering ideas, then train a model, then observe the CV score. If the CV score improves, then our feature engineering is a keeper. If the CV score does not improve then we discard the feature engineering.

We want to experiment as fast as possible and try as many ideas as possible. Computing groupby(COL1)[COL2].agg(STAT) on 4 million rows of train data takes time. We can perform more experiments if we can speed up this computation. One way to accelerate the computation of groupby(COL1)[COL2].agg(STAT) is to use RAPIDS GPU cuDF-Pandas or RAPIDS GPU cuDF-Polars. This is demonstrated in my starter notebook here.

Kaggle Utility Script

RAPIDS v25.02 was just released on Feb 15th, 2025. In our Kaggle notebooks, we can pip install the new RAPIDS version. Version 25.02 is a little faster than the previous 24.12 version when doing some things. 

There is a faster way to install new libraries on Kaggle than using pip. I created a Kaggle Utility Script here with RAPIDS v25.02. If we attach this Utility Script to our Kaggle notebooks, then our Kaggle notebooks will immediately have RAPIDS v25.02 without needing internet and without needing to pip install. Using Utility Scripts is the fastest and easiest way to use new libraries on Kaggle!

Kaggle Starter Notebook
