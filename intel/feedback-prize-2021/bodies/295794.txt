What is NER BERT?

NER stands for "named entity recognition". It is just text token classification. We can think of NER as being like image segmentation when it comes to text. 

What is Question Answer BERT?

Question Answer is like image detection when it comes to text. Both segmentation and detection can help in this Kaggle competition.

Segmentation

When doing image segmentation, each pixel gets assigned to a class. When doing NER, each word (or token) gets assigned to a class. 

Detection

When doing image detection, we find boxes in the image instead of irregular shapes. When doing Question Answer, we find "boxes" in the text instead of "irregular shapes". 

Boxes have the advantage of capturing "holes" (i.e. pixels or words) that may be in the middle of the area of interest that segmentation (or NER) may overlook.

TensorFlow NER Starter Notebook - LB 0.600

I published a TF NER starter notebook here. It uses the transformer LongFormer-base which is like Roberta-base but can accept inputs as wide as 4096 tokens. In the starter notebook, we use 1024 wide tokens since the majority of text is less than 1024 tokens.

The notebook trains one fold for 5 epochs and uses Rob Mulla's competition metric code here. The notebook achieves validation score 0.617 and LB 0.595.

UPDATE: PyTorch NER Starter Notebook - LB 0.600

I posted a PyTorch starter notebook that uses BigBird backbone here. The notebook trains one fold and achieves F1 validation score 0.608 and LB 0.596. 

The PyTorch notebook also demonstrates how to create targets from the predicitonstring column. And demonstrates how to use a dataloader which is necessary if we want to add data augmentation during training. Therefore even TensorFlow users can benefit from reading the PyTorch starter (and can consider adding these features to their TF notebook). 

BigBird is a new SOTA transformer model. The research paper was published in July 2020 to arXiv here
