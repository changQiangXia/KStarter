Topic #379690: Hill Climbing for ensembling
  Author: Samuel Cortinhas
  Posted: 2023-01-20 16:47:45.963000
  Votes: 61  Comments: 39

I wanted to learn something new this week so I've been experimenting with Hill climbing. This is a technique for automatically ensembling predictions by iteratively searching for the best model (and best weight) to add to the current ensemble. The models are evaluated using out-of-fold predictions, so you need to save these each time. 

Pseudo-code:

while not STOP:
    potential_new_best_cv_score = auc(y_train, current_best_ensemble)
    for k in MODELS:
        for wgt in range(-0.5,0.51,0.01):
            potential_ensemble = (1-wgt) * current_best_ensemble + wgt * MODELS[k]
            cv_score = auc(y_train, potential_ensemble)
            if cv_score &gt; potential_new_best_cv_score: 
                potential_new_best_cv_score = cv_score
                k_best, wgt_best = k, wgt

    current_best_ensemble = (1-wgt_best) * current_best_ensemble + wgt_best * MODELS[k_best]
    MODELS.drop(k_best)
    if MODELS is None:
        STOP = True


It improved my CV by nearly 1%, small yes but I can definitely see it being very useful in the big competitions.
