Dear all, 

I have noticed a tendency to use apply method during the feature engineering. It works ok for the small dataset (the one we have for this competition) but it fails to scale up for the bigger ones. I am not going to reference the authors (there is no intention to point the finger). Here are some examples:

1

 ():
     x &lt;=:
         
    :
         

df[] = df[].apply( x: is_young(x))


2

og[] = og[].apply( x:   x ==   )


The alternative is to use the generic binary operations. Not only it speeds the things up but it is elegant:

df[] = df.Age.le().astype()
og[] = og.Attrition.eq().astype()
