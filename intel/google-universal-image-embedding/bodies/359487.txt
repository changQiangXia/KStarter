TLDR Brief Summary

We use as baseline the content from the famous repo https://github.com/mlfoundations/open_clip

Our solution is an ensemble of 2 CLIP models trained using sub-center ArcFace with adaptive margin loss, each model produces a 512D descriptor. A total of 9 models were trained consisting of 4 ViT-L-14-336 models and 5 ViT-H-14 models. 
The weights of these 9 models were then averaged to make 2 “model soups”. 

We created a 1024 dimensional embedding using the concatenated outputs of both models. We then used PCA to reduce the dimensionality from 1024 to 64.

CLIP Models

Pre-trained models from open_clip
ViT-L-14-336 : openai
ViT-H/14 on LAION-2B laion_s32b_b79k

Training Data

Google Landmarks 2020 : https://www.kaggle.com/competitions/landmark-recognition-2020/data

Products-10k : https://www.kaggle.com/competitions/products-10k/data

We did not find it beneficial to use more data for finetuning. Products and landmarks already represent 50% of this challenge data distribution.

Model Soup / Ensembles

When creating the model soup we had to find a way to diversify the models before averaging their weights. It was decided that we would train each model with a different augmentation technique on each run, then train one model without augmentations. For the final ensemble we used the following augmentation methods:

These augmentations were taken from this solution : https://www.kaggle.com/competitions/happy-whale-and-dolphin/discussion/319896

def transforms_happy_whale(image_path, image_size):
   image = cv2.imread(image_path)
   image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB).astype(np.uint8)
   aug8p3 = A.OneOf([
           A.Sharpen(p=0.3),
           A.ToGray(p=0.3),
           A.CLAHE(p=0.3),
       ], p=0.5)

   train_transforms = A.Compose([
           A.ShiftScaleRotate(rotate_limit=15, scale_limit=0.1, border_mode=cv2.BORDER_REFLECT, p=0.5),
           A.Resize(image_size, image_size),
           aug8p3,
           A.HorizontalFlip(p=0.5),
           A.ColorJitter(brightness=0.1, contrast=0.1, saturation=0.1),
           ToTensorV2(),
       ])
   return train_transforms(image=image)['image']


These augmentations were taken from this solution : https://www.kaggle.com/competitions/landmark-recognition-2020/discussion/187757

def transforms_cutout(image_path, image_size):
   image = cv2.imread(image_path)
   image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB).astype(np.uint8)
   train_transforms = A.Compose([
           A.HorizontalFlip(p=0.5),
           A.ImageCompression(quality_lower=99, quality_upper=100),
           A.ShiftScaleRotate(shift_limit=0.2, scale_limit=0.2, rotate_limit=10, border_mode=0, p=0.7),
           A.Resize(image_size, image_size),
           A.Cutout(max_h_size=int(image_size * 0.4), max_w_size=int(image_size * 0.4), num_holes=1, p=0.5),
           ToTensorV2(),
       ])
   return train_transforms(image=image)['image']


These augmentations are taken from this paper : https://arxiv.org/abs/1805.09501

def transforms_auto_augment(image_path, image_size):
   image = Image.open(image_path).convert('RGB')
   train_transforms = transforms.Compose([transforms.AutoAugment(transforms.AutoAugmentPolicy.IMAGENET), transforms.PILToTensor()])
   return train_transforms(image)


We created 4 ViT-L-14-336 models using the above augmentation methods with one model trained without augmentations (all 1 epoch).

We created 5 ViT-H-14 models using the above augmentation methods with one model trained without augmentations (all 1 epoch) and an extra model trained on the auto augment transforms for 2 epochs. 

We then averaged these weights and were left with a single ViT-L-14-336 and a single ViT-H-14.
