We are seeing some kagglers who want to get up to speed on the bioinformatics and function prediction. The problem seems to be that there is a lot of marerial out there: where to start? I hope we can help here.

A good place to start is "A (not so) quick introduction to protein function prediction" Authored by @predragradivojac (attached). It is actually a pretty quick introduction for computational people who have zero domain knowledge and want only the relevant stuff for tacking the problems in this competition. This will explain the motivation for the problem, how it is cast, etc. The third chapter, on CAFA is a bit dated, and while historically correct, the rules that we had for previous CAFA competition do not necessarily apply to the Kaggle challenge. The only source for Rules for CAFA 5 is on this site. Also, we use slightly different assessment metrics than in section 2.3 (again, Rules for CAFA 5).
