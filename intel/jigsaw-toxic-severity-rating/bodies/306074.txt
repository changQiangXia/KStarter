Trust Your CV - 1800th Public to 52nd Private!

Thanks for a great competition. Public leaderboard was very misleading since it only contained 5% of test data. For my final two submissions, I chose two submissions that were ranked 1500th and 1800th on public LB. They both finished at 52nd private. Each had my best leak-free CV score of 0.707, public LB 0.802, private LB 0.804!

RAPIDS FIL infers 100 million rows per second!

In this competition, i chose to use RAPIDS Forest Inference Library because it can infer up to 100 million rows of data per second! See blog here

Feature Engineering - roBERTa XGB

For each comment, we extract 768 features from roBERTa-base that was pretrained on old comp data with old comp targets. And we extract 1024 features from roBERTa-large that was pretrained on old comp data with old comp targets. Next we train XGB using these features and infer with RAPIDS FIL. We did not use Tfidf nor linear regression models.

Infer Every Possible Pair - RAPIDS FIL

Since inference is so fast, instead of predicting 14,000 toxic scores, we can predict 196,000,000 million combinations of every pair of toxic test comments. During inference we build a RAPIDS cuDF dataframe with 196,000,000 million rows and 3584 columns which represents every possible pair 14,000 * 14,000 = 196,000,000. Then we use RAPIDS FIL to predict every row and get 196,000,000 probabilities.

Convert Pair Probabilities into Toxic Scores

Based on the 196,000,000 comparisons of each of the 14,000 test comments with every other comment, we compute toxic scores for each of the 14,000 test comments and merge it unto submission.csv.
