The Workflow: From Observation to Implementation

Here is the breakdown of how specific EDA findings led to the modeling strategy in this notebook:

1. Strategy for the Original Dataset

  • Observation: The distribution of the Original Dataset differs noticeably from the Train/Test datasets (Covariate Shift).
  • Hypothesis: Concatenating the Original data to the Training set might introduce noise due to the distribution mismatch.
  • Approach: Instead of concatenation, I adopted the standard practice of using the Original data as an external reference for Feature Engineering. I created statistical features (e.g., Mean/Count encoding based on the Original data) and mapped them to the Train/Test sets to extract underlying signals without altering the training distribution.

reference: [https://www.kaggle.com/code/cdeotte/use-original-data-for-cv-boost-and-lb-boost]

2. Selective Target Encoding

  • Observation: Many "numerical" features in this dataset actually have very low cardinality (discrete nature). However, some are binary (0/1).
  • Hypothesis: Tree models might benefit from explicit probability mapping via Target Encoding for these discrete features. However, applying it to binary features is redundant.
  • Experiment: I implemented Selective Target Encoding, applying it only to numerical columns with nunique > 2, strictly calculated within the Stratified K-Fold loop to prevent leakage.

The Value of Experiment-Driven Approaches

While this notebook prioritizes an EDA-driven hypothesis (avoiding concatenation due to distribution shift), experiment-driven approaches are equally valuable.

  • Testing Counter-Hypotheses: Even if the distributions differ, simply concatenating the Original data as additional rows might still improve the score depending on the model's robustness. It is definitely worth testing.
  • Hypothesis from Experiment: sometimes, we find new insights only after running experiments that seem counter-intuitive at first glance.

I discarded the concatenation approach in this specific notebook based on my initial analysis, but I encourage you to challenge this assumption.

Potential Improvements

To further improve accuracy beyond this baseline, the following approaches could be effective:

  • Interaction Features (High-Cardinality & Target Encoding): Creating pairwise (bigrams) or higher-order combinations of discrete features is a powerful technique. This process intentionally creates high-cardinality features representing specific subgroups (e.g., "AgeGroup_BMI_Gender"). Applying Target Encoding to these specific combinations allows the model to capture fine-grained risk signals that single features cannot represent.

  • Referencing Past Top Solutions: Since the data structure shares similarities with previous tabular Playground episodes, reviewing and adapting Feature Engineering techniques from top-ranking solutions in the previous competition could provide significant boosts.
