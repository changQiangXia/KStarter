Regression imputation: Use regression analysis to predict the missing values based on the available data. For example, a linear regression model can be trained using the non-missing values of the feature as the independent variables and the feature with missing values as the dependent variable. The model can then be used to predict the missing values.

import pandas as pd
from sklearn.linear_model import LinearRegression
# Load the data
data = pd.read_csv('heat_flux_data.csv')
# Split the data into features with missing values and features without missing values
features_with_missing = ['x_e_out', 'D_e']
features_without_missing = ['Author', 'Geometry', 'Pressure', 'Mass Flux', 'D_h', 'Length', 'chf_exp']
# Create a linear regression model for each feature with missing values
for feature in features_with_missing:
   # Split the data into training and testing sets
   train_data = data[data[feature].notna()]
   test_data = data[data[feature].isna()]

   # Train the model on the non-missing data
   X_train = train_data[features_without_missing]
   y_train = train_data[feature]
   model = LinearRegression()
   model.fit(X_train, y_train)

   # Predict the missing values using the trained model
   X_test = test_data[features_without_missing]
   y_pred = model.predict(X_test)

   # Replace the missing values with the predicted values
   data.loc[data[feature].isna(), feature] = y_pred

Stochastic regression imputation is a variation of regression imputation that incorporates a random error term into the imputation process. Here's an example of how to implement stochastic regression imputation using Python and the statsmodels library:
In this code example, we first load the heat flux dataset and split it into features with missing values (x_e_out and D_e) and features without missing values (Author, Geometry, Pressure, Mass Flux, D_h, Length, and chf_exp). We then loop over each feature with missing values and perform stochastic regression imputation using the non-missing data as the training set and the missing data as the testing set. For each feature, we fit an ordinary least squares (OLS) regression model to the training set and predict the missing values in the testing set using the predict method of the fitted model. We add a random error term to the predicted values by drawing from a normal distribution with mean 0 and standard deviation equal to the square root of the mean squared error of the residuals from the OLS regression. Finally, we replace the missing values in the original dataset with the predicted values.

import pandas as pd
import numpy as np
import statsmodels.api as sm
# Load the data
data = pd.read_csv('heat_flux_data.csv')
# Split the data into features with missing values and features without missing values
features_with_missing = ['x_e_out', 'D_e']
features_without_missing = ['Author', 'Geometry', 'Pressure', 'Mass Flux', 'D_h', 'Length', 'chf_exp']
# Impute missing values with stochastic regression imputation
for feature in features_with_missing:
   # Split the data into training and testing sets
   train_data = data[data[feature].notna()]
   test_data = data[data[feature].isna()]

   # Train the regression model on the non-missing data
   X_train = train_data[features_without_missing]
   y_train = train_data[feature]
   model = sm.OLS(y_train, X_train)
   results = model.fit()

   # Predict the missing values using the trained model and a random error term
   X_test = test_data[features_without_missing]
   y_pred = results.predict(X_test) + np.random.normal(loc=0, scale=np.sqrt(results.mse_resid), size=len(test_data))

   # Replace the missing values with the predicted values
   data.loc[data[feature].isna(), feature] = y_pred

Semi-supervised imputation is a method for imputing missing values using both labeled and unlabeled data. Here's an example of how to implement semi-supervised imputation using Python and the sklearn library:
In this code example, we first load the heat flux dataset and split it into features with missing values (x_e_out and D_e) and features without missing values (Author, Geometry, Pressure, Mass Flux, D_h, Length, and chf_exp). We then split the data into labeled data (data with no missing values in x_e_out and D_e) and unlabeled data (data with missing values in x_e_out and/or D_e). We fit a regression model to the labeled data using the Ridge class from the sklearn library and use a label propagation model from the LabelPropagation class to propagate labels from the labeled data to the unlabeled data.
To impute missing values, we first predict the labels of the unlabeled data using the predict method of the label propagation model and then predict the missing values in the unlabeled data using the trained regression model. Finally, we update the original dataset with the predicted values.
Note that the choice of kernel and number of neighbors in the LabelPropagation class can be adjusted to fit the specific characteristics of the dataset.

import pandas as pd
from sklearn.linear_model import Ridge
from sklearn.semi_supervised import LabelPropagation
# Load the data
data = pd.read_csv('heat_flux_data.csv')
# Split the data into features with missing values and features without missing values
features_with_missing = ['x_e_out', 'D_e']
features_without_missing = ['Author', 'Geometry', 'Pressure', 'Mass Flux', 'D_h', 'Length', 'chf_exp']
# Split the data into labeled and unlabeled data
labeled_data = data[data[features_with_missing].notna().all(axis=1)]
unlabeled_data = data[data[features_with_missing].isna().any(axis=1)]
# Fit a regression model to the labeled data
X_labeled = labeled_data[features_without_missing]
y_labeled = labeled_data[features_with_missing]
model = Ridge(alpha=0.1)
model.fit(X_labeled, y_labeled)
# Use the labeled data to propagate labels to the unlabeled data
label_propagation_model = LabelPropagation(kernel='knn', n_neighbors=5)
label_propagation_model.fit(X_labeled, y_labeled)
# Impute missing values using the semi-supervised approach
X_unlabeled = unlabeled_data[features_without_missing]
y_unlabeled = label_propagation_model.predict(X_unlabeled)
y_pred = model.predict(X_unlabeled)
unlabeled_data[features_with_missing] = y_pred
data.update(unlabeled_data)

Note that the choice of regression model can be adjusted to fit the specific characteristics of the dataset. Additionally, it is important to check the assumptions of the chosen regression model (e.g., linearity, normality of residuals, homoscedasticity) to ensure that the maximum likelihood estimates are reliable.

data = pd.read_csv('heat_flux_data.csv')

Multivariate imputation by chained equations (MICE) is a method for imputing missing values by modeling each incomplete variable as a function of the remaining variables, and iterating this process until convergence. Here's an example of how to implement MICE using Python and the fancyimpute library:
In this code example, we first load the heat flux dataset into a pandas dataframe. We then perform multivariate imputation by chained equations using the IterativeImputer class from the fancyimpute library. The IterativeImputer class implements the MICE algorithm and can handle both continuous and categorical data.
Finally, we convert the imputed data back to a pandas dataframe using the original column names.
Note that MICE assumes that the data are missing at random and that the missing values are ignorable given the observed data. Additionally, it is important to ensure that the imputed data are consistent with the characteristics of the original data (e.g., mean, variance, distribution, correlation structure).

import pandas as pd
from fancyimpute import IterativeImputer
# Load the data
data = pd.read_csv('heat_flux_data.csv')
# Perform multivariate imputation by chained equations
imputer = IterativeImputer()
