The Inference notebook is in:
https://www.kaggle.com/code/yiheng/3d-solution-with-monai

Its latest version contained the trained weight of v5 mentioned in the following table, which gets 0.868.
Tips about how to get 0.872 (v6) is mentioned in Update 4, and do a five folds ensemble can get around 0.877 (the inference notebook can be used directly for multiple folds ensemble, you just need to put more weight files into the corresponding dataset).

The preprocessing notebook is in:
https://www.kaggle.com/yiheng/3d-solution-with-monai-produce-3d-data

The training pipeline is uploaded as a dataset, since I use .py files rather than notebooks in training:
https://www.kaggle.com/datasets/yiheng/uw3dmonaitrainingpipeline

The first version is a basic 3D UNet, the input patch size is (160, 160, 80) by using RandSpatialCropd transform for the original volume.
I used @awsaf49 's data split from his notebook, the local (dice) and LB scores for my 2D and 3D models seem comparable:
