Summary

My overall solution is similar to the 2nd place solution, but without 3D models. My solution is to use the detector to detect the main area, then use the classifier to judge whether it needs to be segmented, and finally segment the image that needs to be segmented, and only keep the segmentation results that the classifier judges as positive samples.

Detail
  • 5 Fold cross validation by group spliting case
  • Only 2.5D Models (slice=3 and slice=5)
  • Pre-processing(crop with a detection model), refer to [bestfitting], [Guanshuo Xu]
  • My training pipeline (cls + seg method and swa for models) is based on our siim acr solution (SIIM-ACR Solution)

Models

Pre-processing

  • EfficientDet-D0, size=256, epoch=5, all other parameters use default parameters. This is a very easy task for the model to learn. I generated some training samples using image preprocessing and relabeled the bad bounding box.

Cls part

Only use Unet(Smp-Unet and Timm-Unet) with different backbone and classification branch,Timm-Unet refer to selimsef's xview3_solution, Thanks for his sharing, Then I made some modifications to the network for this competition.

  • Cls branch loss: bce loss
  • Seg branch loss: bce loss
  • Using ema (refer to DungNB) and swa
  • Epoch=35(7 cycle)
  • Init lr=3e-4 or 5e-4
  • Data: use all data
  • Metric for select model: TP / (TP + FP + FN) and Dice score
models
  • Smp-Unet efficientnet-b7, size=320, slice=5
  • Timm-Unet efficientnet-v2-l, size=320, slice=3
  • Timm-Unet efficientnet-v2-l, size=320, slice=5
  • Timm-Unet efficientnet-v2-m, size=352, slice=5
  • Timm-Unet efficientnet-b7ns, size=320, slice=5

Seg part

For the classification model, I mainly focus on the accuracy of the classification. For the segmentation model, I hope to obtain a better and better segmentation effect, so I train the segmentation model separately.

  • Cls branch loss: bce loss
  • Seg branch loss: ComboLoss({'bce': 0.5, 'dice': 0.5, 'lovasz': 1}
  • Data: All positive samples
  • Using ema and swa
  • Metric for select model: Dice score
  • Timm-Unet efficientnet-v2-l-1 and Timm-Unet efficientnet-v2-l-2 use different scale pretraining adjustments
models
  • Timm-Unet efficientnet-v2-l, size=384, epoch=35, slice=5
  • Timm-Unet efficientnet-v2-l-1, size=416, epoch=35, slice=5
  • Timm-Unet efficientnet-v2-l-2, size=416, epoch=35, slice=5
  • Timm-Unet efficientnet-v2-m, size=416, epoch=35, slice=5

Post-process

  • Remove 25 pixel part
  • Take three consecutively predicted positive samples as the starting point and three consecutively predicted negative samples as the end point(very small improve)

Work for me

  • Add a detection model(It greatly reduces the resources used for training)
  • Add some segmentation models for positive sample(0.886->0.890)
  • Mixup and cutmix are work for segmentation models
  • The swa has a relatively large increase in the single fold, and the score increase is not much different when the 5 folds ensemble.

Not work for me

  • Make some brightness adjustments to the data(spent a lot of time)
  • Hausdorff distance loss function
  • External dataset(CT), maybe need some processing with GAN models
  • Positive and negative sample balance
