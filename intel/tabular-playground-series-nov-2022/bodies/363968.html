Ensemble Learning

Essentially, ensembling takes the predictions from multiple models and combines them to create a more accurate single prediction. Ensembling is relevant to this competition because instead of getting raw data, we are given multiples models predictions, so we need to ensemble these predictions.

There are 3 main ways to go about ensemble learning for a kaggle challenge:

  • basic mean - just a simple average of multiple predictions
  • leaderboard probing - weighted average of predictions with weights selected by hand based on the optimal score from the public leaderboard
  • cross validation tuned - the best technique, uses the training data to tune weights or a meta model to merge predictions

Blending and Stacking are types of ensembles.

Blending

Since we are given a bunch of prediction files, the easiest thing to do is to start with a blend.
Here is what to do:

  1. Define a Meta-Model - this will be a machine learning model used to merge the predictions from other models. I like to start with sklearn's LogisticRegressionCV (LassoCV or RidgeCV for regression) because the are pretty decent models with built in cross validation, so it is easy to set a baseline. Anyway, feel free to use any model you like though (xgb, lgbm, svm, neural net, etc).
  2. Since we already have prediction files, preprocess the data so each prediction column is its own feature ready to be inputted to train the meta-model.
  3. Train the model like any normal tabular task and have the model output your new meta predictions that you can submit.

Stacking

Stacking generalization is similar to blending, but it has multiple layers and a more complicated cross validation system.

  1. Setup the prediction files as features the same way you would do for blending.
  2. Define and train multiple complicated models (e.g. 1 xgb, 1 lgbm, 1 nn, etc) and train each of those models for n folds.
  3. Define a more simple meta-model (e.g. logistic regression or ridge regression) to take a weighted average of all those predictions to produce your final predictions.

  • note you can also take blends of blends and stacks of stacks and keep repeating this process until the accuracy converges and you can improve no more.
