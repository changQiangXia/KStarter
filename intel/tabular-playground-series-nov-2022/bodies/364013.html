The competition description contains a piece of information which seems to be neglected in many public notebooks and discussion posts:

In this competition, you are given a folder of submissions that contain predictions for a binary classification task.

They say predictions rather than features, yet everybody is throwing the usual machine learning algorithms at the data. How can we exploit the fact that we are given predictions rather than features, albeit the predictions are of dubious quality?

Let's try some reverse engineering! The diagrams clearly show that the model predicts probabilities which are too high. How can this happen? I assume that the model was trained on data that has the same distribution as the competition dataset, but during training, the positive samples were weighted higher. Maybe the positives were oversampled, the negatives were undersampled, or the model was simply trained with a wrong class_weight parameter.

If this hypothesis is true, the predictions can be corrected by subtracting a constant from the logits:

x = scipy.special.expit(scipy.special.logit(x) - 1.17)

Equivalently, one can fit a logistic regression model to the logits:

LogisticRegression.fit(scipy.special.logit(x), y)

In a previous post, I showed how predictions can be calibrated with isotonic regression. Isotonic regression improved the cv score of a single model (0.6475577136.csv) from 0.6476 to 0.5286. Shifting the logit improves the same model's cv to 0.5281. We get this improvement because isotonic regression overfits a step function whereas logistic regression fits only one parameter to compensate for the wrong class_weight.

The real improvement, however, doesn't show up in the single model, but when we use the whole dataset. Logistic regression on the original dataset gives a cv score of 0.5318; logistic regression on the logits improves the cv to 0.5258.

Lessons learned

  1. Recommendation: replace the whole dataset by its logit before feature selection, dimensionality reduction and modeling.
  2. Always look for pieces of information that haven't been exploited yet.
