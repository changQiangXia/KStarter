Utkarsh Gaikwad's notebook has been at the top of the public notebooks for three days now with a rmse of 127439. It uses Pycaret, an open-source, low-code machine learning library that automates machine learning workflows.

What does Pycaret do in this notebook?

  1. It cross-validates and compares 20 different models with default hyperparameters and finds that RandomForestRegressor gets the best RMSE.
  2. It refits the RandomForestRegressor with default hyperparameters to 70 % of the training data.
  3. It predicts the test prices with this model.

Note that

  • You can make Pycaret tune the hyperparameters by calling tune_model(). The notebook doesn't.
  • You can make Pycaret refit the model to the complete training data by calling finalize_model(). The notebook doesn't.

The obvious question is: If we fit the same model to the whole training data, does the score improve? More data is always better, isn't it? I did the experiment and the score deteriorated from 127439 to 155871.

Lesson learned: Discard 30 % of the data and you get a better score! 🙃

Perhaps there is something else to be learnt: The competition has been set up so that rmse fluctuations of >10000 points are standard. Don't be fooled by these fluctuations when you compare different approaches!
