Topic #548249: How To Use "Batch_Size>1" and get Correct Perplexity Score!
  Author: Chris Deotte
  Posted: 2024-11-25 20:11:29.659000
  Votes: 92  Comments: 30

The below two steps show how to compute correct perplexity with batch size &gt; 1. Just add these two changes to the metric.py file (v29 with float16 not 8bit) provided by Kaggle

Tokenizer Pad Right Side

The secret to using batch_size&gt;1 and computing the correct perplexity score is to pad the tokenizer on the right: 

self.tokenizer = transformers.AutoTokenizer.from_pretrained(model_path,padding_side="right")

By default, the tokenizer will pad on the left and then when we shift the labels (before cross entropy calculation) we would remove a pad token instead of removing the &lt;bos&gt; token. And the LB score removes the &lt;bos&gt; token before computing the token average for our LB score.

Mask Pad Tokens when Compute Loss

Also, we need to update get_perplexity() to accept a parameter named batch_size and process batches. And, we need to update get_perplexity() function to mask the pad tokens from cross entropy calculation. The code below works:
