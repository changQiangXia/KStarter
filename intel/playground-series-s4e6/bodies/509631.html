After we saw the notebook, which used ROC AUC instead of Log Loss, we also implemented and tested how it would perform. This, however, did not improve performance.

Overview of Other Offline Evaluation Results

In our offline evaluation, we also came to the following conclusions:

  • Treating ordinal features as numerical features is beneficial.
  • Using original data is better for model performance (even with its distribution shift).
  • Using sample weights does not help.
  • Using repeated cross-validation is beneficial.
  • Using transductive learning is beneficial. Yet, we did not use it in our submissions as we did not trust the results of our test.
  • We verified that gradient-bosted decision trees (GBDTs) and neural networks (NNs) are both capable of solving this task.

Stacking

We noticed that NNs were much better than GBDTs among all stacking models. Based on our prior work on stacked overfitting, we knew this pattern and thus opted not to use GBDTs as stacking models anymore, which further improved offline performance.
