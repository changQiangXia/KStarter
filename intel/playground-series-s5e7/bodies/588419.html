After completing a through EDA and a Feature Engineering (based of RF). I present to you the below findings. If you have any more findings or observations I am eager to learn.

Key EDA Take-aways

  • Extreme solitude is a near silver-bullet:
    • Time_spent_Alone > μ + 2 σ → ~94 % of rows are Introverts.
  • Both Boolean flags are almost one-shot Introvert indicators (Stage_fear = Yes, Drained_after_socializing = Yes each give > 90 % Introvert).
  • Numeric variables shift monotonically between classes (median gaps 3–6 units).
  • 5–10 % missingness appears MCAR/MAR; the absence of a value itself carries signal.
  • No measurable train–test drift (KS p-values > 0.75 everywhere).

Why the EDA Features Win

  1. Human priors: each flag embodies a clear behavioural rule, so RF splits align with reality.
  2. Dense not sparse: interaction strings explode the cardinality; forests treat rare categories as noise.
  3. Single-split power: ratios turn curved boundaries into axis-aligned ones the RF can capture early.
  4. Easy pure nodes: high_alone_flag isolates a 94 % Introvert island—trees lock onto it immediately.

Final Blend

A weighted average of the four best CV models (A, B, C, C_top30) using inverse log-loss weights produced the most stable leaderboard score.
Weights were nearly uniform (≈ 0.25 each) because all four LLs sit within 0.00055 of one another.

Take-aways for Fellow Kagglers

  • Start with intuition-based features before carpet-bombing interaction space.
  • If you add hundreds of categorical combos, trim them with feature-importance or you risk dilution.
  • PCA can hurt when your model relies on categorical purity; consider it only for linear models.
  • Random-Forest (or any tree stack) loves explicit threshold flags—cheap, fast, effective.
