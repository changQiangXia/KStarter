The competition provides a summary of the metric and a code to generate required predictions. This metric is new to me, so I read those two links and do a bit more research. In this post, I will try to explain what I learnt from them in my own understanding.

Why a new metric?

So far this year, all playground classification tasks are binary: positive/negative classes. This is the first time, we have a multi-class classification problem: 11 diseases.



For binary classification, we often use either ROC AUC or log loss. In both metrics, we submit predicted probabilities. The ROC curve shows how well the model is able to rank these probabilities for the positive and negative points. Log loss is more about absolute value of the predictions (e.g., if a point is positive (1.0), the prediction of 0.9 will have a better score compared to the prediction of 0.8; however if a point is negative (0.0), the prediction of 0.9 will pay a stronger penalty).

For multi-class classification, negative log-likelihood (an extension of logloss) can be used. If the classes are balanced, simple accuracy is an alternative. However, in this competition MAP@3 is chosen. 
The limitation of those metrics is that only the most probable prediction is considered. For example, in a 1000-way image classification, predicting the correct class is really difficult if you only have one chance, and it's not very useful to compare model performance if all models perform poorly on their top choice. We need a more forgiving metric. 


What is it all about?

Top-5 accuracy is one metric where you can submit 5 predictions and you get a full point if any of them is the same as the true answer. MAP@3 is a similar metric but it takes into account the order of your predictions: you get a higher score if you're correct at your earlier guesses. 
In MAP@3:



for each row: the solution is X and you make 3 guesses [A,B,C]. If you're correct in your first choice (X==A), you get a full point 1.0. If X==B, you get 0.5. And if X==C you get 0.33.

then you simply take an average of those scores.
The provided code is a bit complicated because the ground truth could be a list (like in movie recommendation). But in this competition it's just a single disease. So, it's reduced to a very simple form.


Is it a reasonable metric?

Yes, I think so, considering this example. You go to see a doctor because you have a fever. Based on your symptoms, the doctor thinks you might get a common cold, a flu or covid; in that order of reducing probability. Then, the doctor could ask you to carry out some tests to check if you have a common cold or not (well, I'm exaggerated  here). If it's actually a common cold, full stop. Otherwise, you need to be carried out another examination to see if you have a flu, and so on. So, apparently, it's important to consider multiple predictions and the earlier the doctor guesses right, the better.
Thank you for reading.
