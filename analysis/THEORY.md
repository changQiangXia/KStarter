## A. 数据生成与泄漏

### L1｜生成器状态即特征：顺序生成的数据集里，"索引"就是最便宜的一等特征
- **机制**：同生成器顺序产出 → 索引记录生成进度/随机状态；随机数缺陷让"同 seed + 相近参数"的两行共享大部分抽样结果（feb-2022 的失配率=TV 距离×长度，0.10×30≈3 与官方示例吻合）；ID 位移让"训练尾部≈测试分布"（s5e12 的尾部 2.3 万行/≈3%）。
- **适用**：Playground/合成数据类比赛；边界：ID 与目标无因果，仅当生成器顺序化时成立。
- **证据**：feb2022（重复行对+3 位失配机制）、s5e12（ID 分界 + post-cutoff CV）、nov2022（输入是预测→先验偏移 e^1.17≈3.22）。

### L2｜泄漏有三种粒度，防御手段一一对应
- **机制**：行级复制（同 seed 生成对）→ 反变换+最近邻吸附/Union-Find 分组；患者/实体级（同段信号增广、同图近重复）→ 组 CV + 反增广/嵌入去重；跨届级（历史比赛同题/同图）→ 定向利用或定向防御（先检测重叠再决定）。
- **反例**：hms 未反增广时 CV-LB 相关性差（反增广后 6,350 行"真实点"才恢复）；petfinder 全量混训往届数据无效，只有"定向近重复后处理"有效。
- **证据**：feb2022、hms、petfinder、jigsaw（union-find）、s5e12。

### L3｜标签口径必须与评测口径对齐；"谁来标"本身就是数据分布
- **机制**：评测由子人群标注时，模型分布被直接测（KL）或被排序口径测（agreement）；用全量标签训练=系统性错配。
- **证据**：hms（测试专家癫痫率 1.5% vs 全量 18.8%；vote_count≥10 作近似，两支队伍独立采用）；jigsaw（标注者分歧决定上限<1）；amex（短序列子群违约率 23%→39%→45%，合并学=被稀释）。

## B. 验证与评测

### L4｜CV 与榜单的偏差有方向性：先判方向，再决定信谁
- **机制**：① 证据源单一（如纯 GR/纯文本匹配）且公开榜样本小 → 公开"宽松"，Δ(公开−CV)<0 → 私榜回落（rogii 6th：−0.78 对应私榜 7.40 vs CV 7.50；加物理先验后 Δ≈0）；② 测试含历史泄漏子集 → 私榜被抬高、CV 低估（jigsaw：验证 0.70 级 vs 私榜 0.81，+0.10）。
- **裁决规则**：先量化"泄漏/分布红利"的方向与量级，再选择信任对象；无泄漏证据时应信 CV。
- **证据**：rogii 6th/1st/2nd、jigsaw、s5e12。

### L5｜验证集的合格标准是"对少数主导样本不敏感"
- **机制**：pooled 类指标 ∝ ΣSSE，灾难样本（单井 RMSE 34 ft）可吞掉 0.3+ 均值；148 井量级的私榜会让随机划分决定名次。
- **做法**：LCO 剔除曲线（改进剔 8/773 井即消失 → 拒；剔 52 井仍在 → 收）；患者/井级分组；fold 方差最小化（重抽 split std≈0.015）；多 split 平均（5×5）。
- **证据**：rogii 2nd/3rd/6th；hms（患者分组）；amex（统一折与 holdout）。

### L6｜小榜单的"排序"是噪声，只有"绝对水平"可参考
- **机制**：公开=私榜子集（rogii：52/200 井）；两模型真实差 0.05 时排序可完全反转（7th 的公开排序恰为 CV 镜像；私榜回归 CV）。
- **适用**：一切 split 小于全量 10% 的公开评测；反例：当公开样本足够大到与私榜同分布时该条失效。
- **证据**：rogii 7th（1.75% bootstrap 论证的漏洞）、s5e12（post-cutoff CV 才是真尺子）、jigsaw（私榜+0.10 错位）。

### L7｜互补性的可操作判据：分布距离 / 误差相关性，而不是模型强度
- **机制**：两个模型的预测分布 CDF 越分离（KS 越大）、误差相关越低 → 融合增益越大，弱模型也可拿大权重；反之，与现有候选 0.99 相关的新候选"什么都没加"（对强基线残差自相关≈1.0 时，唯一增量方向是"错误方向不同"的信息源）。
- **证据**：s5e12/nov2022（KS/CDF 判据）、rogii 6th（0.99 相关无用）、optiver（time-id 近邻 #197 + stock-id 近邻 #5 → 叠加 #2）。

## C. 表示与问题重构

### L8｜问题重构优先于模型：把任务降解为"结构已知的问题"
- **机制**：回归 → 对齐/状态估计（rogii：2D 对齐、条件分布+DP、HMM；orbit-wars：舰队折叠为行星未来态、语义动作）；顺序恢复（optiver：tick size → 时间序）；频谱语义（hms）。
- **证据**：rogii 全员、orbit-wars 全员、optiver（时间序三种用途）、hms（先变换后合并）。

### L9｜输出空间的形态必须匹配问题的多模态性
- **机制**：后验多峰时，点回归坍缩到"不存在的均值"（±8 ft 平均 0 ft）；正确形态 = 概率图/条件分布/候选 + 期望或硬分支；同一场里"连续候选族软平均、离散假设硬选择"并存。
- **证据**：rogii 2nd/6th/36th/7th；nov2022（先验偏移的近常数结构 → 单参数校准优于灵活 isotonic）。

### L10｜用最少参数拟合已知结构；损失服从目标分布形状
- **机制**：已知偏差是常数 → 单参数平移/增益（nov2022 的 ln(w)≈1.17；rogii 6th 的 de-shrink a≈1.03）；目标有界 → BCE/裁剪（petfinder）；指标是 KL → KL 训练（hms）；分位/排序 → 秩变换（jigsaw）。
- **反例**：ECE 当特征筛选器（nov2022 3rd，"用错工具比不做更糟"）；灵活模型逼近已知常数结构 = 白白加方差。
- **证据**：nov2022、rogii 6th、petfinder、hms、jigsaw。

### L11｜非线性变换与线性合并的顺序不可交换
- **机制**：`f(a+b) ≠ f(a)+f(b)`；先合并再变换会消掉被抵消的分量（hms：差分链求和只剩 Fp1−O1），应"先变换、后合并"（各差分分别取谱再平均，保留 4 段信息）。
- **适用**：任何"通道差/残差 + 非线性（谱、log、幂）"的特征工程。
- **证据**：hms（Magic Formula 与两种实现的分差）。

### L12｜语义动作/意图 > 数值分辨率（决策类任务）
- **机制**：让引擎/领域计算解算"具体多少、什么角度"（确定性算术），策略只学"打哪、为什么"（战略判断）；把连续数值维度从策略里删掉。
- **证据**：orbit-wars 3rd（语义动作学习提速）、simjeg（all-in-only 得第 2）、Jake（三档语义）、FLG（多比例档零增益）；反例边界：需要精细防守数学时语义档仍有用。

## D. 集成与融合

### L13｜融合层的复杂度必须匹配数据量：约束越强、泛化越好
- **机制**：小数据下无约束高容量堆叠器过拟合 OOF；非负/和为 1 的凸组合把输出限制在候选包络内（rogii 3rd 门控胜无约束精修器 0.1226，5 折全胜）；手调固定权重胜元学习（rogii 6th）；但集成候选足够多时软平均本身即最优（限制 top-k 有害）。
- **证据**：rogii 3rd/6th；petfinder（爬山前向选择）；amex（0.9 权重稳健的幸存者样本警告）。

### L14｜排序类指标优先用秩平均/校准不变融合
- **机制**：秩变换抹平校准差异，只保留排序信息，与 agreement/排序指标天然匹配；对泄漏模型的"记忆优势"也最不敏感。
- **证据**：jigsaw（15 模型秩平均夺金）、petfinder（分类头 + SVR 头混合）、nov2022（CDF 判据）。

## E. 训练动力学（自对弈 RL）

### L15｜熵是分类动作空间的第一训练旋钮；崩溃有前兆
- **机制**：熵过高 → 小优势方向被稀释、策略漂移到 no-op（3rd 4p 首跑 ent 0.05 直接停止发射；13th 用 0.02/0.01；Jake 用 no-op KL 锚替代）；前兆信号 = clip_frac 单调爬升（0.10→0.30+）先于熵塌/KL 尖峰。
- **证据**：orbit-wars 3rd（0.05→0.0005 调度）、Jake（10% 发射率锚）、lightmk 附件（clip_frac）。

### L16｜已决局的处理是终端奖励 RL 的最大效率杠杆（且有崩溃风险）
- **机制**：γ=1.0 无时间偏好 → 学会拖局（1st 的训练算力黑洞）；价值头自评"已胜/已败" → 早停/投降（Jake 砍 60–70% 回合；7th 式早停省 ~18%）；但终止条件会改变残局价值学习（13th resign 试验致稳赢局崩溃而弃用）。
- **证据**：orbit-wars 1st/Jake/FLG/13th。

**Batch 2 增补（L17–L28）**

### L17｜伪标签/蒸馏：可以转移"表示"，不可以转移"分布"
- **机制**：直接把源域软标签混入训练 → 学到源域的标签尺度/泄漏结构（CV 虚涨、LB 不动）；把源域数据当**预训练**、再在目标域微调 → 表示被留下、分布被重校准。
- **证据**：rogii 6th（FP1 目标分布整体高于 FP3：CV 0.4470→0.4370 而 LB 不变）；feedback-ell 3rd（FP1→FP3 同现象，直方图物证）；lmsys（PL 打断 CV/LB 相关性，泄漏子集收益不转移）；对照：feedback-ell 5th 的"预训练式两轮 PL"稳定增益、lmsys 1st 的 logits 蒸馏。

### L18｜"受控源头预训练"优于目标端堆叠（起点选择是一等决策）
- **机制**：先让模型获得任务相关的**能力**（比较/偏好、回译不变性、IR 通道），下游只做格式与领域适配。
- **证据**：lmsys（reward/pair-preference 起点 > chat 起点，4/6 家独立采用；5th 用 UltraFeedback 二分类预训练 +~0.02）；feedback-ell 2nd（回译/FB2 预训练单模 0.4514→0.4488）；vesuvius 6th（IR 图像进训练 +0.01）。
- **边界**：跨域数据或错误阶段（单库预训练、EMNIST）会反向伤害——见 T8。

### L19｜缺席即事件：缺失指示是与领域语义耦合的特征
- **机制**：非随机缺失携带状态信息（停牌/失访/停机）；显式指示允许模型对不同"缺席状态"使用不同映射。
- **证据**：ubiquant 17th（停牌 missing：0.115486→0.117721 ≈ 67 个名次）；rsna（冷启动商品永远无法靠交互信息排名——1st 直接放弃）；hms 的"标签来源位移"亦属同类结构。

### L20｜横截面/时间步归一化：把 regime 从特征里剥离
- **机制**：按时间步（市场状态）聚合/标准化特征与目标，模型只需学"相对强弱→相对收益"的稳定映射。
- **证据**：ubiquant 1st（+100 个 time_id 均值特征：单模 CV 0.141→0.154）；ubiquant 2nd/17th（行级宏聚合、per-time_id 目标标准化）；h&m 的"窗口选择也是超参"（25 周配置 CV 第 4、LB 垫底）。
- **反例/张力**：同一手法在 Transformer 上被报告无效（ubiquant 3rd）——特征工程必须按模型家族定向验证（见 T7）。

### L21｜时间验证纪律：purge/embargo 与"口径不可比"
- **机制**：前瞻目标造成标签窗口重叠 → 不 purge 就没有可信 CV；多轮滚动评估（update1…final）让跨轮分数不可比，只有轮内相对名次有信息。
- **证据**：ubiquant（2nd 的 Purged K-Fold + embargo；5th 20 折 + purge 10；3rd/5th 的名次轨迹 900+→3、1344→5）；rogii（LCO 剔除曲线的同族思想）；santa（纯优化赛连 CV 都不需要——评估即精算）。

### L22｜度量敏感的选择游戏：阈值/提交策略本身是分数
- **机制**：概率化/阈值化指标（pF1、F0.5、MAP 类）对阈值极敏感；OOF 最优 ≠ 榜单最优；多阈值/多版本提交是低成本对冲。
- **证据**：rsna（OOF 最优 0.34 → LB 0.58；LB 峰 0.31 → 0.61；4 个阈值提交把 600 名打到 22 名）；vesuvius（单模型 best_th 可低至 0.1；阈值三路线）；ubiquant（跨轮分数不可比——0.1331 的第 3 轮是第 4 名，0.1232 的第 5 轮是第 2 名）。

### L23｜校准可以由集成"免费"获得
- **机制**：多模型预测平均 → 概率方差收缩、单模型阈值敏感性下降；平均后阈值趋近 0.5。
- **证据**：vesuvius 1st（单模型阈值范围宽、平均后"几乎普遍居中 0.5"）；ventilator（better_than_median 融合）；rsna 的校准讨论；与 L13（融合层复杂度）互补。

### L24｜融合的坐标系：在"任务对象层"而不是"模型私有层"
- **机制**：token/subword 是模型私有实现，跨度/实体/排名是任务对象；跨模型融合要在对象层做（起止平均、50% 重叠分组、秩融合），token 层平均会产生病态（双 B、并集/交集）。
- **证据**：feedback-prize-2021（WBF 平均起止 0.700→0.741；实体级 50% 分组 +0.002）；lmsys/otto（rank blend 与 (score,rank) 堆叠）；santa（无跨模型融合需求，纯优化）。

### L25｜指标的"宽容度"决定后处理自由度
- **机制**：≥50% 重叠计对 → 允许长度平移/交叠容忍；像素级 F0.5 → 低分辨率输出+上采样; MAP@12 → 热门地板高。反过来严格指标（IoU/边界）下同样的技巧会反噬。
- **证据**：feedback-prize-2021（2nd 的 PP ~+0.008、3rd 允许 0.2 交叠）；vesuvius（1/32 输出，"粗分割更容易"，1st 猜测 + 2nd 实证）；otto（候选召回上限锁定 95% 分数）。

### L26｜先最大化"可解析部分"：逆问题/规则引擎 + 模型残差
- **机制**：数据生成器若可逆向（有限参数网格、离散量化、确定性控制），则优先用规则精确解出可解部分，模型只学残差。
- **证据**：ventilator（PID 匹配 66%+5–6pp、PI 反演 85%，匹配即 MAE=0；噪声结构可识别）；feb2022（RNG 同 seed 配对）；hms（反增广 6,350 行）；amex（行级污染修复）；otto（"纯规则 0.590，reranker 仅 +0.011"）。

### L27｜搜索类比赛：局部精修速度 = 搜索宽度；结构化种子降解自由度
- **机制**：全局搜索（GA/SA/Sparrow）产生近可行解，局部精修（LBFGS/push/SA 末段）负责收敛；局部精修越快，相同时间内可尝试的变异越多。大 N 时用对称/晶格/边缘带把 O(N) 维搜索降解为"填边缘"。
- **证据**：santa（CUDA 松弛 30k 次/秒；10.56M SA iters/s；随机撒点只够 N≤40，晶体到 200）；orbit-wars（推理预算决定方法；被动 rollout 表示）。
- **推论（santa 的裁决）**：约束（对称等）是脚手架而非终态——终态须经实验检验（N<60 不对称更优：0.35765 vs 0.36091）。

### L28｜工程吞吐是跨场"通用货币"
- **机制**：在"迭代量→质量"呈单调关系的任务里（RL、启发式搜索、大规模特征工程），每秒吞吐的每一层加速都换算成分数。
- **证据**：santa（30k 松弛/秒、10.56M iters/s、增量碰撞 ~100×）；orbit-wars（环境重写 40K SPS；GPU PF 200×）；ubiquant（parquet 18GB→5GB/3.5GB）；rogii（GPU 粒子滤波 ~200×）；amex/otto（"迭代速度本身就是分数"）。

**Batch 3 增补（L29–L42）**

### L29｜标签空间工程：用样本/题目的结构把 N 类降解为 k 选 1
- **机制**：输出空间里大部分类别对给定样本"不可能出现"（每题固定候选集、每受试者固定组合）→ 把候选集注入输出层/提示，先验正确 + 推理成本按候选数缩小。
- **证据**：map-charting（每题 2–6 候选：3rd Masaya +0.002~0.003 且快 3×；1st 后缀分类；11th 1440 类 QA 头）；cmi-behavior（102 类组合标签）。

### L30｜指标病理学：读评测实现，而不是读指标名字
- **机制**：评测实现的每个古怪行为都是可攻击面或必须适配的约束（tokenizer 行为、特殊 token、长度截断、分布聚焦、处理顺序）。
- **证据**：llm-prompt-recovery（TF SentencePiece 字面 tokenize + eos 聚焦点 → lucrarea 攻击 +0.05；输出越短越准 0.715 vs 0.628）；llm-detect（PPL/GLTR 生成器无关特征）。

### L31｜多生成器/多来源数据覆盖：数据即方法
- **机制**：当评测分布不可知时，唯一可靠的"泛化面"是把生成器/来源的多样性做足；单一来源学的指纹在分布切换时失效。
- **证据**：llm-detect（1st 的 160k 多源 datamix，"建模影响较小、多个单模 0.970+"；8th 的 800k 微调 CV 0.98→私榜 0.674 是反证）；godaddy（补充 census/就业数据）。

### L32｜测试期域适应光谱：从"用测试特征"到"用测试训练"
- **机制**：合法使用测试分布的程度分级——插补拟合（cmi-piu 14th train+test）< 置信伪标签（3rd map / godaddy 探针）< 在线 TTT（jigsaw train-on-test）< teacher 在测试上蒸馏 student（llm-detect 5th）。强度越大收益越大，方差与违规风险也越大。
- **裁决纪律**：强度必须与验证可信度匹配；公开榜可作无偏验证时可用强域适应（jigsaw），否则保守（llm-detect 的教训）。

### L33｜公开榜能否当验证集是"赛制属性"，不是态度问题
- **机制**：随机划分 + 足量样本 → 公开榜≈无偏估计（可当验证集）；时间/分组划分、泄漏、生成器漂移、数据错误 → 公开榜是陷阱。
- **证据**：jigsaw-acrc（官方随机划分 30% → 1st/3rd/7th 以 LB 为准）；llm-detect（生成器漂移，私榜>公开）；godaddy（Dec/Jan 数据 60% 错误期探针失效）；psp-game（0.708=(0.698+0.718)/2 的泄漏读数）。

### L34｜无教师蒸馏：DML 互学习 + peer 多样性
- **机制**：二分类 logits 极尖（温度缩放无法软化）→ 放弃经典 KD，改用同规模 peer 的双向 KL 互蒸馏；错误相关性用第 3 个异质 peer 对冲。
- **证据**：jigsaw-acrc 6th（独立 0.921→DML 0.925；3-peer 0.9324/0.9278 私榜）。

### L35｜隐藏评分器的科学：侧信道 + 结构可行性 + token 经济学
- **机制**：不可见评分器（护栏/私榜）用"非分数通道"测量（运行时长/完成度/错误类）；先用可读代码证明哪些目标结构可达（数学封闭）；再在固定预算下优化单位时间得分。
- **证据**：ai-agent-security（运行时探针 5h08m vs 10h06m；CD 唯一可达；成本模型 0.52×hop+0.192×decode-tok；互质池 2,000 组合零重复；零宽空格绕过子串检查）。

### L36｜同题双提交对冲：把"不可见的一半"买成保险
- **机制**：当一半分数（私有护栏/私榜子集）不可观测时，用两组互补策略各买一份：一组冲可见分、一组求不可见存活；评分取较优使对冲免费。
- **证据**：ai-agent-security 11th（NB1 吞吐 30.04 + NB2 保守 19.33）；jigsaw-acrc 的"CD + DW"双押；godaddy 4th 的三阈值提交。

### L37｜容差型事件指标：target 整形 + 两极化流水线
- **机制**：多档容差匹配下，软目标（与容差同形状的核、逐 epoch 退火）比 0/1 更匹配指标；一级序列模型出候选，二级全局重排（建模"每晚≤2 事件"等约束）。
- **证据**：cmi-sleep-states（1st 逐 epoch 衰减 target +19pt、周期过滤 +17pt、后处理公开 0.768→0.790；2nd 三阶段 0.826→0.844）。

### L38｜排序型指标的追加预测套利：低分追加不伤分
- **机制**：AP/排序指标中，追加分数低于已提交项的预测不会降低得分、可能命中真值 → 主动输出 Top-k 降权候选。
- **证据**：cmi-sleep-states 11th（每夜 Top-30 除以 2^k：CV +0.050）；2nd 第三阶段偏移预测 +0.010；边界：仅在指标定义支持时有效（先读指标代码）。

### L39｜序数标签回归化 + 插补优先 + 高方差验证协议
- **机制**：序数标签是连续潜变量的阈值切分 → 回归到连续分数、评估时切档；缺失值（尤其医学问卷）用迭代/有监督插补，其权重常高于模型选择；QWK 类指标高方差 → 嵌套 CV + 多种子投票 + 折内阈值。
- **证据**：cmi-piu（PCIAT 连续目标；16th 不做插补私榜 0.470→0.412；种子扫掠 0.464–0.472；QWK 自定义目标 CV 0.264→0.452 而公开仅 0.265→0.401）。

### L40｜设备取证 + 采集结构后处理
- **机制**：传感器数据先做"设备级"修正（佩戴方向、左右手、特殊值语义、符号恢复）；数据采集设计（每受试者录了哪些组合、各几次）直接给出后处理约束（无重复指派/联合最大似然）。
- **证据**：cmi-behavior（反置设备修正 + 检测模型私榜 +0.013；102 类无重复 Hungarian 后处理 +0.02~0.03；受试者级 Transformer +0.02；流式乱序导致重提交 0.868–0.880）。

### L41｜噪声门槛：把验证噪声量化成特征准入标准
- **机制**：小数据 + 阈值型指标下，折间噪声常大于"改进"；用 bags(多种验证集组合)×folds 的均值 + 共识折作为准入，只有当增益 > 噪声水平才保留特征/改动。
- **证据**：psp-game-play（噪声 ~0.0003 门槛、10 bags、4/5 折共识；私有测试仅 1450 会话）；与 rogii 的 LCO、cmi-piu 的种子扫掠同族。

### L42｜相对指标的倍率化与"先修口径再修模型"
- **机制**：SMAPE/相对误差指标 → 预测比值/年化率再连乘还原（消除实体水平与趋势）；比率型目标的分母口径变化（census 换版）会造成全榜系统性偏移，必须先对齐口径。
- **证据**：godaddy（3rd 倍率+GRU 后处理 12th→3rd；Last Value 未修 census 3.2776→修正 1.4631；SMAPE 单县月贡献 ~0.0638；小县分流 last value）。

### L43｜级联系统误差 → 训练分布增强
- **机制**：两阶段系统中第一阶段误差不可避免（rsna-2024 层面 ±0 仅 71%）；按误差分布对中间产物做随机位移（±2 层）让第二阶段见过错位输入，把"系统误差"变成数据增强；替代方案：伪标签覆盖（rsna-2022 3rd）、坐标/尺度归一化（4th）。
- **证据**：rsna-2024 1st（instance_number ±2，作者称 crucial）、rsna-2022（87 掩码→全量伪标→结构级标签）、polymer（外部数据偏移校正）。
- **边界**：适用于显式两级流水线；端到端单阶段不适用（rsna-2024 7th 标题留反例，见 T13）。

### L44｜按标注语义拆子模型 + 条件特异融合
- **机制**：多部位/多条件的视角与标签语义不同（scs→sagT2+axial、nfn→sagT1、ss→axial）；统一多头会互相干扰；拆开后按条件专用融合恢复相关性。
- **证据**：rsna-2024 4/4（1st 三类 severity、3rd Center/Side、2nd 逐目标、4th condition-separated pooling + nfn 拼接 scs/ss 输入）；uw-madison 按目标分别建模。

### L45｜OOF 预测当特征必须去乐观
- **机制**：用验证集早停/选模产生 OOF 预测时，预测携带验证集信息；直接当训练特征会让下一层过拟合 CV。修法：per-model 标准化/rank、加高斯噪声（去置信）、独立划分重算。
- **证据**：isic-2024 1st（σ=0.1，0.02–0.12 探针扫描）、12th（加噪）；各场 stacking 的通用纪律。

### L46｜实体/患者内相对特征
- **机制**：医学/经济筛查的判别线索是"该样本对实体是否异常"；把绝对特征转成实体内相对量（z-score / LOF / KNN 距离 / 比值）比绝对值更接近指标胃口。
- **证据**：isic-2024（LOF、KNN(k=5)、患者内标准化三队）；hubmap（椎骨体积比）；godaddy 的县规模分流为同族。

### L47｜脏数据两段用法：预训练学表示、净数据学决策
- **机制**：噪声大数据适合高 LR/轻增广/低分辨率预训练（学表示与尺度先验），干净数据用于低 LR/重增广微调（重建决策边界）；直接混训让噪声污染边界。
- **证据**：hubmap 3rd（ds2 预训练→ds1 微调，LB +4–6%）；isic 预训练式有效 vs 混训失败（域分类器 AUC 0.99）；multimodal 同向。

### L48｜后处理增益方向 = 训练数据偏差试纸
- **机制**：某后处理（dilation/常数偏移）的增益来源可能是训练标注的系统偏差；换训练子集看增益方向是否反转即可诊断；修正数据后"红利"消失。
- **证据**：hubmap（ds1-only dilation 有害 vs 含 ds2 有益；9th 重标 ds2 后红利消失）；polymer Tg 偏移（方向诊断 + 结构性单位变换优先）。

### L49｜粗标签传播三段式
- **机制**：小掩码子集训分割 → 伪标签覆盖全量 → 用掩码/可见性把 study 级标签传播到结构级（切片/椎骨）→ 序列模型聚合成列。
- **证据**：rsna-2022 4/4（1st 14k 椎骨样本、3rd 体积比×骨折、5th 可见性×overall、6th CAS 伪标）；rsna-2024 的坐标传播同构。

### L50｜聚合列需专门建模与校准
- **机制**：patient_overall 等聚合目标不等于子目标 max/any；列 log-loss 需要校准的联合概率；用 mean/min/max 等聚合统计直接优化指标（metric-aware 后段）或联合输入建模。
- **证据**：rsna-2022 5th 的 stage3 融合 +2–3 LB；1st type2（105 图联合）；6th 三路 Transformer 融合。

### L51｜部分标注分层三处理
- **机制**：部分标注有三类污染——缺失（≠空）、错误、语义模糊区；把数据子集与模型角色配对（anno-only 训精细模型、全量训鲁棒模型、模糊区规则排除）。
- **证据**：uw-madison 1st 三分层（图证）+ 排除肠末端 5 层；3rd 只用正样本；isic 2nd 的 OOF 高损失剔除（|Δ|≥0.8，+1%）。

### L52｜指标变更先改选模协议，不是改损失
- **机制**：竞赛指标中途变化（如加 3D Hausdorff）时，旧指标选模会系统偏向"内部填满但边界粗糙"的模型；不可导/离群敏感的新指标直接当损失往往失败；优先改选模指标与后处理。
- **证据**：uw-madison MONAI（旧 Dice 0.9108 vs 新 0.8933；换新指标选模后 LB 0.860→0.872）；3rd 的 Hausdorff loss 失败。

### L53｜弱输入富集优先级：目标编码 ≥ 通用预训练表示 > 手工先验
- **机制**：输入只有类别关键词时，先从数据学类别统计（目标编码），再引入预训练通用表示（SMILES/ChemBERTa/ModernBERT/CodeBERT）；手工领域先验受覆盖与批次效应拖累，收益不稳定。
- **证据**：single-cell-perturbations（one-hot 在非目标编码中最优；通路/PPI 弱；Wikipedia 描述 0.656 vs ChemBERTa 0.614）；polymer（通用 0.0584 vs 化学专用 0.0634 / polyBERT 0.592）。

### L54｜小样本：CV 与提交准备解耦（固定 epoch + almost-entire 重训）
- **机制**：样本极小时早停浪费数据；CV 阶段定超参与 epoch 数，提交阶段固定预算在多个"几乎全量"子集上重训并平均——同时获得数据量与 bagging 方差削减。
- **证据**：single-cell-perturbations #13（boostings 0.584→0.577、MLP 0.580+→0.570+；1st 数据量曲线 25%→100%：0.946→0.719）。

### L55｜仿真器在环：增强器 + 自监督 + 先验
- **机制**：已知且可快速/可微的物理生成过程可三用——变换参数生成配对样本（物理增强）、预测→仿真→比较构成自监督回路、显式反演作为先验/精修；仿真速度决定方法上限。
- **证据**：waveform 5/5（1st Iterative Pseudo、9th CUDA 100×、2nd FWI 28.8→7.6、20th in-batch 回路）；rsna-2022 的伪标传播为弱化版。

### L56｜非空间对齐任务的输入表示决定归纳偏置
- **机制**：输入与输出无空间对应时，UNet 跳连无物理意义；多通道时间序列铺成 2D 网格 + ViT/像素重排回归是自然解；表示错误会让后续所有技巧失效。
- **证据**：waveform 1st（重排后 CV 46.9→32.5）；ribonanza 的结构先验注入、single-cell 的表示链为同族（表示层先于模型层）。

### L57｜外部数据先做重叠样本差值校正
- **机制**：外部数据的标签尺度/口径可能整体偏移；同一分子/实体在两份数据中的标签差是直接估计量；校正（常数/isotonic/分位匹配）后再混训，并记录许可与来源。
- **证据**：polymer 8th（91 个重叠 SMILES → Tg +20、Density −0.118）、1st 的五策略；godaddy census 口径、hubmap dilation 为同族。

### L58｜相似性 CV：分离"分数水平"与"模型排序"
- **机制**：训练集家族冗余时随机 KFold 高估绝对分数；聚类/相似性切分下绝对分数下降但相对排序可能不变——排序用于选模，水平需严格切分估计；泄漏重复样本主动清零是可信度选择。
- **证据**：ribonanza 1st（DBSCAN 汉明 0.2 + 13% 重复清零仍夺冠）、8th（聚类 GroupKFold）、7th（相似性切分）；对照 T10。

### L59｜仿真赛：先复刻生成器形式
- **机制**：仿真数据赛的最优假设空间由生成器参数化决定（如漂移可分离为 f(t)·g(λ)、额外的 foreground 项）；读/逆向生成代码比调模型值钱，"常数补偿"只能修一阶偏差。
- **证据**：ariel-2024（1st 用 f(t)·g(λ)+前景扣除，消融 −0.0105；全场"×1.006 系数"之谜）；g2net（按生成统计造噪声）；leap（气候不变量）。

### L60｜log-likelihood 型指标：不确定度是第二引擎
- **机制**：高斯 logpdf 指标中 sigma/方差与均值同权重；sigma 可由预测离散度、段间预测差、GP 后验等低成本特征回归。
- **证据**：ariel-2024（4th sigma 迭代 +0.03 级；5th std(pred) 相关 +0.030）；leap（confidence head 0.78945→0.79159；丢弃 10% 低置信样本 R² ~0.83）。

### L61｜抗分布迁移：只建模不变量 + 扩充测试侧多样性
- **机制**：分布漂移下，依赖训练统计量的强假设（分子谱、星谱复用、专用预训练）会失效；只建模跨分布不变的结构，并主动生成"测试可能出现的多样性"。
- **证据**：ariel（TauREx 分子拟合失败 vs 新分子谱增强 +0.020；星谱共享测试 0.110）；isic（域分类器 AUC 0.99：预训练可、混训不可）；polymer（通用模型 > 化学专用）。

### L62｜回归：鲁棒损失 + 数值保真优先
- **机制**：误差含极端值时 MSE 被少数样本主导，MAE/SmoothL1/Huber 更稳；动态范围大时浮点精度、soft clipping 与反归一化顺序是 0 分/high 分分界。
- **证据**：leap（MAE 是"秘密"；禁 float32；两级 soft clip；4.75 亿 token 管道）；essay（回归 > 分类、去 dropout）。

### L63｜序数/阈值指标：连续预测 + 阈值优化
- **机制**：序数指标（QWK 等）下，连续回归 + 自定义切点可在不改善 MSE 的情况下提升指标（尤其少数类）；阈值方差大，需多种子/多起点平滑，且不可在小验证集上二次拟合。
- **证据**：essay-scoring-2（OOF 0.818→0.827；切点 1/2≈1.7、5/6≈4.9；Powell+15 起点+3 seed）；leap 的 hard-sample 加权同族。

### L64｜已知信号族：先建物理统计量基线
- **机制**：相位/参数未知但信号族已知时，功率型广义似然比（模板扫描 + 加权求和 + max）对相位误差免疫，常胜过数据驱动近似。
- **证据**：g2net（纯物理功率求和公榜 0.848 夺冠，sinc 核 0.825→0.848）；waveform（2nd 的 FWI 28.8→7.6）。

### L65｜训练长度 ≠ 推理长度（长文本）
- **机制**：训练长度决定表示，推理长度/滑窗重叠决定长文本覆盖；推理端加长是零训练成本涨分，训练端盲目拉长/加 stride 有害。
- **证据**：pii（训练 1280→推理 4000/stride 1024；stride 训练限 0.967）；commonlit（850→1500、4200）；essay 的 maxlen 1024/1536。

### L66｜长尾标签空间：定向合成第一杠杆
- **机制**：稀有类别在真实数据中样本不足 → 用可控管线按类别配额合成（persona/场景/模板 + Faker/求解器 + 过滤/裁判）；合成质量与筛选决定成败，低质合成是毒药。
- **证据**：pii（外部数据 0.854→0.888；Llama3 数据单模型 > 最佳集成）；eedi（分组生成 + LLM-judge）；nemotron（合成题 + 确定性求解器）；deep-past（外部语料 60k 句对）。反例：eedi 的 Generator、pii 的无效数据集。

### L67｜低资源任务：数据构建/表示优先于模型
- **机制**：当语料规模远低于模型容量需求时，收益全部来自"把数据做大做干净"（对齐流水线、归一化、去重、多版本增强）；模型结构改动无感。
- **证据**：deep-past（官方 6.5k 文档→重建句对；vanilla ByT5；两阶段 SFT）；leap（数据规模第一）；pii（外部数据）。

### L68｜byte-level 表示适配罕见字符集/细粒度符号
- **机制**：稀有字符、变音符号、二进制串对 subword 分词不友好；byte-level 或"单 bit/单符号 token 化"可保持对齐与鲁棒性。
- **证据**：deep-past（ByT5 ≫ 其他 T5/NLLB/mT5；差 1–1.5 GM）；nemotron（单 bit tokenization + dynamic loss masking）；pii（[SPACE]/unidecode 归一）。

### L69｜开放域 QA：检索多样性是第一杠杆
- **机制**：模型只做判别，证据必须被检索到；多条异构检索管线补捉不同证据，"加 RAG"的边际收益大于"加模型"。
- **证据**：kaggle-llm-science-exam（Top100：每加 RAG > 加 DeBERTa；3rd 的 tuned reranker +0.015；1st 的 300 组检索×模型×dump 筛选）。

### L70｜级联/分诊：每级优化自己的指标
- **机制**：级联前级要召回（recall），后级要精度（排序/map）；负样本与模型选型随目标切换；难例用大模型 + 长上下文按不确定性分诊。
- **证据**：eedi（retriever 按 recall@32 选型；hard negatives 提升 map 但伤 recall）；kaggle-llm-science-exam（7B 全量→70B 40%→70B 长上下文 5%）；nemotron 的类别分治。

### L71｜候选位置偏差：单 token 打分 + TTA
- **机制**：LLM 对候选顺序敏感；把候选映射为单 token 取 logits 可批量、无解析损失；配合顺序轮转/打乱 TTA 平均位置效应。
- **证据**：kaggle-llm-science-exam（binary per-option + 选项轮转 5× 拼接复用）；eedi（52 字母单 token + 列表 shuffle）；commonlit 的选项排列实验。

### L72｜评分/抽取任务：池化边界 = 预测对象
- **机制**：mean/attention pooling 若覆盖无关 token，会把非目标语义混入表示；只对"被评分/被抽取对象"的 token 池化可显著提升难题。
- **证据**：commonlit（Head Mask 单项最大提升，难 prompt 尤甚）；pii（文档级同名传播、token↔spacy 对齐测试）。

### L73｜记忆 vs 计算：折叠不可展开的搜索
- **机制**：token 预算内无法逐步展开的搜索（如 5e10 候选）→ 预计算"可复用的有限中间结构"（签名目录/模板/规则表）让模型背下来，再用小步骤（DFS/一致性检查）执行；背的是结构而非答案。
- **证据**：nemotron（4205 签名目录 + DFS：crypt 8%→42.9% solver；3rd 的两阶段"记忆→执行"12/17→16/17）；ariel 的部分类别先验。

### L74｜策略已知时 SFT > RL；用"最小 logprob"看可复现性
- **机制**：评测 temp=0 且最优策略可由代码给出时，任务退化为"复现固定算法"；训练目标应保证轨迹中最弱 token 也能被贪心复现（min-logprob 阈值检查），复杂损失/课程/RL 收益有限。
- **证据**：nemotron（huikang 的显式赌注；2nd/10th 的 focal/reweight/multi-stage/curriculum 全部未胜过标准 CE；10th 排除失败轨迹反而降分）。

### L75｜训练-服务对齐即分数（LoRA/导出格式）
- **机制**：训练格式与提交/部署格式的映射损失（SVD 截断、专家权重融合、key 前缀、QKV 交错）会静默吃掉数据/算法收益；端到端对齐验证是必要步骤。
- **证据**：nemotron（Tinker→PEFT 的 SVD 只留 75% 奇异质量；换 Megatron-Bridge 后 bit 0.81→0.89；QKV 交错 bug）；pii（save_safetensors=False 防 NaN、对齐回归测试）。

### L76｜多来源数据：先识别来源，再对齐分布
- **机制**：训练集常由多个来源拼接（评分口径/领域/采集方式不同）；用重复检测、对抗验证、探针识别来源，再用"两阶段（大源表示→小源决策边界）"或源标签对齐；混训会让大源分布主导。
- **证据**：essay-scoring-2（Persuade vs Kaggle-only；两阶段 +0.015；对抗验证 AUC 0.65–0.675）；isic（域分类器 AUC 0.99）；pii（外部数据格式一致性）。

**Batch 6 增补（L77–L113）**

### L77｜类群级损失条件化
- **机制**：稀有类与大类的可学性不同；同一模型按样本量分组、组内选损失（小类 focal 保召回、大类 BCE 保精度）比单损失更优，阈值按组分别校准。
- **证据**：birdclef-2022（稀有类分组 + 三策略阈值校准）。

### L78｜阈值校准三策略
- **机制**：排序模型 + 分类指标下，阈值是"第二引擎"：逐类阈值（类先验差）、分位数阈值（测试分布自适应）、非目标分位（固定 FPR）各有适用面；无验证分布保证时逐类阈值风险高。
- **证据**：birdclef-2022（三策略并存）。

### L79｜外部强模型的"公榜红利"
- **机制**：外部强模型（如 BirdNET）在公开榜被高估（与其训练分布更近），私榜回落；提交对冲（激进+保守）能把红利变保险。
- **证据**：birdclef-2022 1st（0.91→0.84）。

### L80｜Noisy Student 三旋钮
- **机制**：多轮自训练必须有"加噪"才有新信息：伪标以 MixUp 混入（比例可到 1.0）、power transform 压置信、drop_path 正则；重复伪标无增益，迭代需停止条件。
- **证据**：birdclef-2025 1st（0.872→0.930）。

### L81｜预训练语料的规模-多样性条件
- **机制**：预训练增益与语料规模/多样性成正比；小语料或往届数据增益有限甚至为负。
- **证据**：birdclef-2025 2nd 的对照 + T8 扩证。

### L82｜framewise 重叠平均 = 时序 TTA
- **机制**：滑窗重叠推断后按帧平均，等价于时序 TTA，降低边界方差。
- **证据**：birdclef-2025（1st/2nd/5th）。

### L83｜转播视频四段式：检测→映射→配准→跟踪
- **机制**：固定机位体育视频 + 官方追踪点可降解为四段；检测决定下限，配准与跨帧一致性决定名次。
- **证据**：nfl-helmet（4 队全用；映射+配准单模块即 ~0.8 强基线）。

### L84｜身份层融合优于检测层融合
- **机制**：多模型/多帧融合作用在球员-分配矩阵（WBF+Hungarian）比检测框层更稳——错误在身份层可被投票抵消。
- **证据**：nfl-helmet 1st（分配矩阵 WBF）。

### L85｜显式几何模型脆弱，鲁棒配准优先
- **机制**：相机矩阵/纯旋转缩放假设脆弱；带外点的点集配准（描述子+RANSAC/LMEDS+ICP 迭代）更稳。
- **证据**：nfl-helmet 9th（相机矩阵失败 vs shape context+LMEDS+ICP 成功）。

### L86｜实体匹配四段式与图一致化
- **机制**：O(n²) 配对 = 候选生成（地理+文本双路）→ 过滤（高精度分类器）→ 精细匹配（交叉编码器/双塔）→ 图后处理（Union-Find/GNN/组大小自适应阈值）；成对分数必须恢复传递性才能对齐簇级指标。
- **证据**：foursquare（4 队全用；GNN +0.02；新对重预测 +0.0056）。

### L87｜泄漏三信号识别
- **机制**：train-test 重叠污染排序时三个信号同时出现——CV-LB gap 异常、过拟合模型 LB 更高、CV 与 LB 相关消失；处置 = 报告 + 量化 + 保留无泄漏对照提交。
- **证据**：foursquare（1st 三步 0.900→0.943→0.971；13th/3rd 的观察）。

### L88｜Word Tour：embedding 的 GBDT 化
- **机制**：GBDT 无法直接用高维 embedding → 先聚类再按相似度构造 TSP 路径映射为一维语义坐标，树可对其阈值切分（target encoding 的几何版本）。
- **证据**：foursquare 7th（0.933→0.951）。

### L89｜非平稳目标平稳化律
- **机制**：容量/规模驱动的水平漂移触碰树模型"边界墙"（无法外推训练区间）；把目标换成相对量（delta/cap、÷eic_count、÷lag 基线、log 差分）恢复平稳；目标膨胀与重训是二阶手段。
- **证据**：predict-energy（1st 明测 4 变换留 2；3rd/5th/13th/53rd）。

### L90｜滚动评测在线重训律
- **机制**：代码赛评测期持续揭示新数据 → 模型新鲜度收益覆盖剩余全部计分日；最优节奏 4–9 天；预算应从集成宽度腾给重训。
- **证据**：predict-energy（1st 集成 53.66→52.48→52.31、XGB −1.50、GRU −1.97；6 队节奏）。

### L91｜预报差分的去偏律
- **机制**：预测类特征（天气预报）带系统性偏差；用 vintage 对 vintage 的差分消公共偏差，而不是预报对实际。
- **证据**：predict-energy（53rd 明示"预报永远偏高"；13th/5th/12th 同族）。

### L92｜线性指标的可加分解测量律
- **机制**：MAE 等按样本平均的指标对不相交子集可加 → 用"部分替换"提交测量子目标贡献（排行榜上的 A/B 分解）；RMSE 等不可加。
- **证据**：predict-energy 12th（99.93/87.3/72.97→60.34 恒等式）。

### L93｜公开/私有脱钩与新鲜度对冲律
- **机制**：滚动榜的公开段只是有限窗口样本；用模型新鲜度 + 多版本对冲应对，而不是拟合公开榜。
- **证据**：predict-energy（5th 公开 22→私 5；3rd 最后一天爬升；10th CV 35.73 vs LB 61.32；12th 双提交）。

### L94｜复合指标的可操纵性审计律
- **机制**：指标 = 区分度项 + 可独立操纵项（时间趋势惩罚 × 可恢复的时间信息）时，竞赛退化为参数下注；建模前先做可操纵性审计。反例边界：指标项不可独立影响时比赛仍可比。
- **证据**：home-credit（1st 中性下注 0.53→0.605；10th 周区间下调；8th 押公开法私 253）。

### L95｜匿名化时间侧信道律
- **机制**：显式日期被移除 ≠ 时间信息被移除；跨表差值、缺失率趋势、分布漂移都是恢复通道（时间匿名化的通用审计项）。
- **证据**：home-credit（date_decision−min_refreshdate 相关 0.9~0.99、87% 恢复；477075 空值趋势）。

### L96｜弱 CV 环境下二阶模型优先律
- **机制**：CV-LB 弱相关时，优化"多个弱信号的一致性"（stacking/校准/多 seed）比单模调参更可靠。
- **证据**：home-credit（13th 堆叠 +0.003；57th 元分类器 +0.002；8th 集成后相关改善）。

### L97｜黑箱评分器对齐律
- **机制**：本地必须逐位复现官方评分（padding 方向/掩码/精度/批量化）再优化；批量与逐行的 cuBLAS 级差异会变成搜索噪声。
- **证据**：santa-2024（548249 的 padding-right/pad 屏蔽；全社区）。

### L98｜非局部目标的邻域剪枝律
- **机制**：目标非局部（移动改变其后全部上下文）时局部增量失效；禁翻转、限制移动子序列长度、长段静止、整体重评 + 缓存。
- **证据**：santa-2024（2nd P5 全移动 18 分钟；5th 98% GPU + 分数缓存）。

### L99｜位置归一化律
- **机制**：昂贵因果评分下各位置难度不同 → 接受判据要按位置归一（前缀限制/折扣分数），否则搜索系统性偏尾。
- **证据**：santa-2024 5th（前缀限制 + logits/位置均值折扣）。

### L100｜结构压缩双刃剑律
- **机制**：结构先验（字母块/停用词）大幅压缩解空间、给你起点，但会封顶；只有"打破结构"的 kick 才能越过壁垒。
- **证据**：santa-2024（sample5 44→28.5；32.xx 壁垒）。

### L101｜启发式赛分享时机定律
- **机制**：单一答案 + 同分并列的赛制里，赛期公开顶级解会把金牌竞争变成"复现速度 + 提交时机"竞赛。
- **证据**：santa-2024（sample5 帖争议；555881）。

### L102｜匹配制评估优先律
- **机制**：对手分布是环境的一部分；非传递关系与重复变体污染总体强度估计 → 需内部贝叶斯 BT/自适应配对/胜率画像聚类。
- **证据**：pokemon-tcg（24th 320 agents/2.2M 局；15th 配对换座位；712621/736361）。

### L103｜群体/历史池防坍塌律
- **机制**：只对最新策略自对弈会互相过拟合/遗忘；混合历史冻结策略与多样对手维持梯度信号。
- **证据**：pokemon-tcg（15th/24th/27th/213tubo 4/4）。

### L104｜仿真吞吐换经验律
- **机制**：RL 瓶颈是 games/sec；经验不足阶段"小模型+高吞吐"胜过大模型+低吞吐，经验充足后大模型上限重新占优。
- **证据**：pokemon-tcg（24th 1M/1 ms/84 局秒 vs 213tubo 117M 蒸馏）。

### L105｜专家分工 × 廉价路由律
- **机制**：按牌组/原型/对局分层训练专家；运行时用公开信息（对手暴露卡）整模型路由，避免逐层混合专家。
- **证据**：pokemon-tcg（15th/24th/27th/213tubo）。

### L106｜教师覆盖率优先律
- **机制**：小回放冷启动用特征教师（GBDT）生成数据再蒸馏；教师价值在状态覆盖率而非强度。反例边界：无回放时纯 RL 可行。
- **证据**：pokemon-tcg 24th（教师低 ~200 分但省 50–80% 冷启动）；15th（无 BC 亦到前排）。

### L107｜饱和分数→速度排名律
- **机制**：上限被多数强队触达时，"解得多好"不再影响名次，时间成为唯一自由度；策略转为最小化每题提交时间（暴力/探测优先）。
- **证据**：ai-village-ctf（34 人 0.894；1st 的暴力优先策略）。

### L108｜黑箱 oracle 探测律
- **机制**：先花少量调用学结构（边界二分/查表/接口约束试探），再对剩余小空间暴力；评分接口本身是题目的一部分。
- **证据**：ai-village-ctf（WAF 逐字符、inference top-5、crop1 分辨率、math 递增）。

### L109｜安全判定最弱环律
- **机制**：攻击成本 ≈ min(模型鲁棒性, 管线假设强度)；白盒梯度最便宜、黑盒代理迁移次之、弱管线直接绕过（篡改检测/分辨率/输入域）。
- **证据**：ai-village-ctf（hotdog/honor/deepfake/bad-to-good 的非 ML 击穿）。

### L110｜合成数据物理修复律
- **机制**：生成器按边缘分布采样、无法表达约束语义（角度循环/灰度有界/距离非负）；确定性物理映射修复 = 稳定正收益、无过拟合风险。
- **证据**：tps-dec-2021（0.95631→0.95673；负距离置 0 +0.0053）。

### L111｜修复-还原分离律
- **机制**：局部修复（去伪影）改善测试一致性；全局"还原原始分布"改变训练分布 → CV 好/LB 崩；两者必须分开决策。
- **证据**：tps-dec-2021 2nd（土壤掩码/原数据靠拢数十次失败；Aspect 修复幸存）。

### L112｜同质化环境多样性律
- **机制**：单模收敛一致、特征收益枯竭时，训练扰动（batch/seed）软投票是最后一块稳定增量。
- **证据**：tps-dec-2021 2nd（10 模型 soft voting + batch_size 扰动再投票）。

### L113｜公开代码策展律
- **机制**：公开 notebook 使分数快速饱和；最大化差异化 = 私有强单模 + 对公共 blend 做去伪标签/加权策展，而不是无差别复制。
- **证据**：tps-dec-2021 2nd（终版 3+1+3+2；复制党 0.9709–0.9711）。

### L114｜指标结构套利律（Tier B 新增）
- **机制**：中位数型指标只取决于"误差中位数那一个样本量级"；两端样本（极准/极错）几乎不影响分数，因此"对可能成为中位数的样本加权/对预测分布整形"比提高平均精度更值钱。
- **适用范围**：MedAE/分位损失类指标；测试分布与训练同构。
- **反例/边界**：阈值与档位是经验参数，需要 CV 扫描；分成 shape 若偏离真实分布会反噬。
- **证据**：s3e25（对 AE≤0.06 或 ≥0.7 的样本给 0.01 权重，LGBM CV +0.03；9 档 ±0.25 覆盖 89.5%（9533/10406），猜对约 56% 即 MedAE=0.25）。

### L115｜目标随机性检验律（Tier B 新增）
- **机制**：合成数据赛先用"打乱目标"对照测原数据信号；若原目标 CV 落在随机分布 ±2σ 内，则题材无真实规律，收益来自生成痕迹与稳健集成，而不是领域建模。
- **适用范围**：合成/生成数据回归赛；原数据可得。
- **反例/边界**：原数据无信号 ≠ 比赛无技巧——合成过程会引入可挖结构（S5E2 孪生行、S5E11 指纹）。
- **证据**：s5e9（100 次打乱目标 z=-0.83；近 6 场回归 3/6 随机：S4E12、S5E2、S5E9）。

### L116｜实体块切分决定验证口径律（Tier B 新增）
- **机制**：先查"实体是否整体落在 train 或 test"（玩家/马/酒店/患者）；若是，普通 KFold 会让实体历史跨折泄漏，GroupKFold 分数更低但更接近真实泛化。
- **适用范围**：存在强实体特征的表格/序列任务；医疗、体育、用户行为。
- **反例/边界**：分组 CV 与 LB 相关性需实测；s3e22"同 hospital_number 死多次"说明实体键本身可能是合成伪影。
- **证据**：scrabble-player-rating（按 nickname 分组后分数显著变差，StratifiedGroupKFold 改善有限）；s3e22（实体复用、7 区域私榜洗牌）；s3e9（CV 5407 vs 公榜 721 = 测量 vs 随机变量）。

### L117｜评审闭环律（Tier B 新增）
- **机制**：评审制 write-up 的高分结构是"观察 → 改动 → 验证"的完整闭环，而不是结果通报；消融只需一次对照，失败路径与牌组/方案意图必须写清，图表少而精。
- **适用范围**：策略/分析/hackathon 评审赛道。
- **反例/边界**：不同赛事字数与图表规则不同；评审口味依赛道（Metric/Coaching/Undergrad）而变。
- **证据**：pokemon-tcg-strategy（官方 742692：强稿 vs 弱稿五条特征）；nfl-bdb-2023/2024/2025 的评审制复盘。

### L118｜评审可信度工程律（Tier B 新增）
- **机制**：大规模评审采用"高召回初筛（人+LLM）→ 深度复现 → 评委集中讨论"，并用盲样做召回 QA、冲突评委替换、获奖作品复现；个人分数通常不公开。
- **适用范围**：千级提交的 hackathon/benchmark 设计赛。
- **反例/边界**：复现失败/私有依赖会被过滤；评审透明度仍是社区争议点。
- **证据**：gpt-oss red team（600+ 提交→145 深审、盲样 QA、换 1 评委、10+10 奖）；bigquery（缺 artifact 过滤、获奖提交逐一复现）；pokemon strategy（不公开分项评分）。

### L119｜危害增量判定律（Tier B 新增）
- **机制**：安全类红队的价值按"增量危害"（是否超出基础网络搜索/教材）而非攻击成功率评估；同时必须绑定部署配置（`reasoning_effort=low` 可复现、`high` 正确拒绝）。
- **适用范围**：模型红队、安全评测、政策类 hackathon。
- **反例/边界**：方法新颖性可单独作为一等贡献（Lucky Coin、工具预热）；CoT 伪造与工具/通道不一致是系统级发现。
- **证据**：openai-gpt-oss-20b-red-teaming（608537：CoT 可伪造、工具/通道漏洞、low/high 复现差异、多数越狱高估危害）。

### L120｜分层学习率微调律（Tier B 新增）
- **机制**：大骨干 + 任务头微调时，头/融合权重用高 LR 且早 warmup，骨干按层组递减 LR；单一全局 LR 会在"头欠拟合"与"骨干被覆盖"之间失配。
- **适用范围**：预训练视觉/多模态骨干的迁移。
- **反例/边界**：需要显存/时间支持多 scheduler；小数据上过高 LR 仍会崩。
- **证据**：planttraits2024 1st（head 1e-4、blend weights 次之、block7–12 8e-5→2e-5、tokens 2e-5）。

### L121｜身份辅助任务律（Tier B 新增）
- **机制**：当目标是"群体的均值性状/属性"时，显式建模群体身份（分类/软分类/聚类）并把身份标签的均值作为一路预测，比纯回归更稳；硬分类 + 软分类 + 回归三头可互补。
- **适用范围**：生物表型、商品属性、用户画像等"目标与身份强相关"的回归。
- **反例/边界**：群体数量巨大（如 17k）时需 focal loss/长尾处理；聚类错误会传导。
- **证据**：planttraits2024 1st（17,396 个"物种"三头融合、PlantCLEF 预训练、结构化自注意力）；6th（标签链）。

### L122｜提交契约律（Tier B 新增）
- **机制**：提交格式/契约是与模型同等的淘汰线：列顺序必须与 sample_submission 完全一致、zip/PostProcessorKernel 结构、agent schema 要本地 validate、截止前完成提交并留凭证。
- **适用范围**：所有代码赛/agent 赛/hackathon。
- **反例/边界**：平台故障（提交按钮失效、评测未配置、PENDING）不可控，只能用提前量对冲。
- **证据**：planttraits（列顺序不一致导致 CV/LB 大幅偏离）；gan（images.zip/输出找不到）；autonomous-agent（validate_submission.py、schema 失败）；bigquery（提交按钮失效多帖）。

### L123｜平台能力配给律（Tier B 新增）
- **机制**：以模型/云服务为核心的比赛，第一约束是"能力配给"：地区/年龄限制、模型挂载方式（Save & Run All）、免费额度/预算（$2/$300/$50）、TPU/配额与排队。
- **适用范围**：Google/OpenAI/云厂商 hackathon。
- **反例/边界**：额度通常只覆盖探索期，正式全量扫描需自部署/量化兜底。
- **证据**：makersuite（巴西/欧洲不可用）；gemini-long-context（必须 Save&Run All，全站仅 4 用户挂载）；bigquery（$300+$50+$5 额度）；autonomous-agent（60min/$2）。

### L124｜RL 课程+热启动律（Tier B 新增）
- **机制**：复杂 agent 环境先用小地图/简场景学基础技能，再把最佳 checkpoint 热启动到更大场景；比在大场景从头训更省样本。
- **适用范围**：多智能体对战、地图可缩放环境。
- **反例/边界**：小图难度未必随尺寸降低（16×16 也常打不满）；每段仍需独立早停。
- **证据**：lux-ai-s2-neurips（16→32→64，各 80M 步、1024/1024/512 环境、最佳 checkpoint 初始化；16×16 平均约 600 步/局）。

### L125｜RL 收益拐点监控律（Tier B 新增）
- **机制**：训练的有效步数远小于预算；用 KL、资源产量、对旧 checkpoint 胜率曲线判断收益拐点，而不是跑满步数。
- **适用范围**：长周期自对弈 RL；不适用于监督学习。
- **反例/边界**：指标之间会互相矛盾（胜率仍升但产量崩），需多指标交叉。
- **证据**：lux-ai-s2-neurips（32×32 KL>0.02 出现在 30M 步后；金属产量跌破 100（重机器人成本）；64×64 的"赢旧 checkpoint"在 20M 步前停止；loss 每 1000 步周期性尖刺）。

### L126｜规则优先、RL 局部化律（Tier B 新增）
- **机制**：在资源战/迷宫类 agent 赛里，可解释的规则基线（评分函数、精确兵力计算）通常先于 RL 拿到名次；RL 适合替换局部模块，但需要快模拟器、课程与对手多样性。
- **适用范围**：动作空间大、终局规则明确的 agent 赛。
- **反例/边界**：Lux 这类连续控制/大地图环境 RL 是头部主流；规则基线在复杂环境可能触顶。
- **证据**：kore-2022-beta（1st 七模块规则；社区 Q-learning 打不过官方示例微调）；maze-crawler（1st 评分函数 BFS vs 3rd JAX+BC+PPO）。

### L127｜近镜像鲁棒性律（Tier B 新增）
- **机制**：当策略可被复制时，只针对"主流打法"调参会输给镜像变体；需要显式的镜像/对称对局调参与对手多样性预算。
- **适用范围**：规则公开、策略易模仿的 agent 赛。
- **反例/边界**：镜像胜率难精确测量（rating 更新 ±5 不对称、收敛慢）。
- **证据**：maze-crawler 1st（自述对近镜像 bunterrrr 约 53/47，最终 2006.5 vs 1953.4；早期投放矿工与离矿规则是两处差异）。

### L128｜密度分层后处理律（Tier B 新增）
- **机制**：无 GT 的检测/计数赛中，单一置信度阈值在高密度与低密度图上偏差相反；按预测数量分桶（如每图 8 个框）切换阈值/NMS，可把"过滤工程"做到前列。
- **适用范围**：检测+计数、稀疏/密集混合场景。
- **反例/边界**：需要可观察的密度代理；帧间跟踪等重时序方法未必兑现。
- **证据**：iwildcam2022（1st：>8 框用置信度 0.0 + NMS IoU 0.2 + 抑制小框；低密度 0.98/0.8 + 二轮过滤；public MAE 0.247，优于 9th 的 YOLO+WBF+跟踪 0.265/0.275）。

### L129｜域适应组合律（Tier B 新增）
- **机制**：多来源采集的细粒度视觉任务，"高分辨率 + 域适配（IBN/直方图均衡）+ 度量损失 + 外部数据/伪标签 + 集成/TTA"是累积增益的组合拳，单项增益可量化。
- **适用范围**：农业/生物/取证等采集域差异大的图像分类。
- **反例/边界**：域差未知时先做分布可视化；重采样/清洗等常规手段可能无效。
- **证据**：sorghum-id-fgvc-9 3rd（直方图均衡 +0.03、IBN +0.05、ArcFace +0.015、512→1024 +0.04、FGVC8 +0.03、TTA +0.02，≈0.957）；2nd（512→960 私榜 84.1→91.9，伪标签 +3.2）；hotel-id（BlendFlip 遮挡增强 +0.03–0.04 mAP）。

### L130｜标签病态松弛律（Tier B 新增）
- **机制**：presence-only / 单标签多义数据用硬 CE 是病态的；在同一空间网格内以低概率替换为邻居标签（或温度 softmax/多标签聚合）可显著改善 top-K 指标。
- **适用范围**：物种分布、推荐、检索等"未观测≠不存在"的数据。
- **反例/边界**：多标签聚合的实现未必优于邻域松弛；长尾处理要按测试分布决定（分布同样长尾时"不处理"最好）。
- **证据**：geolifeclef-2022 2nd（0.01° 网格、10% 邻域换标，单项 +2%；10 模型伪置信度集成再 +2%）；1st（多标签聚合失败、RF 处理协变量）。

### L131｜原数据合并先对抗验证律（Tier B 新增）
- **机制**：把原始数据集并入合成赛训练前，先用对抗验证确认分布一致；合并后仍需 CV 证明增益。
- **适用范围**：Playground/合成数据 + 原始数据并存。
- **反例/边界**：分布一致不等于标签口径一致；重复行可能引入实体泄漏。
- **证据**：s3e18（419685 对抗验证确认原数据可并入；11th 另删 -666/重复/近常数冗余列）。

### L132｜LLM 辅助的验证义务律（Tier B 新增）
- **机制**：LLM 可以加速环境移植、文献综述与 RAG 助手，但模型给出的引用、来源与代码语义必须人工逐条核验；LLM 输出是不可信输入。
- **适用范围**：LLM 辅助开发、RAG 数据助手、环境移植。
- **反例/边界**：核验成本可能吞掉 LLM 带来的效率；敏感信息不能进外部模型。
- **证据**：maze-crawler 3rd（LLM 辅助写 JAX 端口仍需人工验证）；openai-to-z（584626 源文件幻觉）；data-assistants-with-gemma（RAG/引用要可查）。

### L133｜评审赛激励设计律（Tier B 新增）
- **机制**：过程激励（中期 notebook 奖、限量 swag、补充数据开源）会显著改变社区分享行为；参赛者应在中期节点前发布高质量公开产物，组织者可用小奖品换高分享率。
- **适用范围**：社区赛、hackathon、benchmark 设计赛。
- **反例/边界**：无奖牌赛事仍会出现抄袭/引用缺失争议（声誉是主要回报）。
- **证据**：data-assistants-with-gemma（前 5 周 5 份 notebook 中期奖 + 25 份 swag；原创 vs 抄袭 20 票）；s3e25（40 票引用缺失抱怨）；nfl-bdb-2026（冠军开源补充数据 + AMA）。

**待续（Tier B 之后）**：图内文字 OCR sidecar（claim 数字的图内复核）；各 playbook 的 v2 增补已同步；剩余未覆盖主题主要是私有/未归档方案与平台侧行为（提交基础设施、评分器实现）。
