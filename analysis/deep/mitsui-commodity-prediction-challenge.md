## 1. 一句话重述与数字账

预测 400+ 个"收益率型价差"目标、按排名类指标评分，且要求每个时间步在 1 分钟内完成全流程推理（含特征与预处理）。本届最反直觉的结论是**"越简单越强"**：5th 只用 4 天窗 RNN + 单日 MLP 的平均；10th 用"正则化 naive"（标准化排名 + 正则化协方差，类 Kelly 组合）拿到 0.479；89th 直接提交训练标签的排名均值（几乎零模型）也进到 0.387——而社区用 50 万次随机提交模拟出 std≈0.107 的分数分布，说明在 ±0.3 区间内分数与运气难以区分。

## 3. 共识、分歧与裁决

### 共识一：本场信噪比极低，分数噪声主导（599772、668589、668781；置信度中高）

随机提交模拟 std≈0.107（区间 ±0.3 内可能是运气）；10th 判断"3 个月测试窗不足以让小统计优势跑赢随机"；89th 的常量排名预测都能拿到 0.387。**裁决**：该赛的有效策略是"逼近稳健最优的简单解 + 控制方差"，复杂模型的边际收益不确定。置信度：中高（模拟 + 两个独立方案佐证，但无官方指标细节）。

### 共识二：推理期稳定性是分水岭（668673、668781、赛事帖；置信度高）

15th 的轻量备选方案在第 3 轮因内存/基础设施失败；89th 专门准备极简"保险提交"；社区反映最后一轮大量提交失败、1 分钟/时间步的限制苛刻。**裁决**：在这类带在线推理 API 的代码赛里，"能跑完"优先于"跑得好"；需要 checkpoint、内存上限、回退路径与本地端到端演练。置信度：高。

### 分歧一：在线重训练是否真的带来增益（668673 vs 668589/668781；置信度中）

15th 把 R2→R3 的 0.110→0.445 归功于在线学习；但 10th/89th 用静态/常量方案也拿到 0.479/0.387，且轮次分数方差极大（89th 的 -0.273 → 0.387）。**裁决**：现有材料**不能**把 15th 的分数跳变完全归因于在线学习；小测试窗 + 高噪声 + 基础设施差异都可解释。该结论需更强的对照实验。置信度：中（分歧保留）。

### 事件：规则与数据多次变更（591256、603716、606650、668482、668455；置信度中高）

54 票澄清帖集中在"1 分钟是否含特征工程、能否缓存状态、warm-up、批处理"等；之后有数据集更新、4 个 target 对含退市股票、榜单政策多次变动（含"公榜在终榜前无意义"的提示）。**裁决**：规则不确定性本身就是主要风险，参赛者需要按最严格解释设计管线并做健壮性兜底。置信度：中高。
