## 1. 一句话重述与数字账

预测东京证交所股票的横截面收益并排序（Sharpe 型指标）。真正的考点是**"随机性与泄漏都极强的金融赛"**：随机模型得分近似 N(0, 0.13785)，所以 0.3 以内的分数无法区分能力；同时股价是公开数据，用历史价格可"完美预测"（host 因此周期性清理榜单提交）。第 4 名公开承认"主要是运气"——用**两条互为反号的规则提交**保证分数 > 0。

## 3. 共识、分歧与裁决

### 共识一：本场分数几乎无法区分能力与运气（4th + 67 票帖）

4th 给出量化基准：随机模型 ≈ N(0, 0.13785)；社区专门开帖问"会不会有幸运冠军"；host 也承认榜单被历史数据泄漏污染。**裁决**：单次提交的分数只有超过"随机分布"的可信区间才有信息量；金融赛要预先算随机基线并据此解释名次。置信度：高。

### 共识二：除权日/股息结构是可解释的确定性收益来源（4th + 45 票帖）

`ExpectedDividend` 的定义与 target 的时间窗口（t+2 vs t+1）使除权日附近收益为负；社区帖直接总结"做空除权日 = 简单提分"。**裁决**：金融赛先找"会计/日历性结构"（除权、停牌、指数调整），它们是低风险的可解释 alpha。置信度：高（机制清晰）。

### 共识三：榜单泄漏必须靠治理，不能靠选手自律（host + 116 票帖）

host 明确"用历史数据拿满分不违规但无意义"，采取周期性清理；这本身成为一场高票讨论。**裁决**：涉及公开市场的赛题，评测窗口/榜单机制与建模同等重要；登记 host 的治理实验与最终暂停。置信度：高。

### 分歧一：做 ML 还是做规则

8th 用板块 LGBM；4th 放弃 ML 直接用排名规则并拿到第 4。**裁决**：当随机性主导、且存在确定性结构（除权）时，简单规则的性价比远高于复杂模型；"两条对冲提交"更是本赛独有的策略空间。置信度：中高。

### 事件：往届 JQuants 与历史材料（317250/173 票帖）

host 整理了上一届 JQuants 冠军代码；社区高票帖"猜测冠军方案"纯属推测（无实际方案）。**裁决**：金融赛的公开信息里混杂大量推测内容，引用时应区分"官方/可复现"与"猜测"。置信度：中。
