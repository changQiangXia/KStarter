## 0. 一句话重述：这道题真正在考什么

题面是"由 L1/H1 两台探测器的 STFT 频谱图（360 频率 × 时间）判断连续引力波信号是否存在（AUC）"，实际被考的是**域适应、相位敏感度与生成痕迹审计**：

1. **训练/测试存在硬域差异**：官方训练数据只有模拟的平稳高斯噪声；测试含**真实噪声**（线噪声、非平稳、时间 gap）。所有 DL 方案的第一要务是**造出与测试同统计的噪声**（在线生成 + 真实噪声参数 + 横/竖线 + random walk + gap）。
2. **相位 vs 功率**：连续波在 120 天里被地球自转调制出复杂频率路径。1st 想"相干叠加波形"（需极精确相位）一个月无进展，改做**功率求和**（相位不敏感、按幅度最优加权 + 多普勒模板扫描）后直接夺冠——**冠军没有用机器学习**。
3. **经典方法依然能打**：6th 只用模拟退火拟合正弦（无 ML）拿到金区；3rd 的 DL 集成（无"去噪"约第 5）也证明学习路线可行但非上限。
4. **生成痕迹可被利用（灰区）**：3rd 发现非平稳测试噪声是"真实噪声大分块 + 白噪 + 随机排序 + 整数 Hz 频移"生成的，于是跨样本做全对全频率匹配，`abs1−abs2` 得到无噪信号——约 1100 个样本被"去噪"，私榜 0.801→0.826；标题自称 "How far can deep learning go?"，正文自注 "denoising (or leak 😉?)"。
5. **标签不可全信**：3 个 `-1` 标签文件实际是彩蛋图像（黑洞碰撞卡通、1974 年 Arecibo 信息、2017 诺奖得主）。

一句话：**这是一场"物理最优统计量 vs 深度学习"的比赛**——冠军是纯物理（功率求和）；DL 的上限被域差异与相位信息卡住，但配合生成器洞察（去噪/域适应）仍能进入前三。

## 3. 共识、分歧与裁决

### 共识一：训练/测试域差异是本场第一难题（全员应对）

官方训练 = 平稳高斯模拟；测试 = 真实噪声（平稳 + 非平稳）+ 线噪声 + 时间 gap；
9th：在线生成时变噪声/random walk/横竖线/gap；
3rd：用每张测试图的统计量现场生成噪声并注入同频信号（"infinite training"）；
6th：直接在测试图上做横线/竖条纹修正；
1st：在功率域做时间/频率噪声归一化。

**裁决**：本题本质是"在真实噪声域里的检测"；**DL 的成败首先取决于噪声域适应**，而非架构。置信度：高（多队独立强调）。

### 共识二：信号频率依赖必须显式处理（3rd 图证 + 1st/6th 设计）

3rd 的图 1：低频带（50–100）信号近似直线，高频带（400–500）频率轨迹强烈扇形展开；
1st：4000 模板覆盖不同多普勒形态；
6th：固定 v=0.31（"固定频率略微提升分数"）——单参数近似；
9th/3rd：按样本频率采样注入同频信号。

**裁决**：信号形态随频带变化，训练/模板必须**与样本频率匹配**；否则模型/统计量在部分频带上失效。置信度：高。

### 共识三：经典信号处理与深度学习都有效，但物理统计量上限更高（本场核心裁决）

1st：纯物理 0.848 公榜第一；
3rd：DL 集成（无去噪红利）≈第 5（0.784/0.801），加去噪到 0.826 私榜；
6th：纯 SA 0.79+；
9th：简单 CNN 进金区。

**裁决**：在"已知信号族 + 高斯噪声 + 未知相位/多普勒"的设定下，**匹配滤波/功率求和的广义似然比结构**是统计最优方向；DL 需要额外的域适应工程才能接近。置信度：高（冠军自述 + 多队对照）。

### 分歧一："creative denoising"是否算泄漏

3rd 自述发现测试数据生成流程的重复分块（同频率 bin 跨样本相同），用 `abs1−abs2` 去噪 ~1100 样本，私榜 +0.025；标题自嘲 "denoising (or leak 😉?)"；
主办方/社区未给出处置结论（该队最终第 3）。

**裁决**：这是**利用数据生成器痕迹**的灰区技巧（与 LEAP 的 pbuf_ozone_2、ARIEL 的前景缺失同族）：它不伪造数据，但绕过了"检测真实噪声中的信号"的任务设定。学习者应把它当"审计案例"而非默认策略——**先报告、再决定是否使用**。置信度：中（无官方定性）。

### 分歧二：验证与榜单策略

1st：无 CV，靠统计量分布与公榜；6th：明确"放弃 CV，按公榜调权"，并对真实噪声做 rank/1.1 修正；
3rd：自建"与测试一一对应"的合成验证集（正例 0.66），与公榜相关好；
9th：未展开。

**裁决**：在真实噪声不可得的情况下，**用测试图统计生成对齐验证集**（3rd）比 CV/LB 拍脑袋更系统；公榜权重调整（6th）风险最高。置信度：中。

### 共识四：标签与数据异常要主动审计（-1 彩蛋 + 生成痕迹）

-1 标签是彩蛋图像（125 票帖）；
3rd 的发现来自对测试数据生成过程的逆向；
float32 下溢风险（361312 帖，未收录）暗示数据尺度陷阱。

**裁决**：这场比赛的两大收益（去噪、彩蛋识别）都来自"看数据本身"，而非建模。置信度：高（彩蛋可复验）。

## 5. 机制推演

**M1｜为什么相干"加波形"失败、"加功率"成功**：连续波 = 未知相位 φ 的近单频正弦 + 多普勒漂移。相干检测需要 φ 的精确估计（模拟与真实的相位误差、频率轨迹误差都会让叠加互相抵消）；功率（|·|²）丢弃相位，只保留"能量沿频率轨迹聚集"，再用幅度权重做最优线性组合 → 对相位误差免疫。1st 一个月的失败与之后的成功是这一机制的实验对照。

**M2｜域适应的本质是噪声分布对齐**：训练噪声 N(0,σ²) 是理想化；测试噪声含线噪声（窄带强干扰）、非平稳（时变方差）、gap（缺失时间）与真实 detector 噪声的卡方统计。DL 若只在理想噪声上训练，会把"真实噪声特征"当作信号（假阳性）。在线生成（9th）与"按测试图统计生成"（3rd）都是让训练分布 ≈ 测试分布。

**M3｜生成痕迹去噪的机制**：非平稳测试样本由同一大块真实噪声分块生成 → 不同样本共享完全相同的频率 bin 行 → 逐样本相减可消掉公共噪声、保留各自信号。它依赖"生成器复用数据"这一实现细节；若生成器每次独立采样，技巧失效。**这是"数据生成过程的熵不足"被利用的又一个案例**（与 feb2022 的 RNG 缺陷、s5e12 的 ID 泄漏同族，但发生在测试侧、且性质更接近灰区）。

**M4｜为什么物理统计量能赢 DL**：对已知信号族 + 高斯噪声，Neyman–Pearson 最优检测器是匹配滤波；1st 的方法（模板扫描 + 幅度加权求和 + max + 实噪声归一化）是广义似然比的高效近似。DL 逼近同一决策面需要学习频率轨迹族 + 相位不变性 + 噪声统计，而训练数据（理想模拟）与测试（真实噪声）的差异让学习目标偏移——**先验正确的统计量 > 数据驱动的近似**（对照 waveform/ariel 的"物理在环"）。

**M5｜标签与数据审计的价值**：-1 彩蛋说明"异常标签未必是错误"；3rd 的去噪说明"异常完美的重复模式"是生成痕迹；float32 下溢帖说明数值尺度要检查。三者共同构成"先审计数据、再建模"的纪律（与 L45-L48、T17 同族）。

**M6｜混合路线的最优形态**：3rd 的 DL 集成提供 ~第 5 的基线，生成痕迹去噪再加 +0.02；1st 的物理统计量直接到顶。若把两者结合（物理统计量作特征/教师 + DL 作残差），可能进一步；本场没有队伍走完这条线。**"物理上限 + 学习补充"再次成立**（对照 T5/T16）。

## 7. 边界条件与反事实

- **反事实 1**：不做噪声域适应（只用官方平稳噪声）→ DL 学到错分布，AUC 受限（9th/3rd 的出发点）。
- **反事实 2**：坚持相干加波形 → 1st 一个月无进展；相位精确性在有限资源内不可达。
- **反事实 3**：不利用生成痕迹 → 3rd 约第 5；利用 → 第 3（+0.02 私榜），但伴随合规风险。
- **反事实 4**：把 -1 当正常标签硬训 → 无实质收益（彩蛋图与任务无关），但审计可避免误判。
- **边界**：结论依赖"信号族已知、可模拟"（匹配滤波可行）与"测试噪声可采样/可建模"；纯黑箱异常检测任务不适用。

**失败学（跨队合集）**

- 3rd：noise-to-noise / noise-to-void 去噪、扩散模型、加额外特征的高级 stacking。
- 6th：放弃 CV、按公榜调权（高风险）；真实噪声 rank 修正为事后经验。
- 通用：用官方平稳噪声直接训练（域差异）；不做频率匹配的模板/模型。
