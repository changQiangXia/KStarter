## 1. 一句话重述与数字账

预测 NCAA 锦标赛每场胜负概率（提供历史结果，锦标赛结果作为评测）。真正的考点在本届变成了**"公开代码的复用与增量"**：冠军自述"基本是几年前 raddar 的 Python 代码，只改了两处"，亚军则把独特精力投在**分区效应（conference effects）**上；5th 抱怨"前 100 名里约 60% 是同一个 notebook 的无改动 fork"。

| 关键数字 | 值 | 来源 |
| --- | --- | --- |
| 1st（399553） | 复用 raddar 旧 Python 代码；**仅两处改动**：① 计算 Team Quality 时把 `np.exp()` 注掉（否则产生大量 inf；注掉后仍有约 25% 训练数据为 NaN）② 种子 1–4 对 13–16 不做 override；未改动版公榜 0.17629 也够第 6；特征 = 常规赛统计均值（T1/T1 对手/T2/T2 对手 各一份，含 `PointDiff`）+ `T1/T2_win_ratio_14d` + Team Quality + Seed_diff + 两队的 seed；模型 = XGB + `xgb.cv(5 折, shuffle)` 重复 3 次（原 R 版建议重复 10 次）；作者自述"更多是运气，没做多少新东西" | 399553 |
| 2nd（401578，0.17522） | 流水线 = R 预处理 → **分区效应 offset** → DataRobot 时间感知特征工程 + AutoML → R 端**概率平滑**后输出；最独特的是**从"常规赛跨区比赛"推导每个赛季的分区效应**（触发点：South Dakota State 女篮被他排成第 2，因 Summit 赛区很弱却 18–0）；用 `glmnet` 在非分区常规赛上学两个目标（主场分差、主场胜负 log-odds），主队/客队各取系数并求差作为 offset；技巧：**用单个列表示分区（主队 +1、客队 −1）**而不是主/客两列，从而把整个分区的信息集中在一列；建模动机=让模型用整季信息但对"接近锦标赛强度的比赛"加权；自述"只有 126 个计分样本，很可能有运气成分" | 401578 |
| 5th（401382） | 走"Moneyball"路线：只保留**按回合（possession）归一化**的效率类特征（"每回合更高效的球队更可能赢，与种子/名气无关"）；**丢掉 `NumOT` 与 `WLoc`**（前者是噪声、后者在锦标赛中立场地无意义）；并公开指出"前 100 约 60% 是同一 notebook 的无改动 fork"（对生态的批评） | 401382 |

## 3. 共识、分歧与裁决

### 共识一：公开基线（raddar 代码）统治本届（1st/5th + 生态批评）

冠军自述几乎零增量（两处修改）就夺冠，未改动版也能第 6；5th 统计"前 100 约 60% 为同一 notebook 的无改动 fork"。**裁决**：当"公开基线足够强 + 评测样本极少（126 场）"时，复用基线是**理性策略**，但也让名次信号极度稀薄；复盘应把"相对基线的增量"作为评价标准。置信度：高（当事人自述 + 生态观察）。

### 共识二：锦标赛样本小 → 名次噪声大（1st/2nd）

两位前列选手都主动声明"运气"；2nd 指出只有 126 个计分观测。**裁决**：单届结果不足以区分方法优劣；应把多年份的稳定性作为方法评价依据（该系列"往年冠军方案合集"帖正是为此）。置信度：高。

### 共识三：赛制要求"多提交择优选"（官方计分帖）

每届可提交多份、结算时只用选中的 2 份。**裁决**：锦标赛赛制的正确打法是"用两个提交覆盖不同风险偏好"（与女篮场"赌博/对冲"策略同源）。置信度：高。

### 分歧一：通用强基线 vs 领域自研特征

1st 直接用通用基线；2nd 押"分区效应"这一体育统计学的结构量；5th 押"每回合效率"这套规范化特征。**裁决**：在基线极强时，领域增量必须针对基线的**具体盲区**（2nd 的 South Dakota State 案例）；泛泛加特征无效。置信度：中高。

### 事件：正则化与指标口径（23 票帖 + 官方计分）

社区专门讨论"正则化对 LB Brier 的影响"；官方更新了计分数据源（API）。**裁决**：概率类指标的赛后分析要同时看校准与区分度；数据源变更要登记版本。置信度：中。
