## 0. 一句话重述：这道题真正在考什么

题面是"由 Ariel 卫星模拟的原始光谱信号（AIRS-CH0 光谱仪 + FGS1 制导）反演每个波长的凌星深度与置信区间"，实际被考的是**物理结构建模与仿真代码逆向**：

1. **信号有明确的乘性结构**：2nd 给出最清晰的分解——`Raw = Noise + Star(λ) × Drift(t,λ) × Transit(t,λ)`；1st 进一步指出生成器把 gain drift 建成 **f(t)·g(λ)**（时间多项式 × 波长多项式，可分离），而不是一般二维多项式 h(t,λ)——直接照这个形式拟合是夺冠关键之一。
2. **前四名几乎没有端到端深度学习**：2nd 纯贝叶斯+高斯过程（全程领先、最后被超）、4th 多项式拟合+TensorFlow 当优化器、1st 信号处理+GP/AE/NMF 集成、5th 特征+线性回归/小网络、6th 启发式+双头 CNN。原因是**训练/测试分布被故意做不同**（测试集出现训练中没有的大气分子）——拟合训练分子的模型本地 +0.1、LB 不动（5th 实测）。
3. **不确定度（sigma）是分数大头**：指标是高斯对数似然，sigma 与均值同等重要；4th 的 sigma 迭代（阈值分段→线性→二维曲面）贡献 ~0.03–0.05；5th 用 `std(pred)` 相关把它提升 **+0.030**。
4. **前景（foreground）之谜**：大量队伍发现"预测乘 1.006~1.008"能大涨；2nd 盲用该系数（critical，"score would be under 0.7 without"）并承认不知原因；1st 读 ExoSim2 代码后发现是模拟中加入的波长相关前景，改用 `[0:8]`/`[24:32]` 区域估计并从 `[8:24]` 扣除，拿到正确解。
5. **不确定的胜利**：2nd 全程第一，1st 只在最后两天反超，1st 自述"若比赛早一天或晚一天结束，我们会输"——顶端差距在 0.01 量级。

一句话：**这是一场"理解生成器的人赢"的比赛**——物理形式、检波器瑕疵与评分机制的知识，胜过多层网络。

## 3. 共识、分歧与裁决

### 共识一：物理乘性结构与仿真代码是主信息源（1st/2nd/4th 均显式建模）

1st：从 ExoSim2 代码拿到 `f(t)·g(λ)` 与 foreground，直接照抄生成器形式；
2nd：先验元素表把 noise/star/drift/transit 分层，逐元素定义分布；
4th：信号 = 多项式漂移 + 转捩深度，用拟合反演；
5th/6th：同样以"漂移多项式和转捩区"为核心。

**裁决**：仿真数据竞赛的头部收益来自**读生成器代码/文档**（"hack the simulator"，1st 自述）；纯学习在 0.68–0.70 区间见顶。置信度：高（1st 消融 + 多队结构一致）。

### 共识二：训练/测试有意分布迁移 → 依赖"训练分子"的方法失效（组织者确认 + 5th 实证）

资源帖：测试分布被故意做不同；
5th：任何在特征上加"模型"的方法本地虚涨 ~0.1 而 LB 不动；hosts 确认测试集有新分子；
1st：TauREx 拟合已知气体"train 极好、LB 极差"；
2nd：星谱跨行星共享（训练 +0.005）在测试 0.110 灾难。

**裁决**：在"分布故意不同"的赛制下，只能用**与分子无关的物理结构**（漂移形式、转捩形状、波长相关性）建模；任何基于训练集统计量（分子谱形状、星谱复用）的强假设都有灾难风险。置信度：高。

### 共识三：sigma/不确定度是分数的半壁江山（全员投入，量化 +0.03 级）

4th：sigma 从常数 RMSE → 阈值分段 → 线性 → 二维多项式（overall +0.03~0.05）；
5th：`std(pred)` 与误差强相关 → 缩放 sigma **+0.030**；
1st：常数 + 谱 std + GP 不确定度 加权（消融中 sigma 相关项贡献显著）；
6th：max−min 回归。

**裁决**：log-likelihood 型指标下，**先建好均值预测，再把 20–30% 的精力给 sigma**；sigma 的可解释特征（预测谱的离散度、ingress/egress 差异）比模型更稳。置信度：高。

### 分歧一：为什么"×1.006 系数"有效——盲用 vs 溯源

多数队伍（含 2nd）：probe 出乘 1.006~1.008 涨分，2nd 称"critical"且"不知原因"；
1st：读代码发现模拟加入了波长相关 foreground → 用两侧区域估计并从未污染区扣除；
4th：也发现 mean(preds) 与 mean(preds−targets) 的线性关系并作线性校正（后知同因）。

**裁决**：系数是"前景缺失"的一阶补偿；**结构性修正（估出波形再扣除）优于常数乘子**（1st 的消融：不做前景处理 −0.0105/−0.0123）。分歧本质是"probe 出答案"与"理解答案"的差距。置信度：高（1st 代码 + 消融）。

### 分歧二：贝叶斯全建模（2nd）vs 多项式/优化式拟合（4th）vs 深度集成（1st 的 GP/AE/NMF）

2nd：纯 BI+GP，先验物理、求解通用，全程第一；
4th：把 TensorFlow 当"每行星 2D 多项式优化器"（256 并行），计算便宜；
1st：经典信号处理 + 三个波长相关模型集成。

**裁决**：三种路线都能到 0.70+；BI 的优势在"先验可分解 + 天然给出误差"，代价是非线性要迭代线性化（7 次）与稀疏 GP；拟合路线的优势是快与鲁棒。**顶端差距（0.733 vs 0.70）来自物理形式正确性，而非推断方法**。置信度：中高。

### 分歧三：合成数据增强（5th）——为什么能救 LB

5th：TauREx3 生成 9 种训练中没有的分子谱，加进训练 → LB **+0.020**（本地略降）；
1st/6th：试图用已知气体谱反演 → 失败。

**裁决**：增强的方向不是"拟合训练分子"，而是"**覆盖测试可能出现的新分子**"——扩充输出的多样性（即使模型更难拟合）才对迁移有利；5th 的"少加几种两种榜单都涨、多加只涨 LB"是该逻辑的直接证据。置信度：中高。

## 5. 机制推演

**M1｜为什么物理形式比模型容量重要**：信号 = Star×Drift×Transit 是乘性结构；用错误的参数化（如一般 2D 多项式 h(t,λ)、或让网络自由学习）需要更多数据去逼近同一函数，而在"测试分布不同"的赛制下训练的像素级形状会过拟合到训练分子。**知道生成器形式 = 把假设空间缩到正确子空间**（1st 的 f·g 分解直接提升 dip 估计精度）。

**M2｜为什么 sigma 能贡献 0.03–0.05**：指标是高斯 log-likelihood——对每个波长，预测均值错会损失 logpdf，**sigma 报错（过大/过小）也直接损失**。sigma 的最优值与预测的不确定度分布有关；跨波长的离散度（std(pred)）与转捩前后预测差（ingress/egress 距离）是它的低成本代理（4th 的 2D 曲面、5th 的 +0.030）。在均值已接近天花板时，sigma 是最后的分差来源。

**M3｜分布迁移的三种应对及成败**：① 拟合训练分子（失败：TauREx 谱反演、网络预测吸收）；② 依赖训练统计量（失败：星谱共享 0.110）；③ 只建模物理不变量 + 主动扩充多样性（成功：1st 的结构模型、5th 的新分子增强）。**教训：迁移性来自"哪些量在分布变化下不变"**——漂移形式、转捩几何、波长相关结构不变；分子组成、星谱实例会变。

**M4｜前景为何表现为常数乘子**：模拟在信号上叠加了一个缓慢变化的波长相关附加项（foreground），当它未被建模时，最小二乘会把 dip 深度整体压低（乘法近似）；简单的乘子补偿能修掉一阶项，但**无法修正波长依赖的形状**——1st 的显式扣除因此在 0.01 级分差上胜出（消融 −0.0105）。

**M5｜为什么"训练集上看不到收益"的实验可能才是对的**：5th 的新分子增强让本地验证变差（更难拟合）但 LB +0.020；1st 的物理修正也在本地"打平"（旧方法 probe 也能到相近分）。相反，任何本地 +0.1 的"模型红利"在 LB 不动。**在分布迁移赛制里，本地分数是"拟合训练分布"的代理，而非泛化的代理**（与 L6/T3/T10 同族，本场把它推到极端）。

**M6｜顶端的对手是时间**：2nd 全程第一、1st 最后两天反超、1st 自述"早一天/晚一天都会输"；顶端 0.01 量级的差距由"最后一个正确想法"决定。对学习者的启示：此类比赛应把最后阶段预算留给**机制验证（读代码/消融）**，而不是继续堆模型。

## 7. 边界条件与反事实

- **反事实 1**：若不读生成器代码 → 最高分大致落在 probe-乘子路线（2nd 的 0.733 级别仍是顶级，但 1st 的 0.742 私榜来自结构性修正）。本场说明"代码逆向"在仿真赛可值 0.01+。
- **反事实 2**：若按训练集分布做模型选择 → 选到本地 +0.1 的分子拟合模型，LB 崩（5th/1st 的反证）。
- **反事实 3**：若忽略 sigma → 均值再好也丢 0.03+（4th/5th/1st 的 sigma 增益量化）。
- **反事实 4**：若共享星谱/用训练分子谱 → 测试灾难（2nd 0.110；1st/6th 的 TauREx 失败）。
- **边界**：结论依赖"知道/能读到仿真器"（开源 ExoSim2）与"指标含不确定度"；真实 Ariel 数据不会有 ground truth，但本场方法论（物理形式+不确定度+抗分布迁移）可迁移。
