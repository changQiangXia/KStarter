# Playbook：科学计算

> 版本：v1.1（定稿）｜ 依据：`notes/science/` 23 篇摘要（该主题 23/23 已完成）
> 覆盖：地质（ROGII）、酶（Novozymes）、聚合物（NeurIPS Polymer）、蛋白功能（CAFA 5/6）、单细胞（Open Problems ×2）、
> 医疗预测（AMP-PD）、天文（ARIEL 2024/2025）、控制（Ventilator）、地球物理（Waveform Inversion）、粒子物理（IceCube）、
> 引力波（G2Net）、RNA（Ribonanza）、气候（LEAP）、农业（CSIRO）、分子活性（Leash-BELKA）、行为（MABe）
> 另含研究论文型赛事（WiDS Phase II），见 §6.6

## 1. 这类比赛在比什么

| 特征 | 含义 | 影响 |
| --- | --- | --- |
| **领域先验可编码** | 存在物理/化学/生物规律 | 可写出物理基线，作为强对照 |
| **外部数据库丰富** | 公开数据集/文献/结构库 | 外部数据整合成为主要收益来源 |
| **评测集常与训练分布不同** | 单蛋白、单井、新分子 | 验证设计必须贴合评测结构 |
| **数据规模小、噪声大** | 样本少、测量误差 | 方差大，稳健性优先 |

## 2. 可复用方法

### 2.1 物理模型 + 神经网络混合

- ROGII：粒子滤波/HMM 生成物理可行轨迹，神经网络做误差互补与融合；3rd 用 SoftMax 门控逐位置选择候选。
- 通用形式：**物理模型定义可行域，神经网络拟合残差**。

### 2.2 问题重构

- 把回归重构为**对齐问题**（ROGII 1st 用 2D 对齐 + 交叉熵）。
- 建模**条件分布**再解码（AnchorCNN 预测 P(dTVT|TVT) 后用动态规划求路径）。
- 把序列转成"图像"做分割式预测（ROGII 26th：256 深度桶 × MD 列）。

### 2.3 外部数据整合（本主题最大的坑与最大的机会）

- **必须先做重叠样本差异分析**：NeurIPS Polymer 中外部数据的 Tg 系统性低约 20°C；不校正会引入偏差。
- 学术 PDF/文献挖掘：Deep Past 用 LLM 做句级对齐 + OCR 挖掘 60 篇文献，是低资源领域的标准做法。
- 公开数据库（蛋白稳定性 D1/D2/D3）合理补充训练集。

### 2.4 合成数据与预训练

- 物理一致的**合成数据预训练**（ROGII 2nd/26th）。
- **伪标签预训练**：在无标签大规模库上先训（Polymer 1st 用 PI1M 伪标签预训练 BERT）。

### 2.5 领域特征工程

- 局部几何：突变位点周围 21 个氨基酸的距离与夹角（Novozymes 3rd）。
- 结构/序列表示：SMILES、图神经网络、预训练分子模型（Polymer）。

## 3. 常见坑

| 坑 | 证据 |
| --- | --- |
| 用常规随机 CV 处理"单实体"评测 | Novozymes（测试集只有一个蛋白，公开 1 → 私榜 967） |
| 直接混用外部数据不校正偏移 | Polymer 8th 的偏移发现 |
| 忽视榜单可被探针/拟合操纵 | Novozymes、ROGII（大洗牌） |
| 验证集被少数主导样本带偏 | ROGII 2nd 明确要求"对少数主导井稳健" |
| 硬上重型预训练模型而算力不足 | Polymer 3rd 的教训（Uni-Mol 跑不动，转 GNN） |

## 4. 年度演进（初稿）

- **2022–2023**：物理模型与 GBDT 混合为主（Novozymes、ROGII 早期）。
- **2024–2025**：预训练分子/蛋白模型普及，外部数据整合与伪标签预训练成为标配（Polymer）。
- **2025–2026**：**AI 编码代理深度参与**科学赛实现（ROGII 1st/2nd/7th/36th 均如此），并出现"agent 引入数据泄漏"的新风险。

## 5. 新手学习路径

1. **先学物理基线**：读 ROGII 的粒子滤波思路，理解"先有可行域，再谈拟合"。
2. **再学问题重构**：把回归变成对齐/分布建模的三种做法（ROGII 1st/2nd/26th）。
3. **然后学外部数据整合**：Polymer 的偏移校正流程 + Deep Past 的文献挖掘。
4. **最后学评测陷阱**：Novozymes 的单实体测试集教训。

### 6.2 领域解释帖是被低估的公共资产

多场比赛的最高票内容是"**用最基础的语言讲清领域**"：
- HMS-EEG 的数据结构解释（**603 票**）
- Waveform Inversion 的物理链条解释（156 票）
- IMC 2025 的匹配理论入门（57 票）
- Mayo STRIP AI 的图像分类检查清单（107 票）

**行动建议**：进入新领域时，先花 30 分钟找这类帖子，比直接读代码省时得多。

### 6.3 验证与评估的特殊性

- **指标即物理量**：角度（IceCube）、波形误差（Waveform）、结构相似度（RNA）、检测阈值+虚警率（G2Net）。
- **测试集结构常与训练不同**：Novozymes（单蛋白）、ROGII（少量主导井）、Polymer（分布偏移）→ 验证必须复刻测试结构。
- **标注噪声是常态**：HuBMAP（血管标注不一致）、CAFA（功能注释不全）→ 软标签/一致性过滤。

### 6.4 工程与成本

- 数据规模常是主要障碍（IceCube、Waveform、LEAP）→ **分块/缓存/混合精度是必需项**。
- 训练成本要显式记录（LEAP 的 60h/120h 对照）。
- 算力不足时可用 Kaggle 云端免费资源（Ventilator 1st 的经验）。

### 6.6 非打榜形态：研究论文型赛事

- WiDS Datathon Phase II（2022）：产出物是**研究论文**而非模型，无排行榜、无分数反馈回路；官方用月度 Office Hours（EPA / CCAI / MIT Critical Data）做导师制引导。
- 这类赛的评审口味是**研究规范**：问题定义、数据来源、可复现性、写作质量；验证与论证全靠论文自身严谨性。
- 对新手：适合已有领域问题但缺打榜经验的队伍；选题可借用官方提供的 research questions 清单，同题材历史赛（ASHRAE）的公开 notebook 是写法模板。

## 7. v2 增补（Tier B 204 场，2026-10）

1. **working note 是第二交付物**：GeoLifeCLEF 2022/2024 均要求可复现技术报告（2024 时间线 5/24→6/7→6/21→7/8），收入 CEUR-WS，择优进 Springer LNCS；不可复现的 run 可能被移出正式发表。

4. **多模态融合主线**：卫星时序 + 环境栅格 + 图像；协变量用树模型/自注意力，影像用 CNN/Transformer，再概率层融合（geolifeclef-2022 1st/2nd）。
5. **医疗基座**：HAI-DEF 五族（CXR/Path/Derm/HeAR/CT）面向分类、暂不支持分割/生成；MedGemma 27B 部署与提交流程是主要门槛（med-gemma）。
6. **研究赛规则**：排名/作者归属/报告截止要在赛前确认；Office Hours 与里程碑录像是最低成本的"导师制"教材（wids-phase2、geolifeclef）。
