# Playbook 0：通用方法论（跨主题）

> 版本：v1.1 ｜ 依据：`notes/` 已完成的 189 篇摘要中反复出现的规律（v1.1 增补见 §10）
> 定位：这不是第七个主题，而是**所有主题共用的判断框架**。建议先读这一册，再进入各主题 playbook。

## 1. 开工四问（决定后续 80% 的方向）

| 问题 | 为什么关键 | 反面案例 |
| --- | --- | --- |
| **指标到底在奖励什么？** | 决定目标函数、后处理与风险位置 | ICR（Balanced Log Loss 偏好压低预测）、Hull（Sharpe 而非误差） |
| **测试集的构造方式是什么？** | 决定验证设计 | Novozymes（测试集只有一个蛋白）、CommonLit（4 个题目 → 122 个题目） |
| **赛制是否允许"用新数据更新"？** | 决定要不要做在线学习 | Enefit/Optiver/Jane Street/Mitsui（能更新就更新） |
| **数据来源是否唯一/是否拼接？** | 决定防泄漏与对齐策略 | Essay Scoring（两套数据拼接）、LLM Detect（隐藏测试来自不同生成器） |

## 2. 验证设计（最重要的地基）

1. **按实体分组**：患者/用户/文章/地点，凡有重复实体的任务都必须分组（RSNA 全系列、Feedback 系列、Jigsaw）。
2. **让验证规模与评测对齐**：Jane Street 把验证窗口设为与公开集相同的 200 天。
3. **量化 CV-LB 相关性**，再决定信谁：
   - 相关性高 → 以 CV 为决策依据（Feedback ELL、Optiver Close）。
   - 相关性低/公开榜是陷阱 → 以 CV 为唯一依据（ICR、LLM Detect、Jigsaw Toxic）。
4. **文本任务要防"来源泄漏"**：Union-Find 分组（Jigsaw Toxic）、近重复同折（MAP）。

## 3. 数据侧的三条铁律

1. **外部数据先做重叠样本差异分析**（Polymer 的外部数据 Tg 系统性偏低 20°C）。
2. **缺失即信息**（Ubiquant 的停牌指示价值约 70 个名次）。
3. **训练数据格式要与测试对齐**（AIMO 首届只保留整数答案题）。

## 4. 模型与集成

- **先量化单模型强度，再决定集成投入**（Optiver Volatility 消融：集成只值 0.0002）。
- **爬山法/加权融合**优于等权平均（Feedback ELL、Otto）。
- **跨领域方法迁移**（见 `LEARNING_PATH.md` 附录一：框融合、k-opt、BM25/LSI、对称性增强…）。
- **框架细节会埋雷**（RSNA-MICCAI 的 BatchNorm 与多通道输入冲突；Santa 2024 的 padding_side）。

## 5. 机制红利与风险

- **在线学习**：只要评测期会揭示新标签，就应增量更新（4 场独立验证）。
- **测试时训练（TTT）**：分布迁移大时在推理期适配（ARC 2024/2025、Jigsaw Agile Rules）。
- **黑箱评分下的迭代搜索**：可用但要设停止条件，且先确认规则允许（见 `LEARNING_PATH.md` 附录二）。
- **指标套利**：存在但要区分"能力"与"套利"（Home Credit 的下注策略、LLM Prompt Recovery 的后缀攻击）。

## 6. 常见陷阱总表

| 陷阱 | 后果 | 证据 |
| --- | --- | --- |
| 随机切分用于有分组/时间结构的数据 | 本地虚高、线上崩 | ICR、Home Credit、RSNA 系列 |
| 用公开榜标签/探针拟合 | 私榜暴跌 | ICR（公开 1 → 私榜 967）、Novozymes |
| 目标可由公开信息直接构造 | 比赛失去可比性 | JPX（历史股价满分） |
| 大评测集 vs 小评测集不分 | 小评测集下过度优化 | March Mania、CMI |
| 忽视推理成本 | 跑不完集成/超时 | WSDM（CausalLM + vLLM）、AIMO3 |
| 只看分数不看校准 | 概率任务失分 | March Mania、RSNA 乳腺 |
| 忽视赛制变动 | 策略过时 | Lux S2（规则改动需重写策略）、RSNA 2023（截止延长） |

## 8. 补充：经典方法与 ML 的力量对比（重要判断）

进入一个新领域前，先回答：**这个任务的经典方法有多强？** 多场比赛给出的答案是——**不要默认 ML 更强**。

| 比赛 | 经典方法 | ML 的合理位置 |
| --- | --- | --- |
| Ventilator Pressure | 控制逻辑可复现 66% 的数据 | 只负责剩余 34% 的困难部分 |
| G2Net 引力波 | 匹配滤波（信号处理） | 时频分类 + 与经典方法对照 |
| Smartphone GNSS | RTK/PPP 类定位算法 | 残差修正 / 噪声建模 |
| ARIEL 2024/2025 | 贝叶斯推断（同一作者两年连胜） | 未使用深度学习 |
| Kore 2022 | 规则型 agent | 冠军就是纯规则 |
| Otto 推荐 | 共现规则 | 纯规则进前三 |
| Smartphone/Rogii 等物理模型 | 物理/几何约束 | 网络拟合残差 |

**判断方法**：
1. 先搜该领域的"标准算法"（教科书/论文里的经典方法）；
2. 用它做基线，量出 ML 相对它的增量；
3. 若经典方法已很强，把 ML 用在**残差、噪声、后处理**上，而不是端到端替换。

**反面信号**：如果公开 notebook 里全是深度模型却没人报经典基线，先自己补一个——它可能直接是强基线。

## 9. 补充：公共学习资产的优先级

多场比赛的最高票内容不是方案，而是"**公共学习资产**"。遇到新领域时按此顺序找：

1. **领域解释帖**（用最基础语言讲清任务/数据/物理链条）：HMS-EEG（603 票）、Waveform（156 票）、IMC 2025（57 票）
2. **流程检查清单**：Mayo STRIP AI 的图像分类清单（107 票）
3. **方法综述**：PlantTraits 的机器视觉综述
4. **官方/主办方 notebook**：IMC 系列直接提供 LoFTR/DISK/DKM 示例；Learning Equality 的主办方树遍历代码
5. **往届系列方案汇总**：RSNA、HuBMAP、BirdCLEF、Jigsaw 等系列都有社区汇总帖

**收益**：这些材料的阅读回报率通常高于直接读代码——它们回答"为什么"，而代码只回答"怎么做"。

## 10. v1.1 增补：第二批次摘要（约 90–189 场）的新教训

### 10.1 集成科学（Playground 与 Featured 的共同结论）

- **信 CV–LB 关系，而不是最高 CV**（S6E2 冠军原话）：把真实提交按 CV 分段观察，CV 超过某阈值后不再兑现为 LB 提升——那是过拟合折内行为；从"可信区间"选提交。
- **无选择的全量平均会伤分**：150 个 OOF 直接平均不如 Optuna 选子集 + Ridge；约 1/10 的模型被稳定选中。**集成贡献 ≠ 单模 CV**：单模较弱的模型可能提供关键互补误差（S6E2 的 RGF/TabICL；S5E5 的 TE-XGB 拿 25% 权重）。
- **秩平均是对抗私榜抖动的稳定器**（S6E2 4th：把 4 个冠军 blend 转秩再平均）；概率平均受校准漂移影响大。
- **指标决定集成数学**：RMSLE 在 log1p 空间平均/Ridge/爬山；MAE 用中位数；RMSE 用均值（S5E5 教程）。
- **残差栈制造多样性**：NN 学线性模型残差、XGB 再学 NN 残差——不保证单模涨分，但给集成提供互补误差（S5E5 冠军）。
- **全量重训技巧**：5 折出 OOF 定权重后，用 100% 训练数据重训（迭代数≈1.25×最优均值）+ 多种子平均（S5E5 冠军称"每个比赛都有效"）。

### 10.2 合成数据与原始数据逆向（Playground 专场）

- **原数据先逆向公式**：S6E4 社区找到完全分离的生成公式（规则版打分即可 100%）；S6E1 用遗传编程逼近原公式（RMSE 8.97）。公式/规则是特征金矿，也是"噪声上限"标尺。
- **原数据的接入方式要做对照实验**：拼行（concat）vs 拼列（merge）可造成 ~0.003 的单模差异（S5E3：拼列 + SVC 直接冲到亚军级）；NN 拼行常被"搞糊涂"，只宜注入聚合统计（S6E2 4th）。
- **伪标签的正确理解**：收益来自"更多真实特征组合进入训练"，而不是假标签本身；折内训练两次即无泄漏（S6E1 教程）。前提：教师够强 + 分布一致。

### 10.3 结构与指标适配

- **按混淆结构设计架构**：当两类几乎从不混淆（S6E4 的 Low vs High），One-vs-Rest 两二分类器 + 概率闭式换算优于直接多分类。
- **均衡指标必须配阈值搜索/类权重**（Balanced Accuracy、QWK）；稀有类占比 3% 时分数对个别样本极敏感，名次呈"彩票"分布。
- **边界/截断目标用门控或区间加权**（S6E1 的 gating 与不对称损失、S6E2 的 CV 区间纪律）。
- **时间新窗口的测试集用按时间分组 CV**（S5E3 按年 GroupKFold；原数据 + 时间特征先做对抗验证再决定去留）。
- **先量化噪声上限**：找出互相矛盾的样本（S5E7 约 500 个不可预测行），避免对噪声过拟合，也为名次波动提供解释。

### 10.4 评审制比赛（非打榜赛）的写法

- 产出物是报告/论文/prompt 时，评分维度是：领域定义 → 方法匹配数据类型 → 叙事与可视化 → 复现规范。
- 通用军规（Survey 系列 7 条）：选具体问题、独特角度、引用来源、方法匹配测量尺度、简单图表、解释所有结果、美学与导航。
- 提前公开换反馈是被官方激励的策略（Survey 早鸟奖）；系列赛的往届获奖陈列是最便宜的起点。

### 10.5 LLM Agent 已成为竞赛基础设施（2025–2026 新常态）

- S6E4 亚军：Claude Code 第一天把上月比赛的 150 个脚本迁移到新赛，第 3 天登上私榜第一；Codex 再迁一版做双保险。ROGII 科学赛前排出多套 agent 参与的方案（见科学册）。
- 使用原则：**agent 提速局部迭代，但路线判断仍归人**（AI Agent Security 笔记的警示）；跨届代码资产 + 标准化脚本 = 新竞争力。
- 风险：agent 可能引入数据泄漏、也可能"过早放弃"复杂重构；重要提交保留人工复核环节。
