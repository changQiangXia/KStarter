### Previous Solutions and Takeaways

来源：https://www.kaggle.com/competitions/march-machine-learning-mania-2025/discussion/562585

Below are the publicly available links to the previous March Machine Learning Mania Solutions with a note on the techniques used. Happy Kaggling.

March Machine Learning Mania 2021 - NCAAW - Spread 1st Place

Elo Model for Probabilities: Used a simple Elo rating system (with minor tuning) to generate win probabilities. 

Data Preparation: Merged historical tournament outcomes (calculating margin of victory) with Elo-based probabilities, initially forgetting to merge on Season (a lucky oversight). 

KNN Regression for Spreads: Leveraged a KNeighborsRegressor, tuned via GridSearchCV, to map win probabilities to margin predictions. 

Final Submission: Despite the merge bug, the model (k=41) predicted spreads effectively—securing first place.

March Machine Learning Mania 2021 - NCAAW - Discussion

Data & Feature Engineering: Combined standard season data (focused on spreads), reused R notebook features, implemented a custom PageRank approach via cuGraph, and integrated 538-based features for the most recent four seasons. 

Two-Stage Modeling: First created meta-features on all seasons without 538 data, then combined these meta-features with 538 data (restricted to the last four seasons) for the final model. 

Ensembling & Model Types: Enlisted XGBoost, LightGBM, HistGradientBoosting, etc., in a multi-step ensemble to predict spreads (Level 1) and win probabilities (Level 2). 

Postprocessing / “Betting” Adjustments: Selected high-ranked teams in early rounds to gain a slight score edge, acknowledging that the “1-0” trick could have yielded a larger boost.

March Machine Learning Mania 2021 - NCAAM - 3rd Place Solution 

Minimal Dataset: Focused on Kaggle’s provided files without Massey Ordinals, allowing more time for model tuning rather than data wrangling. 

PyCaret Classification: Employed PyCaret with extensive parameter tuning (feature engineering, missing data imputation, Boruta) to minimize LogLoss. 

Model Ensembling: Performed 10-fold cross-validation and ensembled Extra Trees, LDA, and Naive Bayes regressors specifically targeting LogLoss. 

Final Submission: Submitted predictions directly from the finalized model—no manual overrides—finishing 3rd among 707 participants.

March Machine Learning Mania 2021 - NCAAM - 4th Solution 

Data & Basic Features: Averaged all system ranks (converted to ratings) and regular-season stats (eFG%, TO%, FTR, ORB%, PPP, POSS, etc.). 

Single LightGBM Approach: Used a single LightGBM model, splitting data from 2003–2018 and performing separate year-based validations (2016–2019). 

Four-Model Ensemble: Trained four distinct models (each omitting one validation season) and averaged their predicted probabilities for submission. 

Result: Achieved 4th place with a log-loss of 0.56346, boosted by steady cross-validation and a final ensemble blend.

March Machine Learning Mania 2022 - Women's - 1st Place Solution 

Two-Model Strategy: Submitted a “passive” LightGBM-only model plus an “aggressive/gambling” model that manually boosted probabilities for three strong teams. 

Feature Engineering: Focused on basic seeded features (team IDs, seeds, etc.) and minimal transformations, relying on LightGBM for robust performance. 

Implementation: Ran all data prep via R scripts, then shifted to Python notebooks for final model execution, merging outputs in a straightforward workflow. 

Post-Processing: Overrode predictions for select teams in the “aggressive” submission, ending with a best log-loss of 0.35438 and a 1st place finish.

March Machine Learning Mania 2022 - Women's - 2nd Place Approach 

Base FiveThirtyEight Model: Converted 538’s rating differences into probabilities and adjusted early-round matches for more precise outcomes. 

Uncertain Match Overrides: Applied Madtown-style thresholds (e.g., 0.36 vs. 0.64) to split close games across two submissions, limiting log-loss near 0.5. 

Variance in Predictions: Flipped ~13 matches to contrarian probabilities in each submission, guaranteeing at least one “correct” side to reduce overall log-loss. 

Consistent Top Finish: All override setups placed in the top 8, illustrating how strategic probability splitting can markedly improve final standings.

March Machine Learning Mania 2022 - Women's - 3rd Place Solution 

538 Baseline: Started with implied win probabilities from 538’s projections, deriving each matchup’s chance by adjusting for round advancement. 

Linear Transformations: Generated ~1,200 small probability distortions (translation/rotation) around the baseline to explore contrarian edges. 

Monte Carlo Simulation: Simulated 25,000 tournaments per transformation, selecting the one that consistently placed top 5 across all runs. 

Contrarian Edge: Slightly exaggerating probabilities over 0.93 (and discounting near 0.36–0.64) boosted log-loss improvement by ~0.036, securing 3rd place.

March Machine Learning Mania 2022 - Men’s - #1 Solution (Lucky Error) 

Accidental Data Omission: Used only regular-season data but mistakenly missed the stage2 file, reverting to Prelim2018 stats for 2017. 

Single XGBoost: Trained an XGBoost model with a cauchy objective (MAE-focused) to predict point margins, then converted margins into probabilities. 

Focused Feature Selection: Carefully curated features and discovered near-optimal performance on a consistent year-by-year cross-validation. 

Fortunate Upset Capture: Correctly covered big upsets (e.g., Oregon St. #6 over Baylor #2) and ended up first place due to the unintentional data slip.

March Machine Learning Mania 2022 - #2 Solution 

LightGBM Model: Employed AutoLGBM for rapid hyperparameter tuning, running a 10-fold cross-validation pipeline. 

Data Selection: Used MNCAATourneyDetailedResults, MNCAATourneySeeds, and partial MMasseyOrdinals for essential features. 

Implementation Simplicity: Kept feature engineering minimal while focusing on stable parameter settings within Python code. 

Efficiency & Results: Achieved second on the private leaderboard (0.55415) with a ~2-hour total training process.

March Machine Learning Mania 2022 - #3 Solution Explained 

Excel-Based Power Ratings: Regressed historical results (2018–2021) in Excel to generate standardized team power metrics. 

Input Metrics: Included offensive/defensive efficiency, 3-point share, possessions, assist/turnover ratio, and seeds/Quad outcomes. 

Weighting & Coefficients: Used linear regression coefficients to combine each metric into a single predictive rating system. 

Bracket Execution: Applied these ratings to build bracket predictions in Excel, finishing 3rd overall in 2022.

March Machine Learning Mania 2023 - 1st Place Submission 

Adapted raddar Code: Leveraged @raddar’s older model in Python, mainly fixing a bug in np.exp() and verifying data merges. 

Key Features: Used regular-season averages (FGM/FGA, OR, Ast, TO, point diff) plus short-term win ratios and seed info. 

XGB + Repeated CV: Ran XGBoost with 5-fold cross-validation, repeated thrice, to map these features into final predictions. 

Minimal Overrides: Avoided heavy gambling overrides, finishing 1st with a final log-loss near 0.176 on the private leaderboard.

March Machine Learning Mania 2023 - 2nd Place Solution 

Conference Effects: Used a glmnet approach on non-conference data to offset conference strength, then fed these offsets into main models. 

Multiple Sub-Models: Trained four models (home win & point diff) each for men and women, doubling the weight of NCAA games. 

Time-Aware Featurization: Relied on DataRobot’s rolling-stat engineering (2 weeks, 1 month, etc.) for pace, efficiency, and box-score differentials. 

Final GAM Smoothing: Tied predicted margins to win probabilities with mgcv to correct for overconfidence, landing at 2nd overall.

March Machine Learning Mania 2023 - 3rd Place Solution 

Selective Data Use: Focused on NCAATourneyDetailedResults, seeds, and regular-season info, discarding MasseyOrdinals for minimal gains. 

Season-Blended Averages: Combined current-season metrics with prior two seasons (weighted) to stabilize outlier performances. 

XGBoost & Repeat CV: Employed repeated cross-validation (5 folds) with Normalizer scaling on core features (points, seeds, etc.). 

Stable Outcome: Achieved 3rd place at 0.17525 log-loss, illustrating steady performance with minimal post-processing.

March Machine Learning Mania 2024 - 1st Place Solution 

Nate Silver Ratings + Tweaks: Converted rating gaps into probabilities, slightly inflating top teams into “super teams” for a final edge. 

Normal-Based Transform: Used a simple normal distribution margin function, adjusting for small home advantages in early women’s rounds. 

Monte Carlo Bracket: Simulated 5,000 tournament brackets (runtime <1 hour) for an averaged bracket submission. 

Victory Result: Topped the leaderboard at 0.05313, showing that well-chosen overrides on strong favorites can be decisive.

March Machine Learning Mania 2024 - 2nd Place Solution 

Ridge & Mixed-Effects Ratings: Derived offense/defense pace and efficiency through GLM/mixed-effects regressions, feeding them into XGBoost. 

Score Difference to Win Probability: Translated predicted margins into probabilities for 100k bracket simulations in R. 

Override Champion: Increased UConn men’s probability to 100% in one submission, jumping from 16th to 2nd. 

Scoring Critique: Noted that round-based Brier scoring incentivizes champion “gambles,” expressing a preference for point-based MAE scoring.

March Machine Learning Mania 2024 - 3rd Place Solution 

Odds-Based Bracket: Started from Nate Silver’s 2024 odds, converting rating differences to weighted probabilities per matchup. 

Favorite-Longshot Fix: Employed a custom goto_conversion to adjust biases in extremely high or low win probabilities. 

Fast Simulations: Generated 99 bracket simulations with weighted coin flips in ~30 seconds total runtime. 

Third Place Finish: Logged a 0.05536 final score, proving that straightforward rating cleanup and bracket randomization can secure a top result.

### 4th Place Solution for the March Machine Learning Mania 2025 Competition

4th Place Solution for the March Machine Learning Mania 2025 Competition

Context:

Business context: https://www.kaggle.com/competitions/march-machine-learning-mania-2025/overview

Data context: https://www.kaggle.com/competitions/march-machine-learning-mania-2025/data

Overview of the Approach:

Logistic regression (win or loss) on the leaf nodes of Xgboost with Cauchy loss function on point differential. Features include all features of the original https://www.kaggle.com/code/raddar/vilnius-ncaa but I added Laplace Smoothed features based upon prior season matchup, away wins, last 14 day win ratio, and uniquely stacked out of fold predictions. For the validation strategy, I only use personal intuition based upon the Brier score of the last year 2024 being left out.

Details of the Submission:

I did not use the CV code listed because of time based leakage. I did not use the spline in the original code because of target leakage. I used the leave one season out only for model averaging instead of CV. I had models with "better" leaky local CV which I did not submit. No gambling was used. No manual manipulation was used. My other submission was Raddar's old Github published solution in R which won multiple times in the past. I did not use any external data and only utilized data published on Kaggle for official use in this competition.

If you'd like to visualize your Kaggle submission file as a bracket, you can do so at this webpage:

https://wncviz.com/NCAABrackets/KaggleBrackets.html

When you first navigate to the page, it will display a blank bracket. If you upload your submission, Games that have been scheduled or played will automagically appear. Games that have been played will be shaded according to your prediction. You can hover of the games to get more information and you can also project to see how the tournament might play out according to your predictions.

There are several example submissions accessible via a dropdown menu, if you just want to see how the process works. They date back to 2010 and are all generated via a simple linear regression against an eigenvector based rating system. The most recent one is my 2025 entry which uses linear regression against that same rating system and some other team stats. Evidently, your prediction file need not be recent. In principle, the predictions can be for any tournament for which Kaggle provides data. Your submission need not be complete, either.
