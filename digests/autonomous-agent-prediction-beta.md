### Common Causes of Submission Failures

来源：https://www.kaggle.com/competitions/autonomous-agent-prediction-beta/discussion/723907

I will collect here some common reasons submissions fail, as I observe them, and how to fix the failure. If you are able, running the evaluation locally first is a great way to debug your agents.

Unable to submit request because Multiple tools are supported only when they are all search tools.

Some models have limited tool support. The gemini-2.5-* series models only support one tool. The deepseek-r1-0528 model does not support tools at all. You probably want to use other models except for special cases.

Evaluation harness error: Failed to load skill

A skill name "must be lowercase kebab-case (a-z, 0-9, hyphens), with no leading, trailing, or consecutive delimiters." Change my_skill to my-skill, for instance.

Agent completed without submitting any valid predictions

There can be a lot of reasons for this. An agent can get stuck in a thought loop at the start of a session and burn up the token budget or error out. Agents can also run scripts that use up the allowed session time before they have a chance to submit anything. They can also just get confused and terminate the session without doing anything. The fix for these kinds of issues will come from better instructions, temperature settings, etc.

Agent error: 'Context variable not found: x.'

The evaluation system compiles submissions into Google ADK agents. ADK supports injecting session state variables into agent instructions using Python {key} templates. (We define a number of task-related variables you can use. See the kaggle-kaggle-skill/resources/agent-instructions.md file in the competition dataset.)

If your instructions include things that look like valid Python identifiers wrapped in braces, ADK will try to inject them as session state variables, raising an error if they are undefined. So including LaTeX strings like \sqrt{x} will fail because x is a valid Python identifier and is undefined. However, ADK will skip parsing things that do not look like Python identifiers, so \sqrt{x } and \sqrt{x+1} are okay.

temperature is deprecated for this model

Newer Anthropic models will fail with temperature set in the generation config. A previous (prior to July 9th) version of the metric was injecting a default temperature into the config, but this is now fixed.

### 3rd place solution + my first Kaggle competition! 🎉

来源：https://www.kaggle.com/competitions/autonomous-agent-prediction-beta/discussion/737407

Hey everyone,

Just wanted to share — this was actually my first-ever Kaggle competition. I joined mostly to learn and try something new, and honestly didn't expect to place at all, so 3rd place is a really nice surprise!

My approach, briefly:
I built an Agent Config for this meta-competition that trains and blends multiple models — LightGBM, XGBoost, and CatBoost (each handling categorical columns natively, no one-hot blowup), plus a logistic regression baseline — and picks between the best single model or a blend based on honest out-of-fold (OOF) validation, so the comparison is never made blind.

The agent's workflow was budget-aware given the 60-minute/session constraint: orient on the dataset first, validate with proper CV, submit a fast baseline early to get a real anchor score, then iterate with feature engineering and re-check whether blending still wins after each round.

Biggest takeaway for a first-timer: getting the Agent Config schema exactly right (agent.yaml, sub-agent config paths, etc.) took a few failed submissions before it validated — worth testing locally with validate_submission.py before burning submission attempts.

Thanks to the organizers for such a fun and different competition format — really enjoyed learning through this one. And yes, that's my swag water bottle below 😄
