### 4th place solution - stacking approach with XGB as meta model.

来源：https://www.kaggle.com/competitions/playground-series-s3e26/discussion/464863

Thanks for the PS3 2023 series, always a fun and good area for testing and experiment new models and ideas, benchmark against the old ones! It started well and ending the same with a 1st in PS3E1 and 4th place in this one, the common for all during the series are the knowledge one gets, valuable knowledge and insights.

The solution

As hinted in this post https://www.kaggle.com/competitions/playground-series-s3e26/discussion/461062 XGB works well in classification, and that was the base idea.

The key was using a stacking approach with OOF from many other different top solutions and use XGB as meta model for training the stacked predictions + orginal features. And also try not to tune and optimize every solution to much, reduce the risk of overfitting, instead use the predictions as extra features in the final stacking training.

Many solutions shared the same small added feature engineering as below, rest was unchanged in terms of FE.

train_df['Age_Group'] = pd.cut(train_df['Age'], bins=[9000, 15000, 20000, 25000, 30000], labels=['A', 'B', 'C', 'D'],)

train_df['Log_Age'] = np.log1p(train_df['Age'])

scaler = MinMaxScaler()

train_df['Scaled_Age'] = scaler.fit_transform(train_df['Age'].values.reshape(-1, 1))

### 2nd Place: with help from NNs.

来源：https://www.kaggle.com/competitions/playground-series-s3e26/discussion/464887

With this competition I set out to improve my knowledge of neural networks. I had trouble getting good results with them in past competitions, often finding they performed worse in the private leaderboard, even when added to ensembles of GBDTs. However, this time I think they were the secret sauce that helped me get 2nd place.

My solution is pretty straightforward. Just a combination of XGBoost, LightGBM, and neural network predictions, with another neural network used to stack them together. The XGBoost and LightGBM predictions were nothing special, just an average of predictions from 10 different sets of hyperparameters found by Optuna.

For the initial neural network predictions, after reading through a bunch of papers and iterating on the techniques described within, I found that the piecewise linear encoding (PLE) technique described in this paper greatly improved my score. 

I applied PLE to each continuous feature, an embedding layer for the edema and stage features, and fed in the remaining binary features as is (after converting to 0/1). The structure looks sort of like this:

[图 1: inbox%2F420768%2F98b38d0a01227623402b6ae538da9ffd%2Fmodel_level0.png]

The actual network included some additional layers after each PLE input, before they were concatenated together, but to keep the diagram simple I did not include them. With this neural network alone I was able to get a score around .401 on the private LB, good enough for top 10%. Despite its solid individual performance, its addition to the stack only added around a .001 boost to the score, but I'm just glad it improved the stack at all.

For the stacking neural network, I started with the idea of getting the network to learn a weighted average of input predictions, which looked something like this:

[图 2: inbox%2F420768%2F714a6644786aa1a3cf062646c213c5a0%2Fmodel_level1.png]

Through some more experimentation, I found that the network achieved better scores by

Giving each class probability within a prediction its own weight, rather than computing a single weight and applying it to each class probability, and

Calculating each prediction's weights using all 3 predictions, rather than only itself.

With these changes the network looked more like this:

[图 3: inbox%2F420768%2Fc1f9601e0528dbf7f9a2c63018fcae41%2Fmodel_level1_2.png]

Again, for the sake of simplicity, there are some additional layers not included here. This stacking architecture gave a boost of .004 compared to taking a simple average.

Overall, I had a lot of fun working on this competition. The 2nd place was a nice bonus, but I'm more grateful from the knowledge acquired in the process of researching and trying out neural networks. For anyone else interested in recent tabular neural network innovations, I would recommend taking a look at https://sebastianraschka.com/blog/2022/deep-learning-for-tabular-data.html. There are plenty of ideas using neural networks that I either wasn't able to try or wasn't able to get working for this competition, but definitely look forward to trying these ideas and more in future competitions.

Happy new year!

In this Kaggle competition, I employed a sophisticated ensemble learning technique combining LightGBM and XGBoost classifiers. This approach was instrumental in securing the 7th place. Below, I outline the key components of my methodology, including data preprocessing, feature engineering, model optimization, and ensemble strategy.

1. Data Preprocessing and Feature Engineering:

Label Encoding: Custom class LabelEncoding was implemented to convert categorical features like 'Drug', 'Sex', etc., into numerical format, ensuring compatibility with ML models.

Feature Creation: New features, such as 'date_of_diagnosis' and 'diseases', were engineered from existing data to enhance the model's predictive power.

Data Splitting: The dataset was split into training and testing subsets, with stratification to maintain the proportion of target classes.

2. Model Optimization:

-Optuna for Hyperparameter Tuning: Optuna, an open-source hyperparameter optimization framework, was employed to fine-tune the parameters of LightGBM and XGBoost models.

Custom Objective Function: For each model, a custom objective function was defined to optimize the negative log loss, ensuring a robust model performance.

3. Ensemble Strategy:

-Voting Classifier: An ensemble of LightGBM and XGBoost models was created using the **VotingClassifier ** from scikit-learn. This approach combined the strengths of both models, improving overall accuracy and robustness.

-Soft Voting: The ensemble used soft voting, which takes the probability estimates from each classifier and averages them to predict the final output.

4. Results and Submission:

-Performance Evaluation: The ensemble model was evaluated using the log loss metric on the test dataset.

-Prediction and Submission: Predictions were made on the unseen test data, and results were formatted into a submission file following the competition guidelines.

Conclusion:

The combination of LightGBM and XGBoost with a focus on hyperparameter optimization and feature engineering proved to be a highly effective strategy. This approach not only provided robust predictions but also showcased the power of ensemble techniques in tackling complex machine learning problems.
